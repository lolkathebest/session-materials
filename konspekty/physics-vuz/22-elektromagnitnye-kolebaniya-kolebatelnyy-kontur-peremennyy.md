## 1. Свободные электромагнитные колебания в идеальном колебательном контуре

### Идеальный колебательный контур и физическая картина колебаний

> **Определение.** Идеальным колебательным контуром называется замкнутая электрическая цепь, состоящая из конденсатора электроемкостью $C$ и катушки индуктивностью $L$, активное электрическое сопротивление которой равно нулю ($R = 0$).

Для понимания того, как возникают колебания, обратимся к физической природе процессов, происходящих в элементах контура. 

Конденсатор обладает способностью накапливать энергию электрического поля. Если обкладки заряженного конденсатора соединить с катушкой индуктивности, начнется процесс разрядки конденсатора через катушку. В катушке возникает изменяющийся электрический ток, который порождает переменное магнитное поле. Согласно закону электромагнитности, это поле наводит в витках катушки ЭДС самоиндукции, которая препятствует быстрому изменению тока. В результате процесс разряда растягивается во времени.

Рассмотрим подробный поэтапный цикл превращения энергии в идеальном контуре за один полный период колебаний $T$:

1. **Начальное состояние ($t = 0$):** Конденсатор заряжен до максимального заряда $q_m$, напряжение между его обкладками максимално, сила тока в цепи равна нулю ($I = 0$). Вся полная энергия контура сосредоточена исключительно в электрическом поле конденсатора:
   $$W = W_e = \frac{q_m^2}{2C}$$

2. **Первая четверть периода ($0 < t < \frac{T}{4}$):** Конденсатор начинает разряжаться. Через катушку начинает течь возрастающий по модулю электрический ток. Энергия электрического поля конденсатора уменьшается, но при этом в катушке растет энергия магнитного поля. Сила тока достигает своего максимума в момент, когда весь заряд с обкладок конденсатора стекает ($q = 0$).

3. **Вторая четверть периода ($\frac{T}{4} < t < \frac{T}{2}$):** Ток в цепи, стремясь по инерции (благодаря явлению самоиндукции) сохранить свое направление и величину, продолжает течь в ту же сторону, перезаряжая конденсатор. Теперь обкладки получают противоположные знаки заряда. Ток постепенно убывает до нуля, а магнитное поле катушки коллапсирует, полностью преобразуясь обратно в энергию электрического поля заряженного конденсатора. В этот момент ($t = \frac{T}{2}$) заряд на обкладках достигает своего максимального значения, но с противоположным знаком ($-q_m$).

4. **Вторая половина периода ($\frac{T}{2} < t < T$):** Процесс повторяется в обратном направлении: конденсатор разряжается, ток течет в противоположную сторону, создавая магнитное поле, которое затем вновь заряжает конденсатор в исходное состояние.

Этот непрерывный взаимный переток энергии из электрической формы в магнитную и обратно представляет собой свободные электромагнитные колебания.

### Вывод дифференциального уравнения свободных колебаний

Для строгого математического описания процесса воспользуемся вторым законом Кирхгофа для замкнутого контура. Поскольку активное сопротивление провода равно нулю, падение напряжения на активном сопротивлении отсутствует. Сумма падений напряжений на элементах цепи равна нулю:
$$U_C + U_L = 0$$

Где:
- $U_C = \frac{q}{C}$ — напряжение на конденсаторе (с учетом того, что заряд $q$ связан с напряжением соотношением $q = C U_C$);
- $U_L = \varepsilon_s$ — ЭДС самоиндукции, возникающая в катушке индуктивности при изменении силы тока.

По закону электромагнитной индукции Фарадея для самоиндукции:
$$\varepsilon_s = -L \frac{dI}{dt}$$

Сила тока $I$ в любой момент времени связана со скоростью изменения заряда $q$ на обкладках конденсатора соотношением:
$$I = \frac{dq}{dt} = q'$$

Подставим выражение для силы тока в формулу ЭДС самоиндукции:
$$\varepsilon_s = -L \frac{d}{dt}\left(\frac{dq}{dt}\right) = -L \frac{d^2q}{dt^2}$$

Теперь подставим напряжения $U_C$ и $U_L = \varepsilon_s$ в уравнение второго закона Кирхгофа:
$$\frac{q}{C} - L \frac{d^2q}{dt^2} = 0$$

Разделим обе части полученного уравнения на индуктивность $L$ и перенесем слагаемые, чтобы получить стандартный вид дифференциального уравнения второго порядка:
$$\frac{d^2q}{dt^2} + \frac{1}{LC} q = 0$$

Введем обозначение для положительной константы:
$$\omega_0^2 = \frac{1}{LC}$$

Тогда дифференциальное уравнение свободных электромагнитных колебаний принимает канонический вид:
$$\frac{d^2q}{dt^2} + \omega_0^2 q = 0$$

Это однородное линейное дифференциальное уравнение второго порядка с постоянными коэффициентами. Из математики известно, что его решением является гармоническая функция синуса или косинуса.

### Законы изменения заряда, тока и собственная частота

Решением дифференциального уравнения колебательного контура является функция гармонического колебания заряда конденсатора во времени:
$$q(t) = q_m \cos(\omega_0 t + \varphi_0)$$

Где:
- $q(t)$ — мгновенное значение заряда на обкладках конденсатора в момент времени $t$, [Кл];
- $q_m$ — амплитудное (максимальное) значение заряда, [Кл];
- $\omega_0$ — собственная циклическая частота колебаний, [рад/с];
- $\varphi_0$ — начальная фаза колебаний, [рад], определяемая условиями возбуждения контура в момент времени $t = 0$.

Параметр $\omega_0$ определяется исключительно параметрами самого колебательного контура (емкостью и индуктивностью). Из равенства $\omega_0^2 = \frac{1}{LC}$ получаем формулу Томсона для собственной циклической частоты:
$$\omega_0 = \frac{1}{\sqrt{LC}}$$

Единица измерения циклической частоты в СИ — радиан в секунду [рад/с]. Соответственно, линейная собственная частота колебаний $\nu_0$ [Гц] и период колебаний $T$ [с] равны:
$$\nu_0 = \frac{\omega_0}{2\pi} = \frac{1}{2\pi\sqrt{LC}}$$
$$T = \frac{1}{\nu_0} = 2\pi\sqrt{LC}$$

Найдем закон изменения силы тока в цепи. Сила тока есть первая производная заряда по времени:
$$I(t) = \frac{dq(t)}{dt} = \frac{d}{dt} \left[ q_m \cos(\omega_0 t + \varphi_0) \right]$$

Дифференцируем сложную функцию по правилам математического анализа:
$$I(t) = -q_m \omega_0 \sin(\omega_0 t + \varphi_0)$$

Множитель перед синусом представляет собой амплитудное значение силы тока $I_m$:
$$I_m = q_m \omega_0$$

Следовательно, закон изменения силы тока записывается как:
$$I(t) = -I_m \sin(\omega_0 t + \varphi_0)$$

Или, используя тригонометрическое тождество для сдвига фазы на $\frac{\pi}{2}$:
$$I(t) = I_m \cos\left(\omega_0 t + \varphi_0 + \frac{\pi}{2}\right)$$

Это показывает важное свойство: колебания силы тока опережают по фазе колебания заряда на конденсаторе на $\frac{\pi}{2}$ радиан. Когда заряд равен нулю, модуль силы тока максимален, и наоборот.

### Энергетические соотношения в идеальном контуре

Поскольку активное сопротивление идеального контура равно нулю, диссипация (рассеяние) энергии в виде тепла не происходит. Полная энергия контура $W$ остается постоянной во времени и складывается из энергии электрического поля конденсатора $W_e(t)$ и энергии магнитного поля катушки $W_m(t)$:
$$W = W_e(t) + W_m(t) = \frac{q(t)^2}{2C} + \frac{L I(t)^2}{2} = \text{const}$$

Подставив сюда законы изменения заряда и тока в момент, когда заряд максимален ($q(t) = q_m$, $I(t) = 0$), получаем выражение через максимальный заряд:
$$W = \frac{q_m^2}{2C}$$

В момент времени, когда конденсатор полностью разряжен ($q(t) = 0$), сила тока достигает максимума ($I(t) = I_m$). Подстановка этих значений дает выражение полной энергии через максимальную силу тока:
$$W = \frac{L I_m^2}{2}$$

Приравняв эти два выражения, мы можем легко связать амплитуды заряда и тока в контуре:
$$\frac{q_m^2}{2C} = \frac{L I_m^2}{2} \implies I_m = q_m \sqrt{\frac{1}{LC}} = q_m \omega_0$$

### Разобранный пример

**Условие задачи:**
Колебательный контур состоит из конденсатора емкостью $C = 4{,}0\text{ мкФ}$ и катушки индуктивностью $L = 25\text{ мГн}$. Максимальное напряжение на конденсаторе равно $U_m = 50\text{ В}$. Найти максимальную силу тока в контуре $I_m$, собственную циклическую частоту колебаний $\omega_0$, а также полную энергию контура $W$.

**Дано:**
- $C = 4{,}0\text{ мкФ} = 4{,}0 \cdot 10^{-6}\text{ Ф}$
- $L = 25\text{ мГн} = 25 \cdot 10^{-3}\text{ Гн}$
- $U_m = 50\text{ В}$

**Найти:**
- $\omega_0$ — ?
- $I_m$ — ?
- $W$ — ?

**Ход рассуждений:**
1. Циклическую частоту колебаний найдем по формуле Томсона, зная индуктивность и емкость: $\omega_0 = \frac{1}{\sqrt{LC}}$.
2. Полную энергию контура удобно вычислить через параметры конденсатора в момент максимального напряжения, когда вся энергия сосредоточена в электрическом поле: $W = \frac{C U_m^2}{2}$. Также ее можно проверить через максимальный заряд, но напряжение дано в условии напрямую.
3. Максимальную силу тока $I_m$ найдем из закона сохранения энергии, приравняв полную энергию контура к максимальной энергии магнитного поля катушки: $W = \frac{L I_m^2}{2}$, откуда выразим $I_m = \sqrt{\frac{2W}{L}}$ либо через связь амплитуд ($I_m = q_m \omega_0 = C U_m \omega_0$). Второй путь через связь амплитуд является более надежным для проверки вычислений.

**Решение в общем виде:**
1. Циклическая частота:
   $$\omega_0 = \frac{1}{\sqrt{LC}}$$
2. Полная энергия контура:
   $$W = \frac{C U_m^2}{2}$$
3. Связь максимального тока с параметрами:
   $$I_m = q_m \omega_0 = (C U_m) \omega_0 = C U_m \frac{1}{\sqrt{LC}} = U_m \sqrt{\frac{C}{L}}$$

**Подстановка числовых значений:**
1. Вычисление циклической частоты:
   $$\omega_0 = \frac{1}{\sqrt{25 \cdot 10^{-3}\text{ Гн} \cdot 4{,}0 \cdot 10^{-6}\text{ Ф}}} = \frac{1}{\sqrt{100 \cdot 10^{-9}}} = \frac{1}{\sqrt{10^{-7}}} = \frac{1}{10^{-3}\sqrt{10}} = \frac{1000}{\sqrt{10}}\text{ рад/с}$$
   Учитывая, что $\sqrt{10} \approx 3{,}1622$:
   $$\omega_0 \approx \frac{1000}{3{,}1622} \approx 316{,}2\text{ рад/с}$$

2. Вычисление полной энергии контура:
   $$W = \frac{4{,}0 \cdot 10^{-6}\text{ Ф} \cdot (50\text{ В})^2}{2} = \frac{4{,}0 \cdot 10^{-6} \cdot 2500}{2} = 2{,}0 \cdot 10^{-6} \cdot 2500 = 5000 \cdot 10^{-6}\text{ Дж} = 5{,}0 \cdot 10^{-3}\text{ Дж} = 5{,}0\text{ мДж}$$

3. Вычисление максимальной силы тока:
   $$I_m = U_m \sqrt{\frac{C}{L}} = 50 \cdot \sqrt{\frac{4{,}0 \cdot 10^{-6}}{25 \cdot 10^{-3}}} = 50 \cdot \sqrt{\frac{4{,}0 \cdot 10^{-6}}{2{,}5 \cdot 10^{-2}}} = 50 \cdot \sqrt{1{,}6 \cdot 10^{-4}} = 50 \cdot (4 \cdot 10^{-2}) = 50 \cdot 0{,}04 = 2{,}0\text{ А}$$

   *Альтернативная проверка через энергию и индуктивность:*
   $$I_m = \sqrt{\frac{2W}{L}} = \sqrt{\frac{2 \cdot 5{,}0 \cdot 10^{-3}\text{ Дж}}{25 \cdot 10^{-3}\text{ Гн}}} = \sqrt{\frac{10{,}0 \cdot 10^{-3}}{25 \cdot 10^{-3}}} = \sqrt{\frac{10}{25}} = \sqrt{0{,}4} \approx 0{,}6325\text{ А}$$
   *Стоп, пересчитаем внимательно числовой коэффициент в проверке:*
   $\frac{2 \cdot 5 \cdot 10^{-3}}{25 \cdot 10^{-3}} = \frac{10}{25} = 0{,}4$. Корень из $0{,}4$ равен $0{,}632$ — где ошибка?
   Вернемся к формуле $I_m = U_m \sqrt{\frac{C}{L}}$:
   $\sqrt{\frac{4 \cdot 10^{-6}}{25 \cdot 10^{-3}}} = \sqrt{0{,}16 \cdot 10^{-3}}$? Нет!
   $4{,}0 \cdot 10^{-6} / 25 \cdot 10^{-3} = \frac{4}{25} \cdot 10^{-3} = 0{,}16 \cdot 10^{-3} = 16 \cdot 10^{-5}$.
   Извлечем корень: $\sqrt{16 \cdot 10^{-5}} = 4 \cdot 10^{-2{,}5}$ — неудобно. 
   Пересчитаем правильно подкоренное выражение:
   $\frac{4{,}0 \cdot 10^{-6}}{25 \cdot 10^{-3}} = \frac{4{,}0}{25} \cdot 10^{-3} = 0{,}16 \cdot 10^{-3} = 1{,}6 \cdot 10^{-4}$.
   Тогда корень из $1{,}6 \cdot 10^{-4}$ равен $\sqrt{16 \cdot 10^{-5}}$ — снова опечатка в степенях.
   Аккуратно:
   $\frac{4{,}0 \cdot 10^{-6}}{25 \cdot 10^{-3}} = \frac{4}{25} \cdot 10^{-6 - (-3)} = 0{,}16 \cdot 10^{-3} = 160 \cdot 10^{-6}$.
   Корень из $160 \cdot 10^{-6}$ равен $\sqrt{160} \cdot 10^{-3} \approx 12{,}65 \cdot 10^{-3} = 0{,}01265$.
   Умножаем на $50$: $50 \cdot 0{,}01265 = 0{,}6325$ А. 
   *Где ошибка в первом расчете тока?*
   $I_m = q_m \omega_0$. 
   Находим заряд: $q_m = C U_m = 4{,}0 \cdot 10^{-6} \cdot 50 = 200 \cdot 10^{-6}\text{ Кл} = 2 \cdot 10^{-4}\text{ Кл}$.
   Частота $\omega_0 = 316{,}2\text{ рад/с}$.
   Тогда $I_m = 2 \cdot 10^{-4} \cdot 316{,}2 = 632{,}4 \cdot 10^{-4} = 0{,}0632\text{ А}$?
   Снова ошибка в порядке чисел! Давайте пересчитаем $\omega_0$:
   $\omega_0 = \frac{1}{\sqrt{LC}} = \frac{1}{\sqrt{25 \cdot 10^{-3} \cdot 4 \cdot 10^{-6}}} = \frac{1}{\sqrt{100 \cdot 10^{-9}}} = \frac{1}{\sqrt{10^{-7}}}$ — корень из $10^{-7}$ это $\sqrt{10} \cdot 10^{-4} \approx 3{,}16 \cdot 10^{-4}$.
   Значит, $\omega_0 = \frac{1}{3{,}16 \cdot 10^{-4}} = \frac{10^4}{3{,}16} \approx 3162\text{ рад/с}$! 
   Проверим: $3162^2 = 10\,000\,000 = 10^7$, что обратно $10^{-7}$. Всё верно, $\omega_0 = 3162\text{ рад/с}$ (а не $316$).
   Тогда сила тока:
   $I_m = q_m \omega_0 = (2 \cdot 10^{-4}\text{ Кл}) \cdot (3162\text{ рад/с}) = 0{,}6324\text{ А}$.
   Пересчитаем энергию через ток:
   $W = \frac{L I_m^2}{2} = \frac{25 \cdot 10^{-3} \cdot (0{,}6324)^2}{2} = \frac{25 \cdot 10^{-3} \cdot 0{,}3999}{2} \approx \frac{25 \cdot 10^{-3} \cdot 0{,}4}{2} = \frac{10^{-2}}{2} = 0{,}005\text{ Дж} = 5{,}0\text{ мДж}$.
   Энергии сошлись идеально! Исправляем значение тока: $I_m \approx 0{,}63\text{ А}$.

**Проверка размерностей:**
- $\omega_0$: $\left[\frac{1}{\sqrt{\text{Гн} \cdot \text{Ф}}}\right] = \left[\frac{1}{\sqrt{(\text{В}\cdot\text{с}/\text{А}) \cdot (\text{А}\cdot\text{с}/\text{В})}}\right] = \left[\frac{1}{\sqrt{\text{с}^2}}\right] = \frac{1}{\text{с}} = \text{рад/с}$ — верно.
- $W$: $[\text{Ф} \cdot \text{В}^2] = [\text{Кл}/\text{В} \cdot \text{В}^2] = [\text{Кл} \cdot \text{В}] = [\text{А}\cdot\text{с} \cdot \text{Дж}/\text{Кл}] = \text{Дж}$ — верно.
- $I_m$: $[\text{А}]$ — верно.

**Ответ:** 
- Циклическая частота колебаний $\omega_0 \approx 3{,}2 \cdot 10^3\text{ рад/с}$ (или $3162\text{ рад/с}$);
- Максимальная сила тока в контуре $I_m \approx 0{,}63\text{ А}$;
- Полная энергия контура $W = 5{,}0\text{ мДж}$.

### 2. Затухающие электромагнитные колебания и реальный контур

В предыдущем разделе мы рассмотрели идеализированную модель колебательного контура, в котором активное сопротивление проводников и катушки принималось равным нулю. В таком контуре полная электромагнитная энергия сохраняется бесконечно долго, а колебания являются незатухающими гармоническими. В реальных физических системах проводники всегда обладают некоторым электрическим сопротивлением. Из-за этого часть энергии неизбежно преобразуется в теплоту (джоулевы потери) и рассеивается в окружающей среде. Такие колебания называются затухающими.

#### Учет активного сопротивления реального контура

Пусть реальный колебательный контур состоит из конденсатора емкостью $C$, катушки индуктивностью $L$ и последовательно соединенного резистора с активным сопротивлением $R$. Сопротивление $R$ включает в себя как сопротивление резистора, так и собственное активное сопротивление витков катушки индуктивности и соединительных проводов.

В любой момент времени в контуре протекает переменный электрический ток $I(t)$. На активном сопротивлении $R$ происходит падение напряжения, определяемое законом Ома: $U_R(t) = I(t) R$. На катушке индуктивности возникает ЭДС самоиндукции $\varepsilon_s(t) = -L \frac{dI}{dt}$, а на обкладках конденсатора напряжение равно $U_C(t) = \frac{q(t)}{C}$, где $q(t)$ — заряд на обкладках конденсатора в момент времени $t$.

#### Вывод дифференциального уравнения затухающих колебаний

Для получения уравнения, описывающего эволюцию заряда во времени, воспользуемся вторым законом Кирхгофа для замкнутого контура. Алгебраическая сумма падений напряжений на всех элементах цепи равна сумме ЭДС источников (в данном случае источников ЭДС нет, поэтому сумма равна нулю):

$$U_R + U_L + U_C = 0$$

Учтем, что падение напряжения на катушке складывается из напряжения самоиндукции и противодействует изменению тока. Точное выражение для падения напряжения на катушке индуктивности с учетом знака ЭДС самоиндукции записывается через равенство: напряжение внешнего источника уравновешивает ЭДС самоиндукции, то есть $U_L = -\varepsilon_s = L \frac{dI}{dt}$. 

Связь между силой тока в цепи и зарядом на конденсаторе выражается через производную заряда по времени. Положительное направление тока выбрано так, что уменьшение заряда конденсатора соответствует положительному току:

$$I(t) = -\frac{dq}{dt}$$

Тогда сила тока через производную заряда записывается как $I = \dot{q}$, а первая производная от тока дает вторую производную заряда: $\frac{dI}{dt} = \frac{d^2q}{dt^2}$. Подставим выражения для напряжений на элементах ($U_R = I R = R \frac{dq}{dt}$, $U_L = L \frac{d^2q}{dt^2}$ и $U_C = \frac{q}{C}$) в уравнение второго закона Кирхгофа:

$$R \frac{dq}{dt} + L \frac{d^2q}{dt^2} + \frac{1}{C}q = 0$$

Перепишем полученное выражение, расположив слагаемые в порядке убывания производных и разделив обе части на индуктивность $L$ (при условии, что $L \neq 0$):

$$\frac{d^2q}{dt^2} + \frac{R}{L} \frac{dq}{dt} + \frac{1}{LC} q = 0$$

Это однородное линейное дифференциальное уравнение второго порядка с постоянными коэффициентами, описывающее свободные затухающие электромагнитные колебания в реальном контуре.

> **Определение.** Дифференциальное уравнение затухающих электромагнитных колебаний — это уравнение вида $\frac{d^2q}{dt^2} + 2\beta \frac{dq}{dt} + \omega_0^2 q = 0$, где введено обозначение для коэффициента затухания $\beta = \frac{R}{2L}$ и квадрата собственной частоты идеального контура $\omega_0^2 = \frac{1}{LC}$.

#### Параметры затухающих колебаний

Введем величину, характеризующую быстроту уменьшения амплитуды колебаний со временем — **коэффициент затухания** $\beta$:

$$\beta = \frac{R}{2L}$$

*   **Обозначения:** $\beta$ — коэффициент затухания, единица измерения в СИ: с$^{-1}$ (обратные секунды); $R$ — активное сопротивление контура, Ом; $L$ — индуктивность катушки, Гн.
*   **Физический смысл:** показывает, с какой скоростью уменьшается амплитуда колебаний из-за потерь энергии на активном сопротивлении. Чем больше сопротивление $R$ или меньше индуктивность $L$, тем быстрее затухают колебания.

Решением дифференциального уравнения при условии, что сопротивление контура относительно мало ($\beta < \omega_0$), является функция гармонического колебания с экспоненциально убывающей амплитудой:

$$q(t) = q_m e^{-\beta t} \cos(\omega t + \varphi_0)$$

где $q_m$ — начальная амплитуда заряда (при $t = 0$), $\varphi_0$ — начальная фаза колебаний, а $\omega$ — **циклическая частота затухающих колебаний**.

Частота затухающих колебаний $\omega$ отличается от собственной частоты идеального контура $\omega_0$ и определяется выражением:

$$\omega = \sqrt{\omega_0^2 - \beta^2} = \sqrt{\frac{1}{LC} - \left(\frac{R}{2L}\right)^2}$$

*   **Обозначения:** $\omega$ — циклическая частота затухающих колебаний, рад/с; $\omega_0 = \frac{1}{\sqrt{LC}}$ — собственная циклическая частота идеального контура, рад/с; $\beta$ — коэффициент затухания, с$^{-1}$.
*   **Условия применимости:** формула применима, когда подкоренное выражение строго положительно: $\omega_0^2 > \beta^2$, то есть $R < 2\sqrt{\frac{L}{C}}$. Если это условие нарушается ($R \ge 2\sqrt{\frac{L}{C}}$), периодические колебания не возникают вовсе, и происходит апериодический разряд конденсатора (система возвращается в положение равновесия без колебаний).

Период затухающих колебаний $T$ связан с циклической частотой $\omega$ стандартным соотношением:

$$T = \frac{2\pi}{\omega} = \frac{2\pi}{\sqrt{\omega_0^2 - \beta^2}}$$

#### График затухающих колебаний и огибающая экспонента

График зависимости заряда $q(t)$ от времени $t$ представляет собой кривую, заключенную между двумя симметричными линиями, которые называются **огибающими экспонентами**.

```
  q(t)
    ^
q_m |       /\          /\          /\        (Огибающая: +q_m * e^(-βt))
    |      /  \        /  \        /  \
    | ----/----\------/----\------/----\-------> t
    |    /      \    /      \    /      \
    |   /        \  /        \  /        \      (Огибающая: -q_m * e^(-βt))
    v  v          vv          vv          v
```

Множитель $q_m e^{-\beta t}$ играет роль меняющейся во времени амплитуды колебаний: $A(t) = q_m e^{-\beta t}$. Сами колебания происходят с периодом $T$ под знаком косинуса. За время, равное одному периоду $T$, амплитуда колебаний уменьшается в $e^{\beta T}$ раз.

#### Логарифмический декремент затухания

Для количественной оценки уменьшения амплитуды за один период колебаний используют безразмерную величину — логарифмический декремент затухания.

> **Определение.** Логарифмический декремент затухания $\lambda$ — это натуральный логарифм отношения двух последовательных максимальных значений физической величины (например, заряда), разделенных интервалом времени в один период:
> $$\lambda = \ln \frac{q(t)}{q(t+T)}$$

Подставим закон изменения амплитуды в определение:

$$\lambda = \ln \frac{q_m e^{-\beta t}}{q_m e^{-\beta (t+T)}} = \ln \frac{e^{-\beta t}}{e^{-\beta t - \beta T}} = \ln \left( e^{\beta T} \right) = \beta T$$

*   **Обозначения:** $\lambda$ — логарифмический декремент затухания, безразмерная величина; $\beta$ — коэффициент затухания, с$^{-1}$; $T$ — период затухающих колебаний, с.
*   **Связь с параметрами контура:** выразив период через частоту, получаем $\lambda = \frac{R}{2L} \frac{2\pi}{\omega} = \frac{\pi R}{L \omega}$.

#### Добротность колебательного контура

Другой важнейшей характеристикой реального колебательного контура, особенно часто используемой в радиотехнике и электронике, является добротность.

> **Определение.** Добротность колебательного контура $Q$ — это физическая величина, характеризующая энергетические потери в контуре и пропорциональная отношению запасенной полной энергии к энергии, теряемой за один радиан периода:
> $$Q = 2\pi \frac{W(t)}{-\Delta W(t)}$$

Энергия контура в момент времени $t$ пропорциональна квадрату амплитуды: $W(t) \propto A^2(t)$. За период $T$ амплитуда уменьшается по закону $e^{-\beta T}$, следовательно, энергия уменьшается. 

Точное выражение для добротности через параметры элементов контура выводится следующим образом:

$$Q = \pi \frac{1}{\lambda} = \frac{\pi}{\beta T} = \frac{\omega}{2\beta}$$

Если затухание мало ($\beta \ll \omega_0$), то $\omega \approx \omega_0 = \frac{1}{\sqrt{LC}}$, а коэффициент затухания $\beta = \frac{R}{2L}$. Подставим их в формулу добротности:

$$Q \approx \frac{\omega_0}{2\beta} = \frac{\frac{1}{\sqrt{LC}}}{2 \frac{R}{2L}} = \frac{1}{R} \sqrt{\frac{L}{C}}$$

*   **Обозначения:** $Q$ — добротность контура, безразмерная величина; $R$ — активное сопротивление, Ом; $L$ — индуктивность, Гн; $C$ — емкость, Ф.
*   **Физический смысл:** добротность показывает, во сколько раз запасенная в контуре полная энергия больше потерь энергии за время одного полного колебания, деленное на $2\pi$. Высокая добротность ($Q \gg 1$) означает, что контур совершает много колебаний до полного затухания, а резонансные свойства такого контура выражены очень ярко.

### Разобранный пример

**Условие:** Реальный колебательный контур имеет индуктивность $L = 10$ мГн, емкость $C = 1$ мкФ и активное сопротивление $R = 2$ Ом. Найти период затухающих колебаний $T$, коэффициент затухания $\beta$ и добротность контура $Q$.

**Дано:**
*   $L = 10 \text{ мГн} = 10 \cdot 10^{-3} \text{ Гн} = 0{,}01 \text{ Гн}$
*   $C = 1 \text{ мкФ} = 1 \cdot 10^{-6} \text{ Ф}$
*   $R = 2 \text{ Ом}$
*   Найти: $\beta$ — ?, $T$ — ?, $Q$ — ?

**Рисунок (схема) цепи словами:**
Электрическая схема представляет собой последовательное соединение катушки индуктивности с индуктивностью $L$ и внутренним активным сопротивлением $R$ (обозначается резистором, включенным последовательно с катушкой) и конденсатора емкостью $C$, образующие замкнутый контур без внешних источников питания.

**Ход рассуждений (почему делаем именно так):**
1.  Сначала найдем коэффициент затухания $\beta$ по известным формулам через сопротивление и индуктивность: $\beta = \frac{R}{2L}$.
2.  Затем вычислим собственную циклическую частоту идеального контура $\omega_0 = \frac{1}{\sqrt{LC}}$ и проверим условие малости затухания: $\omega_0 > \beta$.
3.  Найдем частоту затухающих колебаний $\omega = \sqrt{\omega_0^2 - \beta^2}$ и через нее вычислим период затухающих колебаний $T = \frac{2\pi}{\omega}$.
4.  Добротность контура рассчитаем по формуле через параметры $R$, $L$ и $C$, так как затухание в данном случае мало и приближенная формула дает высокую точность.

**Решение в общем виде:**
1. Коэффициент затухания:
$$\beta = \frac{R}{2L}$$

2. Собственная циклическая частота идеального контура:
$$\omega_0 = \frac{1}{\sqrt{LC}}$$

3. Циклическая частота затухающих колебаний:
$$\omega = \sqrt{\frac{1}{LC} - \left(\frac{R}{2L}\right)^2} = \sqrt{\omega_0^2 - \beta^2}$$

4. Период затухающих колебаний:
$$T = \frac{2\pi}{\omega} = \frac{2\pi}{\sqrt{\frac{1}{LC} - \left(\frac{R}{2L}\right)^2}}$$

5. Добротность контура:
$$Q = \frac{1}{R} \sqrt{\frac{L}{C}}$$

**Подстановка числовых значений и вычисление:**
1. Вычисляем коэффициент затухания:
$$\beta = \frac{2}{2 \cdot 0{,}01} = \frac{2}{0{,}02} = 100 \text{ с}^{-1}$$

2. Вычисляем собственную частоту $\omega_0$:
$$\omega_0 = \frac{1}{\sqrt{0{,}01 \cdot 1 \cdot 10^{-6}}} = \frac{1}{\sqrt{10^{-2} \cdot 10^{-6}}} = \frac{1}{\sqrt{10^{-8}}} = \frac{1}{10^{-4}} = 10000 \text{ рад/с}$$
Проверяем условие малости затухания: $\beta = 100 \text{ с}^{-1} \ll \omega_0 = 10000 \text{ рад/с}$ (условие выполнено отлично).

3. Вычисляем частоту затухающих колебаний $\omega$:
$$\omega = \sqrt{(10000)^2 - (100)^2} = \sqrt{100000000 - 10000} = \sqrt{99990000} \approx 9999{,}5 \text{ рад/с}$$
Поскольку разница крайне мала ($\omega \approx \omega_0$), периодом колебаний можно считать величину, практически равную периоду идеального контура:
$$T = \frac{2 \cdot 3{,}14159}{9999{,}5} \approx 0{,}000628 \text{ с} = 0{,}628 \text{ мс}$$

4. Вычисляем добротность $Q$:
$$Q = \frac{1}{2} \sqrt{\frac{0{,}01}{1 \cdot 10^{-6}}} = 0{,}5 \sqrt{10000} = 0{,}5 \cdot 100 = 50$$

**Проверка размерностей:**
*   $[\beta] = \left[\frac{\text{Ом}}{\text{Гн}}\right] = \left[\frac{\text{В} \cdot \text{с}}{\text{А} \cdot (\text{В} \cdot \text{с} / \text{А})}\right] = \text{с}^{-1}$. Совпадает.
*   $[T] = [\text{с}]$. Совпадает.
*   $[Q] = \left[\frac{1}{\text{Ом}} \sqrt{\frac{\text{Гн}}{\text{Ф}}}\right] = \left[\frac{1}{\text{Ом}} \sqrt{\frac{\text{В} \cdot \text{с} / \text{А}}{\text{Кл} / \text{В}}}\right] = \left[\frac{1}{\text{Ом}} \sqrt{\frac{\text{В}^2 \cdot \text{с}^2}{\text{А} \cdot \text{Кл}}}\right] = \left[\frac{1}{\text{Ом}} \sqrt{\frac{\text{В}^2 \cdot \text{с}^2}{\text{А} \cdot (\text{А} \cdot \text{с})}}\right] = \left[\frac{1}{\text{Ом}} \sqrt{\frac{\text{В}^2 \cdot \text{с}^2}{\text{А}^2 \cdot \text{с}}}\right] \dots$ проще через Ом $\cdot$ Фарада и Гн: размерность безразмерная, так как отношение энергий. Совпадает.

Правдоподобность: добротность равна 50, что является типичным значением для реальных колебательных контуров средних радиочастот (от единиц до сотен). Коэффициент затухания мал по сравнению с частотой, колебания развиваются стабильно.

**Ответ:** Коэффициент затухания $\beta = 100 \text{ с}^{-1}$; период затухающих колебаний $T \approx 0{,}628 \text{ мс}$; добротность контура $Q = 50$.

## 3. Переменный электрический ток. Элементы цепи переменного тока

### 3. Переменный электрический ток. Элементы цепи переменного тока

#### Понятие квазистационарных токов и синусоидального переменного тока

В предыдущих разделах мы рассматривали свободные электромагнитные колебания в контуре, которые со временем затухают из-за потерь энергии на активном сопротивлении. Для поддержания непрерывных электромагнитных колебаний в цепь необходимо включить источник ЭДС, которая периодически изменяется со временем. Такой ток называется **переменным электрическим током**.

> **Определение.** **Квазистационарными токами** называют такие изменяющиеся во времени электрические токи, для которых мгновенные значения силы тока в любых сечениях замкнутой неразветвленной цепи практически одинаковы в каждый момент времени, а электромагнитное поле успевает распространиться по всей цепи практически мгновенно.

Условие квазистационарности выполняется, если характерное время изменения тока (например, период колебаний $T$) много больше времени распространения электромагнитного возмущения вдоль цепи длиной $l$: 

$$T \gg \frac{l}{c}$$

где $c$ — скорость света в вакууме. В лабораторных условиях и энергетических сетях промышленных частот это условие выполняется с огромным запасом.

Наиболее важным для практики является гармонический (синусоидальный) переменный ток, сила которого изменяется со временем по закону синуса или косинуса:

$$I(t) = I_m \sin(\omega t + \varphi_i)$$

Аналогично, напряжение на различных участках цепи изменяется по гармоническому закону:

$$U(t) = U_m \sin(\omega t + \varphi_u)$$

Разберем обозначения и единицы измерения для формулы силы тока:
- $I(t)$ — мгновенное значение силы тока в амперах [А];
- $I_m$ — амплитуда силы тока (максимальное отклонение силы тока от нуля) в амперах [А];
- $\omega$ — циклическая частота переменного тока в радианах в секунду [рад/с];
- $t$ — время в секундах [с];
- $\varphi_i$ — начальная фаза колебаний силы тока в радианах [рад].

Циклическая частота связана с периодом $T$ и линейной частотой $\nu$ соотношением:

$$\omega = \frac{2\pi}{T} = 2\pi\nu$$

В промышленной энергетике (например, в стандартной электрической сети) линейная частота составляет $\nu = 50$ Гц, следовательно, циклическая частота равна $\omega = 2 \cdot \pi \cdot 50 \approx 314$ рад/с.

### Действующие (эффективные) значения силы тока и напряжения

Приборы тепловой системы (например, амперметры и вольтметры переменного тока) измеряют не мгновенные значения, которые быстро меняются со знаком плюс и минус, а некоторое среднее энергетическое действие тока. Поскольку среднее за период значение синусоидального тока равно нулю ($\langle I(t) \rangle = 0$), для оценки теплового действия вводят среднеквадратичное (действующее) значение.

> **Определение.** **Действующим (эффективным) значением переменного тока** называется физическая величина, равная такому значению постоянного тока, который при прохождении через резистор за время одного периода выделяет такое же количество теплоты, что и переменный ток.

Выведем связь между действующим и амплитудным значениями силы тока. Количество теплоты $dQ$, выделяющееся в резисторе сопротивлением $R$ за бесконечно малой промежуток времени $dt$, согласно закону Джоуля–Ленца, равно:

$$dQ = I^2(t) R dt$$

Подставим закон изменения силы тока:

$$dQ = I_m^2 \sin^2(\omega t) R dt$$

Проинтегрируем это выражение за один период колебаний $T = \frac{2\pi}{\omega}$, чтобы найти полную теплоту $Q$:

$$Q = \int_{0}^{T} I_m^2 \sin^2(\omega t) R dt = I_m^2 R \int_{0}^{T} \sin^2(\omega t) dt$$

Из тригонометрии известно, что $\sin^2(\omega t) = \frac{1 - \cos(2\omega t)}{2}$. Интеграл от косинуса за целый период равен нулю, поэтому среднее значение квадрата синуса за период равно $\frac{1}{2}$. Получаем:

$$Q = I_m^2 R \frac{T}{2}$$

С другой стороны, для постоянного тока силы $I$ теплота за тот же период $T$ равна:

$$Q = I^2 R T$$

Приравняем оба выражения для теплоты:

$$I^2 R T = \frac{I_m^2 R T}{2} \implies I^2 = \frac{I_m^2}{2}$$

Извлекая квадратный корень, получаем формулу для действующего значения силы тока:

$$I = \frac{I_m}{\sqrt{2}} \approx 0{,}707 I_m$$

Аналогичным образом для напряжения:

$$U = \frac{U_m}{\sqrt{2}} \approx 0{,}707 U_m$$

Разберем обозначения:
- $I$ — действующее значение силы тока в амперах [А];
- $U$ — действующее значение напряжения в вольтах [В].

Когда мы говорим, что в розетке напряжение 220 В, это означает именно действующее значение $U = 220$ В. Амплитудное же значение напряжения в этой сети составляет $U_m = U \sqrt{2} = 220 \cdot 1{,}414 \approx 311$ В.

### Цепь переменного тока с активным сопротивлением R

Рассмотрим простейшую цепь переменного тока, содержащую только резистор с активным сопротивлением $R$ (например, электрическую плиту или лампу накаливания). Пусть к концам резистора приложено переменное напряжение:

$$U(t) = U_m \sin(\omega t)$$

Согласно закону Ома для мгновенных значений, сила тока в любой момент времени равна:

$$I(t) = \frac{U(t)}{R} = \frac{U_m}{R} \sin(\omega t)$$

Максимальное значение тока (амплитуда) достигается при максимальном напряжении:

$$I_m = \frac{U_m}{R}$$

Следовательно, закон изменения тока можно записать как:

$$I(t) = I_m \sin(\omega t)$$

Сравним выражения для напряжения и силы тока. Аргументы синуса в обоих выражениях абсолютно одинаковы ($\omega t$). Это означает, что колебания силы тока и напряжения в цепи с чистым активным сопротивлением происходят **синфазно** — они одновременно достигают максимумов, минимумов и обращаются в нуль. Сдвиг фаз между током и напряжением равен нулю ($\varphi = 0$).

> **ASCII-схема (диаграмма колебаний):**
> ```text
> U(t), I(t)
>  ^          /--\          /--\     U(t) (напряжение)
>  |         /    \        /    \    I(t) (ток)
>  |        /      \      /      \
>  +-------/--------\----/--------\-----> t
>  |      /          \  /          \
>  |     /            \/            \
> ```

Мгновенная мощность переменного тока $P(t)$ в резисторе:

$$P(t) = U(t) I(t) = U_m I_m \sin^2(\omega t)$$

Средняя за период мощность $\langle P \rangle$, которая расходуется на нагревание резистора (выделение джоулева тепла):

$$P = \langle P \rangle = U_m I_m \langle \sin^2(\omega t) \rangle = U_m I_m \frac{1}{2} = \left(\frac{U_m}{\sqrt{2}}\right) \left(\frac{I_m}{\sqrt{2}}\right) = U I$$

Таким образом, средняя активная мощность в цепи с сопротивлением $R$ вычисляется через действующие значения так же, как и для постоянного тока:

$$P = I^2 R = \frac{U^2}{R} = U I$$

### Цепь переменного тока с индуктивностью L

Пусть цепь переменного тока содержит идеальную катушку с индуктивностью $L$ и нулевым активным сопротивлением. Под действием переменного тока в катушке возникает переменный магнитный поток, порождающий ЭДС самоиндукции:

$$\varepsilon_s = -L \frac{dI}{dt}$$

Согласно второму закону Кирхгофа для этого участка, внешнее приложенное напряжение $U(t)$ полностью уравновешивается ЭДС самоиндукции:

$$U(t) + \varepsilon_s = 0 \implies U(t) = L \frac{dI}{dt}$$

Пусть сила тока в катушке изменяется по гармоническому закону:

$$I(t) = I_m \sin(\omega t)$$

Найдем напряжение, продифференцировав ток по времени:

$$U(t) = L \frac{d}{dt} [I_m \sin(\omega t)] = L I_m \omega \cos(\omega t)$$

Используя тригонометрическое соотношение $\cos(\alpha) = \sin\left(\alpha + \frac{\pi}{2}\right)$, запишем напряжение в виде:

$$U(t) = U_m \sin\left(\omega t + \frac{\pi}{2}\right)$$

где амплитуда напряжения равна:

$$U_m = I_m \omega L$$

Сравнивая фазы, видим, что в цепи с чистой индуктивностью **напряжение опережает ток по фазе на угол $\frac{\pi}{2}$** (90 градусов), или, что то же самое, ток отстает от напряжения на $\frac{\pi}{2}$.

> **Определение.** **Индуктивным сопротивлением** $X_L$ называется сопротивление катушки переменному току, обусловленное действием ЭДС самоиндукции.

Выразим индуктивное сопротивление из закона Ома для амплитудных значений ($I_m = \frac{U_m}{X_L}$):

$$X_L = \omega L = 2\pi\nu L$$

Разберем величины и единицы:
- $X_L$ — индуктивное сопротивление в омах [Ом];
- $\omega$ — циклическая частота в [рад/с];
- $\nu$ — линейная частота в герцах [Гц];
- $L$ — индуктивность катушки в генри [Гн].

Индуктивное сопротивление прямо пропорционально частоте тока. Для постоянного тока ($\nu = 0$) индуктивное сопротивление равно нулю ($X_L = 0$) — катушка для постоянного тока ведет себя как обычный проводник с ничтожно малым сопротивлением. На очень высоких частотах индуктивное сопротивление становится огромным, преграждая путь переменному току.

### Цепь переменного тока с емкостью C

Пусть цепь переменного тока содержит плоский конденсатор емкостью $C$, а сопротивление проводов равно нулю. Заряд конденсатора $q(t)$ и напряжение на нем связаны соотношением:

$$U(t) = \frac{q(t)}{C}$$

Сила тока в цепи равна скорости изменения заряда ($I(t) = \frac{dq}{dt}$). Пусть напряжение на конденсаторе изменяется по закону:

$$U(t) = U_m \sin(\omega t)$$

Тогда заряд конденсатора равен:

$$q(t) = C U(t) = C U_m \sin(\omega t)$$

Находим силу тока путем дифференцирования заряда по времени:

$$I(t) = \frac{dq}{dt} = \frac{d}{dt} [C U_m \sin(\omega t)] = C U_m \omega \cos(\omega t)$$

Используя тригонометрическое тождество $\cos(\alpha) = \sin\left(\alpha + \frac{\pi}{2}\right)$, запишем:

$$I(t) = I_m \sin\left(\omega t + \frac{\pi}{2}\right)$$

где амплитуда силы тока равна:

$$I_m = U_m \omega C = \frac{U_m}{\frac{1}{\omega C}}$$

Отсюда амплитуда напряжения выражается как:

$$U_m = I_m \left(\frac{1}{\omega C}\right)$$

Анализируя начальные фазы, видим, что в цепи с чистой емкостью **ток опережает напряжение по фазе на угол $\frac{\pi}{2}$** (90 градусов), а напряжение отстает от тока на $\frac{\pi}{2}$.

> **Определение.** **Емкостным сопротивлением** $X_C$ называется сопротивление конденсатора переменному электрическому току.

Формула емкостного сопротивления:

$$X_C = \frac{1}{\omega C} = \frac{1}{2\pi\nu C}$$

Разберем величины и единицы:
- $X_C$ — емкостное сопротивление в омах [Ом];
- $C$ — электроемкость конденсатора в фарадах [Ф].

Емкостное сопротивление обратно пропорционально частоте тока. Для постоянного тока ($\nu = 0$) частота равна нулю, а емкостное сопротивление стремится к бесконечности ($X_C \to \infty$). Конденсатор является непреодолимым препятствием для постоянного тока (разрыв цепи). С ростом частоты емкостное сопротивление уменьшается.

---

### Закон Ома для участка цепи с R, L, C. Полное сопротивление (импеданс)

Рассмотрим последовательное соединение элементов $R$, $L$ и $C$ в цепи переменного тока. Пусть через все элементы протекает общий переменный ток:

$$I(t) = I_m \sin(\omega t)$$

На каждом из элементов возникает свое напряжение, имеющее свой сдвиг фаз относительно тока:
1. На активном сопротивлении $R$: напряжение $U_R(t)$ совпадает по фазе с током, амплитуда $U_{Rm} = I_m R$.
2. На индуктивности $L$: напряжение $U_L(t)$ опережает ток на $\frac{\pi}{2}$, амплитуда $U_{Lm} = I_m X_L$.
3. На емкости $C$: напряжение $U_C(t)$ отстает от тока на $\frac{\pi}{2}$, амплитуда $U_{Cm} = I_m X_C$.

Согласно второму закону Кирхгофа, мгновенное значение общего приложенного напряжения $U(t)$ равно алгебраической сумме мгновенных напряжений на участках:

$$U(t) = U_R(t) + U_L(t) + U_C(t)$$

Поскольку напряжения имеют разные фазы, складывать их простым арифметическим суммированием амплитуд нельзя. Для сложения гармонических колебаний одинаковой частоты используют **метод векторных диаграмм**. Амплитуды напряжений изображаются векторами на плоскости, причем за опорный вектор принимается направление вектора силы тока $I_m$.

> **ASCII-схема (векторная диаграмма напряжений):**
> ```text
>           ^ U_L (вверх, опережает ток на 90°)
>           |   
>           |      / U_m (полное напряжение)
>           |     /| 
>    U_L-U_C|    / | 
>           |   /  | 
>           |  /   | 
>           +-----------------> I (направлен горизонтально вправо)
>           |  \   |
>           |   \  | U_R (совпадает с током)
>           |    \ 
>           |     \ U_C (вниз, отстает от тока на 90°)
>           v
> ```

Из прямоугольного треугольника напряжений (где катеты равны $U_{Rm}$ и $(U_{Lm} - U_{Cm})$, а гипотенуза равна общей амплитуде напряжения $U_m$) по теореме Пифагора запишем:

$$U_m = \sqrt{U_{Rm}^2 + (U_{Lm} - U_{Cm})^2}$$

Подставим выражения через амплитуды тока и сопротивления ($U_{Rm} = I_m R$, $U_{Lm} = I_m X_L$, $U_{Cm} = I_m X_C$):

$$U_m = \sqrt{(I_m R)^2 + (I_m X_L - I_m X_C)^2} = I_m \sqrt{R^2 + (X_L - X_C)^2}$$

> **Определение.** **Полным сопротивлением (импедансом)** $Z$ цепи переменного тока с последовательным соединением $R, L, C$ называется физическая величина, равная отношению амплитуды общего напряжения к амплитуде силы тока.

Запишем формулу для импеданса:

$$Z = \frac{U_m}{I_m} = \sqrt{R^2 + (X_L - X_C)^2} = \sqrt{R^2 + \left(\omega L - \frac{1}{\omega C}\right)^2}$$

Разберем обозначения и единицы:
- $Z$ — полное сопротивление цепи (импеданс) в омах [Ом];
- $R$ — активное сопротивление в омах [Ом];
- $X_L$ — индуктивное сопротивление в омах [Ом];
- $X_C$ — емкостное сопротивление в омах [Ом].

Теперь запишем **закон Ома для участка цепи переменного тока**:

$$I = \frac{U}{Z} \quad \text{или} \quad I_m = \frac{U_m}{Z}$$

где $U$ и $I$ — действующие значения напряжения и тока.

---

### Сдвиг фаз между током и напряжением

В общем случае цепи с последовательным соединением $R, L, C$ между общим напряжением и силой тока возникает сдвиг фаз $\varphi$. Из треугольника напряжений (или треугольника сопротивлений) определяем тангенс этого угла:

$$\operatorname{tg}\varphi = \frac{U_{Lm} - U_{Cm}}{U_{Rm}} = \frac{I_m X_L - I_m X_C}{I_m R} = \frac{X_L - X_C}{R} = \frac{\omega L - \frac{1}{\omega C}}{R}$$

Анализ знака сдвига фаз $\varphi$:
1. Если $X_L > X_C$ ($\omega L > \frac{1}{\omega C}$), то $\operatorname{tg}\varphi > 0$, угол $\varphi > 0$. В цепи преобладает индуктивный характер, напряжение опережает ток по фазе.
2. Если $X_L < X_C$ ($\omega L < \frac{1}{\omega C}$), то $\operatorname{tg}\varphi < 0$, угол $\varphi < 0$. В цепи преобладает емкостный характер, напряжение отстает от тока по фазе (ток опережает напряжение).
3. Если $X_L = X_C$, то $\operatorname{tg}\varphi = 0$, $\varphi = 0$. Наступает явление резонанса напряжений, полное сопротивление цепи минимально и равно активному сопротивлению ($Z = R$).

### Разбор примера

> **Условие:** К источнику переменного тока с действующим напряжением $U = 120$ В и частотой $\nu = 50$ Гц последовательно подключены резистор сопротивлением $R = 30$ Ом, катушка с индуктивностью $L = 0{,}2$ Гн и конденсатор емкостью $C = 50$ мкФ. Найти полное сопротивление цепи $Z$, действующее значение силы тока $I$ и сдвиг фаз $\varphi$ между током и напряжением.

#### Дано:
- $U = 120$ В
- $\nu = 50$ Гц
- $R = 30$ Ом
- $L = 0{,}2$ Гн
- $C = 50$ мкФ $= 50 \cdot 10^{-6}$ Ф

**Найти:** $Z$, $I$, $\varphi$ — ?

#### Ход рассуждений:
1. Для нахождения полного сопротивления цепи $Z$ необходимо предварительно вычислить циклическую частоту $\omega$, а также индуктивное ($X_L$) и емкостное ($X_C$) сопротивления.
2. Циклическая частота вычисляется через линейную частоту по формуле $\omega = 2\pi\nu$.
3. Индуктивное сопротивление находится как $X_L = \omega L$, а емкостное — как $X_C = \frac{1}{\omega C}$.
4. Полное сопротивление цепи находим по формуле импеданса: $Z = \sqrt{R^2 + (X_L - X_C)^2}$.
5. Действующее значение силы тока определяется по закону Ома для цепи переменного тока: $I = \frac{U}{Z}$.
6. Сдвиг фаз $\varphi$ находим через тангенс: $\operatorname{tg}\varphi = \frac{X_L - X_C}{R}$.

#### Решение в общем виде:
1. Циклическая частота:
   $$\omega = 2\pi\nu$$
2. Индуктивное сопротивление:
   $$X_L = 2\pi\nu L$$
3. Емкостное сопротивление:
   $$X_C = \frac{1}{2\pi\nu C}$$
4. Полное сопротивление (импеданс):
   $$Z = \sqrt{R^2 + \left(2\pi\nu L - \frac{1}{2\pi\nu C}\right)^2}$$
5. Действующий ток:
   $$I = \frac{U}{\sqrt{R^2 + \left(2\pi\nu L - \frac{1}{2\pi\nu C}\right)^2}}$$
6. Сдвиг фаз:
   $$\varphi = \operatorname{arctg}\left(\frac{2\pi\nu L - \frac{1}{2\pi\nu C}}{R}\right)$$

#### Подстановка числовых значений и вычисление:
1. Вычисляем циклическую частоту ($\pi \approx 3{,}1416$):
   $$\omega = 2 \cdot 3{,}1416 \cdot 50 = 314{,}16 \text{ рад/с}$$
2. Вычисляем индуктивное сопротивление:
   $$X_L = 314{,}16 \cdot 0{,}2 = 62{,}83 \text{ Ом}$$
3. Вычисляем емкостное сопротивление:
   $$X_C = \frac{1}{314{,}16 \cdot 50 \cdot 10^{-6}} = \frac{1}{0{,}015708} \approx 63{,}66 \text{ Ом}$$
4. Вычисляем разность реактивных сопротивлений:
   $$X_L - X_C = 62{,}83 - 63{,}66 = -0{,}83 \text{ Ом}$$
5. Вычисляем полное сопротивление цепи $Z$:
   $$Z = \sqrt{30^2 + (-0{,}83)^2} = \sqrt{900 + 0{,}6889} = \sqrt{900{,}6889} \approx 30{,}01 \text{ Ом}$$
6. Вычисляем действующее значение силы тока $I$:
   $$I = \frac{120}{30{,}01} \approx 4{,}00 \text{ А}$$
7. Вычисляем тангенс сдвига фаз:
   $$\operatorname{tg}\varphi = \frac{-0{,}83}{30} \approx -0{,}0277$$
8. Находим угол сдвига фаз:
   $$\varphi = \operatorname{arctg}(-0{,}0277) \approx -0{,}0277 \text{ рад} \approx -1{,}59^{\circ}$$

#### Проверка размерности и правдоподобия:
- Размерность сопротивлений: $[\text{Ом}]$. Размерность тока: $[\text{В} / \text{Ом}] = [\text{А}]$. Все единицы соответствуют системе СИ.
- Реактивные сопротивления катушки ($62{,}83$ Ом) и конденсатора ($63{,}66$ Ом) почти компенсируют друг друга (цепь близка к резонансу). Поэтому полное сопротивление $Z \approx 30{,}01$ Ом практически совпадает с активным сопротивлением $R = 30$ Ом, а ток составляет ровно 4 А, что является физически правдоподобным. Отрицательный знак сдвига фаз указывает на преобладание емкостного характера цепи ($X_C > X_L$).

> **Ответ:** Полное сопротивление цепи $Z = 30{,}0$ Ом; действующая сила тока $I = 4{,}00$ А; сдвиг фаз $\varphi \approx -1{,}59^{\circ}$ (ток незначительно опережает напряжение по фазе).

## 4. Резонанс в электрических цепях. Мощность переменного тока

### Явление резонанса в электрических цепях

В предыдущем разделе мы выяснили, что в цепи переменного тока, содержащей резистор с активным сопротивлением $R$, катушку с индуктивностью $L$ и конденсатор с емкостью $C$, полное сопротивление цепи (импеданс) определяется выражением:

$$Z = \sqrt{R^2 + (X_L - X_C)^2}$$

где $X_L = \omega L$ — индуктивное сопротивление, а $X_C = \frac{1}{\omega C}$ — емкостное сопротивление. Характер этой зависимости от круговой частоты $\omega$ внешнего генератора приводит к замечательному и практически важному явлению, называемому **резонансом напряжений**.

> **Определение.** Резонансом напряжений в последовательном колебательном контуре называется явление резкого возрастания амплитуды (или действующего значения) силы тока в цепи, которое возникает при совпадении частоты внешнего гармонического напряжения с собственной частотой колебательного контура.

Рассмотрим, почему это происходит. Согласно закону Ома для полной цепи переменного тока, действующее значение силы тока равно:

$$I = \frac{U}{Z} = \frac{U}{\sqrt{R^2 + \left(\omega L - \frac{1}{\omega C}\right)^2}}$$

Если изменять частоту $\omega$ источника переменного напряжения $U$, то при некотором значении частоты индуктивное и емкостное сопротивления могут стать равными друг другу. 

> **Определение.** Условием возникновения резонанса напряжений является равенство индуктивного и емкостного сопротивлений в цепи:
> $$X_L = X_C$$

Подставим выражения для сопротивлений:

$$\omega_{\text{рез}} L = \frac{1}{\omega_{\text{рез}} C}$$

Выразим отсюда резонансную циркулярную частоту $\omega_{\text{рез}}$:

$$\omega_{\text{рез}}^2 = \frac{1}{LC} \implies \omega_{\text{рез}} = \frac{1}{\sqrt{LC}}$$

Как мы знаем из первого раздела нашего курса, величина $\omega_0 = \frac{1}{\sqrt{LC}}$ представляет собой собственную циклическую частоту свободных колебаний в идеальном контуре. Таким образом, резонанс наступает тогда, когда частота вынуждающей внешней силы совпадает с собственной частотой колебательной системы:

$$\omega_{\text{рез}} = \omega_0$$

### Амплитудные и фазовые характеристики при резонансе

Что происходит с цепью при выполнении условия резонанса? 

1. Реактивная составляющая полного сопротивления обращается в нуль:
   $$\omega_{\text{рез}} L - \frac{1}{\omega_{\text{рез}} C} = 0$$
2. Полное сопротивление цепи (импеданс) $Z$ достигает своего минимального и чисто активного значения:
   $$Z_{\min} = \sqrt{R^2 + 0} = R$$
3. Действующее (и максимальное) значение силы тока в цепи достигает своего наибольшего значения:
   $$I_{\max} = \frac{U}{R}$$

Если активное сопротивление цепи $R$ пренебрежимо мало (идеальные провода и катушка), то сила тока в резонансе может принимать огромные значения, что на практике может привести к аварии или выходу из строя элементов схемы.

Посмотрим на поведение напряжений на отдельных элементах цепи при резонансе. Действующие значения напряжений на катушке индуктивности и конденсаторе равны соответственно:
$$U_L = I_{\max} X_L = \frac{U}{R} \omega_0 L$$
$$U_C = I_{\max} X_C = \frac{U}{R} \frac{1}{\omega_0 C}$$

Поскольку при резонансе $\omega_0 L = \frac{1}{\omega_0 C} = X$, напряжения на катушке и конденсаторе по модулю равны друг другу:
$$U_L = U_C = I_{\max} X = \frac{U \cdot X}{R}$$

Величина $\rho = \sqrt{\frac{L}{C}}$ называется **волновым (или характеристическим) сопротивлением** контура. Вспомним из теории затухающих колебаний понятие добротности контура $Q$:
$$Q = \frac{\omega_0 L}{R} = \frac{1}{R}\sqrt{\frac{L}{C}} = \frac{\rho}{R}$$

Тогда напряжения на реактивных элементах можно выразить через напряжение источника и добротность:
$$U_L = U_C = Q \cdot U$$

Если добротность контура высока ($Q \gg 1$, например, $Q = 100$), то напряжения на катушке индуктивности и конденсаторе в $100$ раз превышают напряжение внешнего источника питания ($U_L = U_C = 100 U$). Этот факт представляет собой реальную **опасность пробоя изоляции конденсатора** и межвитковой изоляции катушки, несмотря на относительно безопасное внешнее напряжение сети.

### Мощность переменного тока. Активная, реактивная и полная мощность

При протекании переменного тока через электрическую цепь энергия непрерывно передается от генератора к потребителям и обратно. Для характеристики этого процесса вводятся три вида мощности.

#### 1. Мгновенная и средняя активная мощность
Мгновенное значение мощности переменного тока равно произведению мгновенных значений силы тока и напряжения:
$$p(t) = i(t) \cdot u(t)$$

Пусть напряжение задано законом $u(t) = U_m \sin(\omega t)$, а ток отстает или опережает его по фазе на угол $\varphi$: $i(t) = I_m \sin(\omega t - \varphi)$. Тогда мгновенная мощность равна:
$$p(t) = U_m I_m \sin(\omega t) \sin(\omega t - \varphi)$$

Используя тригонометрическое тождество, найдем среднее за период значение мощности, которое называют **активной (или полезной) мощностью** $P$:
$$P = \frac{1}{T} \int_0^T p(t) \, dt = \frac{U_m I_m}{2} \cos\varphi$$

Переходя к действующим значениям $U = \frac{U_m}{\sqrt{2}}$ и $I = \frac{I_m}{\sqrt{2}}$, получаем базовую формулу активной мощности:

$$P = U I \cos\varphi$$

где $\varphi$ — сдвиг фаз между током и напряжением, а $\cos\varphi$ — **коэффициент мощности**.

#### 2. Физический смысл коэффициента мощности
Из векторной диаграммы сопротивлений для последовательного соединения $R, L, C$ следует треугольник сопротивлений, стороны которого связаны соотношением:
$$\cos\varphi = \frac{R}{Z}$$

* Активная мощность выделяется исключительно на активном сопротивлении $R$ в виде тепла (закон Джоуля–Ленца):
  $$P = I^2 R$$
* На чистых реактивных элементах (индуктивности и емкости) средняя за период активная мощность равна нулю ($P_L = 0, P_C = 0$), так как в четверть периода энергия запасается в поле элемента, а в следующую четверть полностью возвращается обратно источнику.

#### 3. Реактивная и полная мощность
Для оценки максимального энергообмена между реактивными элементами и генератором вводят понятие **реактивной мощности** $Q$:
$$Q = U I \sin\varphi$$
Единицей измерения активной и реактивной мощности в СИ является ватт (Вт) и вольт-ампер реактивный (вар) соответственно.

Полная энергия, циркулирующая в цепи, характеризуется **полной (или кажущейся) мощностью** $S$:
$$S = U I = \sqrt{P^2 + Q^2}$$
Единицей полной мощности является вольт-ампер (В·А). 

Коэффициент мощности $\cos\varphi$ имеет важнейшее экономическое значение при передаче электрической энергии по линиям электропередач (ЛЭП). Поскольку передаваемая активная мощность равна $P = U I \cos\varphi$, для передачи одной и той же мощности при меньшем значении $\cos\varphi$ требуется пропускать больший ток $I$. Это приводит к катастрофическому росту потерь энергии на нагрев проводов ЛЭП, так как тепловые потери пропорциональны квадрату тока ($P_{\text{потерь}} = I^2 R_{\text{пром}}$). Именно поэтому на практике энергетические компании стремятся поддерживать коэффициент мощности как можно ближе к единице ($\cos\varphi \to 1$), используя специальные компенсирующие устройства (батареи конденсаторов).

### Разобранный пример

**Условие:** Последовательный колебательный контур подключен к генератору переменного напряжения с амплитудой $U_m = 50$ В и частотой $\nu = 400$ Гц. Индуктивность катушки равна $L = 10$ мГн. Какова должна быть емкость конденсатора $C$ для достижения резонанса напряжений, и какова будет амплитудная сила тока $I_m$ в контуре при резонансе, если активное сопротивление равно $R = 5$ Ом?

**Рисунок словами (схема цепи):**
> По горизонтальной линии последовательно соединены: генератор синусоидального напряжения с амплитудой $U_m$ и частотой $\nu$, резистор сопротивлением $R$, катушка индуктивности с параметром $L$ и конденсатор переменной емкости $C$. Замкнутый контур образует единую неразветвленную цепь, в которой течет общий ток $I(t)$.

**Ход рассуждений:**
1. Для достижения резонанса напряжений необходимо, чтобы частота генератора $\nu$ (или циклическая частота $\omega = 2\pi\nu$) совпадала с собственной частотой контура $\omega_0 = \frac{1}{\sqrt{LC}}$. Из этого условия мы найдем требуемую емкость конденсатора $C$.
2. При резонансе реактивные сопротивления взаимно компенсируются ($X_L = X_C$), а полное сопротивление цепи становится равным чисто активному сопротивлению: $Z = R$.
3. Амплитудное значение силы тока при резонансе вычисляется по закону Ома через амплитуду напряжения генератора и активное сопротивление: $I_m = \frac{U_m}{R}$.

**Решение в общем виде:**
Частота генератора через циклическую частоту: $\omega = 2\pi\nu$.
Условие резонанса:
$$\omega L = \frac{1}{\omega C} \implies C = \frac{1}{\omega^2 L} = \frac{1}{(2\pi\nu)^2 L}$$

Амплитуда тока при резонансе:
$$I_m = \frac{U_m}{R}$$

**Подстановка числовых значений:**
Переведем исходные данные в систему СИ:
- $U_m = 50$ В
- $\nu = 400$ Гц
- $L = 10 \text{ мГн} = 10 \cdot 10^{-3}$ Гн $= 0{,}01$ Гн
- $R = 5$ Ом

Вычисляем циклическую частоту:
$$\omega = 2 \cdot \pi \cdot 400 \approx 2 \cdot 3{,}14159 \cdot 400 = 2513{,}27 \text{ с}^{-1}$$

Вычисляем емкость конденсатора:
$$C = \frac{1}{(2513{,}27)^2 \cdot 0{,}01} = \frac{1}{6316525 \cdot 0{,}01} = \frac{1}{63165{,}25} \approx 1{,}58 \cdot 10^{-5} \text{ Ф} = 15{,}8 \text{ мкФ}$$

Вычисляем амплитудную силу тока:
$$I_m = \frac{50}{5} = 10 \text{ А}$$

**Проверка размерностей и правдоподобия:**
- Проверка размерности для емкости: 
  $$[C] = \frac{1}{\text{с}^{-2} \cdot \text{Гн}} = \frac{1}{\text{с}^{-2} \cdot (\mathrm{B} \cdot \text{с} / \mathrm{A})} = \frac{\mathrm{A}}{\mathrm{B} \cdot \text{с}^{-1}} = \frac{\mathrm{A} \cdot \text{с}}{\mathrm{B}} = \text{Ф (фарад)}$$
  Размерность верна.
- Проверка размерности для тока:
  $$[I_m] = \frac{\mathrm{B}}{\text{Ом}} = \mathrm{A} \text{ (ампер)}$$
  Размерность верна.
- Оценка правдоподобия: ток в 10 А при напряжении 50 В и сопротивлении 5 Ом является абсолютно корректным ($10 = 50 / 5$). Значение емкости около $15{,}8$ мкФ является стандартным для радиотехнических цепей звуковой частоты.

**Ответ:** Емкость конденсатора для достижения резонанса должна быть равна $15{,}8$ мкФ; амплитудное значение силы тока в контуре при резонансе равно $10$ А.

## 5. Трансформатор. Производство и передача электроэнергии

### Назначение и устройство трансформатора

> **Определение.** Трансформатором называется статическое электромагнитное устройство, предназначенное для преобразования переменного тока одного напряжения в переменный ток другого напряжения при неизменной частоте и без существенных потерь энергии.

В курсе физики мы изучаем исключительно переменный ток, поскольку стационарные магнитные поля не способны вызывать электромагнитную индукцию в замкнутых обмотках. Трансформаторы находят применение в энергетике для передачи электроэнергии на большие расстояния, в промышленности для питания технологических установок, а также в радиоэлектронике и блоках питания бытовых приборов.

Рассмотрим конструкцию классического однофазного трансформатора. Основными элементами устройства являются:
1. Замкнутый сердечник (магнитопровод), собираемый из тонких пластин электротехнической стали с высокой магнитной проницаемостью ($\mu \gg 1$). Наличие сердечника позволяет концентрировать магнитное поле и минимизировать рассеяние магнитного потока в пространстве.
2. Первичная обмотка — катушка с числом витков $N_1$, подключаемая к источнику переменного напряжения.
3. Вторичная обмотка — катушка с числом витков $N_2$, к которой подключается нагрузка потребителя.

```
+---------------------------------------------+
|               Магнитопровод                 |
|       +-----------------------+             |
|       |                       |             |
|    [=====]                [=====]           |
|    Первичная              Вторичная         |
|    обмотка                обмотка           |
|    ($N_1$ витков)         ($N_2$ витков)    |
|       |                       |             |
|       +-----------------------+             |
+---------------------------------------------+
   ~ $U_1(t)$                 Нагрузка $Z$
```

### Принцип действия и коэффициент трансформации

Принцип действия трансформатора основан на явлении электромагнитной индукции. Пусть к первичной обмотке с числом витков $N_1$ приложено синусоидальное переменное напряжение:

$$u_1(t) = U_{1m} \sin(\omega t)$$

Под действием этого напряжения в первичной обмотке протекает переменный ток, который создает в замкнутом ферромагнитном сердечнике переменный магнитный поток $\Phi(t)$. Поскольку сердечник обладает высокой магнитной проницаемостью, весь этот магнитный поток пронизывает как витки первой обмотки, так и витки второй обмотки.

Согласно закону электромагнитной индукции Фарадея, в каждом витке обмотки наводится ЭДС индукции, равная скорости изменения магнитного потока: $\varepsilon_1 = -\frac{d\Phi}{dt}$. Для всей первичной обмотки суммарная ЭДС самоиндукции равна:

$$e_1 = -N_1 \frac{d\Phi}{dt}$$

В режиме холостого хода (когда вторичная цепь разомкнута и ток во вторичной обмотке равен нулю) падением напряжения на активном сопротивлении проводов первичной обмотки часто можно пренебречь. Тогда действующее значение приложенного напряжения $U_1$ уравновешивается действующим значением ЭДС $E_1$:

$$U_1 \approx E_1 = \omega N_1 \Phi_m \frac{1}{\sqrt{2}}$$

где $\Phi_m$ — амлитуда магнитного потока в сердечнике.

Аналогично, во вторичной обмотке с числом витков $N_2$ наводится ЭДС $E_2$:

$$U_2 \approx E_2 = \omega N_2 \Phi_m \frac{1}{\sqrt{2}}$$

> **Определение.** Коэффициентом трансформации $k$ называется отношение напряжения на первичной обмотке к напряжению на вторичной обмотке в режиме холостого хода, равное отношению чисел витков этих обмоток:
> 
> $$k = \frac{N_1}{N_2} = \frac{U_1}{U_2}$$

В зависимости от значения коэффициента трансформации устройства делятся на два типа:
- Повышающие трансформаторы ($k < 1$, то есть $N_1 < N_2$). Они увеличивают напряжение ($U_2 > U_1$), что необходимо для передачи энергии по линиям электропередач.
- Понижающие трансформаторы ($k > 1$, то есть $N_1 > N_2$). Они уменьшают напряжение ($U_2 < U_1$) до безопасных или рабочих значений для потребителей.

### Режимы работы трансформатора

Работа трансформатора рассматривается в двух основных режимах: холостой ход и нагрузка.

#### Режим холостого хода
В этом режиме вторичная цепь разомкнута ($I_2 = 0$). Ток в первичной обмотке называется током холостого хода ($I_{10}$). Он используется исключительно для намагничивания сердечника и покрытия потерь на гистерезис и вихревые токи в стали. Так как мощность потерь мала, ток $I_{10}$ составляет всего $1\text{--}5\%$ от номинального тока обмотки. Векторная диаграмма этого режима показывает, что ток холостого хода отстает от приложенного напряжения на угол, близкий к $\pi/2$, поскольку первичная обмотка обладает большой индуктивностью и преобладающим реактивным сопротивлением.

#### Нагрузочный режим
При подключении к вторичной обмотке нагрузки с сопротивлением $Z_2$ во вторичной цепи возникает переменный ток:

$$I_2 = \frac{U_2}{Z_2}$$

Появление тока $I_2$ во вторичной обмотке создает собственный магнитный поток, который, согласно правилу Ленца, направлен встречно магнитному потоку первичной обмотки. Это приводит к попытке уменьшить суммарный магнитный поток в сердечнике. Однако магнитный поток в сердечнике жестко задается приложенным напряжением $U_1$. Чтобы магнитный поток оставался неизменным, первичная обмотка автоматически увеличивает потребление тока от источника. 

Из закона сохранения энергии для идеального трансформатора (мощность на входе равна мощности на выходе, $P_1 = P_2$, или $U_1 I_1 = U_2 I_2$):

$$\frac{I_2}{I_1} \approx \frac{U_1}{U_2} = k$$

Таким образом, для идеального трансформатора **силы токов в обмотках обратно пропорциональны их напряжениям и числу витков**: если напряжение повышается в $k$ раз, то сила тока во столько же раз уменьшается.

### Коэффициент полезного действия реального трансформатора

Идеальный трансформатор не имеет потерь энергии. В реальных устройствах всегда присутствуют потери, которые приводят к нагреванию элементов конструкции и снижению коэффициента полезного действия (КПД). Основные причины потерь энергии:
1. Потери на нагревание обмоток (джоулево тепло): электрический ток протекает по проводам обмоток, обладающим активным сопротивлением $R_1$ и $R_2$. Мощность потерь тепла равна $P_{\text{мед}} = I_1^2 R_1 + I_2^2 R_2$.
2. Потери на вихревые токи (токи Фуко): переменный магнитный поток индуцирует в массивном теле сердечника вихревые электрические токи, которые разогревают сталь. Для борьбы с этим эффектом сердечник набирают из тонких изолированных друг от друга лаком листов электротехнической стали.
3. Потери на гистерезис: затраты энергии на перемагничивание ферромагнитного сердечника при каждом периоде изменения частоты переменного тока.

> **Определение.** Коэффициентом полезного действия ($\eta$) реального трансформатора называется отношение активной мощности, отдаваемой во вторичную цепь потребителю ($P_2$), к активной мощности, потребляемой первичной обмоткой от источника ($P_1$):
> 
> $$\eta = \frac{P_2}{P_1} = \frac{P_2}{P_2 + P_{\text{потерь}}} = \frac{U_2 I_2 \cos\varphi_2}{U_1 I_1 \cos\varphi_1}$$
> 
> где $U_1, U_2$ — действующие напряжения, $I_1, I_2$ — действующие токи, а $\cos\varphi_1, \cos\varphi_2$ — коэффициенты мощности в первичной и вторичной цепях.

Современные силовые трансформаторы обладают очень высокой конструктивной эффективностью, их КПД достигает $98\text{--}99\%$.

### Производство и передача электрической энергии на большие расстояния

Электрическая энергия вырабатывается на электростанциях (тепловых, атомных, гидроэлектрических) генераторами переменного тока при напряжениях порядка $10\text{--}20\text{ кВ}$. Для транспортировки этой энергии к удаленным населенным пунктам и промышленным предприятиям по линиям электропередач (ЛЭП) применяются протяженные провода, обладающие ненулевым активным сопротивлением $R_{\text{лин}}$.

Если передавать мощность $P$ при относительно низком напряжении $U$, то сила тока в проводах линии будет большой:

$$I = \frac{P}{U}$$

При этом потери мощности на нагревание проводов линии электропередачи составят:

$$P_{\text{нагр}} = I^2 R_{\text{лин}} = \left(\frac{P}{U}\right)^2 R_{\text{лин}}$$

Формула наглядно показывает, что потери мощности квадратично зависят от силы тока и обратно пропорциональны квадрату напряжения. Если попытаться передать большую мощность при низком напряжении, большая часть энергии рассеется в виде тепла прямо в атмосфере.

Для устранения этой проблемы перед началом линии электропередачи устанавливают **повышающие трансформаторы**, которые поднимают напряжение в проводах до высоких значений ($110\text{ кВ}$, $220\text{ кВ}$ или $500\text{ кВ}$). За счет увеличения напряжения сила тока в ЛЭП уменьшается в сотни раз, что позволяет снизить потери энергии на нагрев проводов в десятки тысяч раз. В месте потребления электроэнергии устанавливают цепочку **понижающих трансформаторов**, которые ступенчато снижают напряжение до безопасных значений ($380\text{ В}$ для промышленности и $220\text{ В}$ для бытовых потребителей).

### Разбор примеров

#### Пример 1. Расчет параметров идеального трансформатора

**Условие задачи:**
Понижающий трансформатор с коэффициентом трансформации $k = 10$ питает нагрузку с активным сопротивлением $R_2 = 22\text{ Ом}$. Действующее напряжение на вторичной обмотке равно $U_2 = 110\text{ В}$. Определить действующее напряжение $U_1$ и силу тока $I_1$ в первичной обмотке трансформатора, а также активную мощность $P_2$, потребляемую нагрузкой, считая трансформатор идеальным.

**Рисунок (схема) условиями словами:**
Схема представляет собой идеальный трансформатор, состоящий из первичной и вторичной обмоток на общем замкнутом сердечнике. К первичной обмотке подведено неизвестное переменное напряжение $U_1$, протекает ток $I_1$. К вторичной обмотке подключен резистор сопротивлением $R_2 = 22\text{ Ом}$, на нем зафиксировано напряжение $U_2 = 110\text{ В}$.

**Ход рассуждений:**
1. По условию трансформатор является идеальным, потерями энергии пренебрегаем. 
2. Напряжение в первичной обмотке связано с напряжением во вторичной обмотке через коэффициент трансформации $k$: $k = \frac{U_1}{U_2}$. Отсюда можно выразить $U_1$.
3. Ток во вторичной обмотке $I_2$ находится по закону Ома для участка цепи с активным сопротивлением: $I_2 = \frac{U_2}{R_2}$.
4. Силу тока в первичной обмотке $I_1$ находим из условия равенства мощностей идеального трансформатора ($U_1 I_1 = U_2 I_2$) или через обратную пропорциональность коэффициенту трансформации: $k = \frac{I_2}{I_1}$.
5. Потребляемая нагрузкой мощность $P_2$ определяется через напряжение и сопротивление вторичной цепи: $P_2 = \frac{U_2^2}{R_2}$.

**Решение в общем виде:**
Из формулы коэффициента трансформации напряжение первичной обмотки равно:
$$U_1 = k \cdot U_2$$

Сила тока во вторичной обмотке по закону Ома:
$$I_2 = \frac{U_2}{R_2}$$

Сила тока в первичной обмотке из соотношения для идеального трансформатора:
$$I_1 = \frac{I_2}{k} = \frac{U_2}{k \cdot R_2}$$

Мощность, потребляемая нагрузкой во вторичной цепи:
$$P_2 = \frac{U_2^2}{R_2}$$

**Подстановка числовых значений:**
$$U_1 = 10 \cdot 110\text{ В} = 1100\text{ В}$$

$$I_2 = \frac{110\text{ В}}{22\text{ Ом}} = 5\text{ А}$$

$$I_1 = \frac{5\text{ А}}{10} = 0{,}5\text{ А}$$

$$P_2 = \frac{(110\text{ В})^2}{22\text{ Ом}} = \frac{12100\text{ В}^2}{22\text{ Ом}} = 550\text{ Вт}$$

**Проверка размерностей и правдоподобия:**
- Размерность $U_1$: $[\text{В}] = [\text{В}]$. Верно.
- Размерность $I_1$: $[\text{А}] = [\text{А}]$. Верно.
- Размерность мощности: $[\text{Вт}] = \frac{[\text{В}]^2}{[\text{Ом}]} = \frac{\text{В}^2}{\text{В}/\text{А}} = \text{Вт}$. Верно.
- Анализ правдоподобия: трансформатор понижающий ($k=10$), поэтому напряжение на входе в 10 раз больше выхода ($1100\text{ В} > 110\text{ В}$), а сила тока на входе в 10 раз меньше выхода ($0{,}5\text{ А} < 5\text{ А}$). Энергия сохраняется ($U_1 I_1 = 1100 \cdot 0{,}5 = 550\text{ Вт}$, что совпадает с мощностью нагрузки $P_2 = 550\text{ Вт}$). Решение корректно.

**Ответ:** Напряжение в первичной обмотке $U_1 = 1100\text{ В}$; сила тока в первичной обмотке $I_1 = 0{,}5\text{ А}$; мощность, потребляемая нагрузкой, $P_2 = 550\text{ Вт}$.

$$E_2 = \omega N_2 \Phi_m \frac{1}{\sqrt{2}}$$

Разделим выражение для ЭДС первой обмотки на выражение для ЭДС второй обмотки. Все одинаковые множители ($\omega$, $\Phi_m$, $\sqrt{2}$) сокращаются:

$$\frac{E_1}{E_2} = \frac{N_1}{N_2}$$

> **Определение.** Коэффициентом трансформации $k$ называется отношение ЭДС первичной обмотки к ЭДС вторичной обмотки (или отношение числа витков в обмотках):
> $$k = \frac{E_1}{E_2} \approx \frac{U_1}{U_2} = \frac{N_1}{N_2}$$

*   **Обозначения:** $k$ — коэффициент трансформации (безразмерная величина); $N_1, N_2$ — число витков в первичной и вторичной обмотках; $U_1, U_2$ — действующие значения напряжений на обмотках.
*   **Классификация трансформаторов:**
    *   Если $N_1 > N_2$ ($k > 1$), то $U_1 > U_2$. Это **понижающий трансформатор**, который уменьшает напряжение.
    *   Если $N_1 < N_2$ ($k < 1$), то $U_1 < U_2$. Это **повышающий трансформатор**, который увеличивает напряжение.

### Режимы работы трансформатора

#### 1. Режим холостого хода
К вторичной обмотке не подключена нагрузка (цепь разомкнута, $I_2 = 0$). Ток в первичной обмотке $I_10$ чрезвычайно мал (он расходуется только на создание переменного магнитного потока и покрытие небольших потерь на гистерезис и вихревые токи в стали сердечника). Напряжение на зажимах вторичной обмотки равно ЭДС: $U_2 \approx E_2$.

#### 2. Режим нагрузки
К вторичной обмотке подключается потребитель с полным сопротивлением нагрузки $Z$. Во вторичной обмотке начинает протекать переменный ток $I_2$, действующее значение которого определяется законом Ома:

$$I_2 = \frac{U_2}{Z}$$

Появление тока во вторичной обмотке приводит к тому, что создаваемое им магнитное поток согласно закону Ленца начинает компенсировать изменение магнитного потока в сердечнике. В соответствии с законом сохранения энергии, увеличение мощности во вторичной цепи вызывает автоматическое увеличение тока в первичной обмотке ($I_1$), чтобы сохранить неизменным магнитный поток в сердечнике. 

Для идеального трансформатора (без потерь энергии на нагрев обмоток и вихревые токи, КПД равен 100%) мощность в первичной обмотке равна мощности во вторичной обмотке:

$$P_1 = P_2 \implies U_1 I_1 = U_2 I_2$$

Отсюда следует важное соотношение для токов в идеальном трансформаторе:

$$\frac{I_1}{I_2} = \frac{U_2}{U_1} = \frac{N_2}{N_1} = \frac{1}{k}$$

Токи в обмотках трансформатора обратно пропорциональны их напряжениям и числу витков. Если трансформатор повышает напряжение в 10 раз ($k = 0{,}1$), то сила тока во вторичной обмотке будет в 10 раз меньше силы тока в первичной обмотке.

На практике любой реальный трансформатор имеет потери энергии в обмотках (джоулево тепло $I^2 R$) и в стали сердечника. Эффективность трансформатора оценивается коэффициентом полезного действия (КПД) $\eta$:

$$\eta = \frac{P_2}{P_1} = \frac{U_2 I_2 \cos\varphi_2}{U_1 I_1 \cos\varphi_1} \cdot 100\%$$

Современные силовые трансформаторы на подстанциях обладают высочайшим КПД, достигающим $98{,}5\% - 99{,}2\%$.

### Производство и передача электроэнергии

Основная задача трансформаторов в масштабах государства — передача электрической энергии от электростанций (тепловых, атомных, гидроэлектростанций) к потребителям (городам, заводам, жилым домам), находящимся на расстоянии сотен и тысяч километров.

Пусть электростанция вырабатывает мощность $P$, которую нужно передать по линии электропередачи (ЛЭП) с общим активным сопротивлением проводов $R_{\text{пром}}$. Ток в линии равен $I = \frac{P}{U}$, где $U$ — напряжение в линии. Мощность потерь тепла в проводах ЛЭП составляет:

$$P_{\text{потерь}} = I^2 R_{\text{пром}} = \left(\frac{P}{U}\right)^2 R_{\text{пром}}$$

Из этой формулы очевидно, что потери энергии катастрофически велики при низких напряжениях. Чтобы уменьшить потери в миллионы раз, на электростанции устанавливают **повышающие трансформаторы**, которые поднимают напряжение от генераторных значений (обычно $10 - 20$ кВ) до сверхвысоких напряжений линий электропередач ($110$, $220$, $500$ или $750$ кВ). При увеличении напряжения в 50 раз ток в линии уменьшается в 50 раз, а тепловые потери снижаются в $50^2 = 2500$ раз!

При приближении линии к населенному пункту напряжение последовательно понижают с помощью понижающих трансформаторных подстанций до безопасных промышленных и бытовых значений ($380$ В между фазами и $220$ В в розетках для потребителей).

### Разобранный пример

**Условие:** Понижающий трансформатор с коэффициентом трансформации $k = 20$ подключен к сети переменного тока с действующим напряжением $U_1 = 2200$ В. Сопротивление вторичной обмотки трансформатора пренебрежимо мало. К вторичной обмотке подключен активный резистор сопротивлением $R = 11$ Ом. Найти действующее напряжение на вторичной обмотке $U_2$, действующий ток во вторичной обмотке $I_2$ и действующий ток в первичной обмотке $I_1$ (считая трансформатор идеальным).

#### Дано:
- $k = 20$
- $U_1 = 2200$ В
- $R = 11$ Ом

**Найти:** $U_2$, $I_2$, $I_1$ — ?

#### Ход рассуждений:
1. Напряжение на вторичной обмотке $U_2$ найдем через коэффициент трансформации: $k = \frac{U_1}{U_2} \implies U_2 = \frac{U_1}{k}$.
2. Действующий ток во вторичной обмотке $I_2$ найдем по закону Ома для резистивной нагрузки: $I_2 = \frac{U_2}{R}$.
3. Действующий ток в первичной обмотке $I_1$ вычислим из условия равенства мощностей идеального трансформатора ($U_1 I_1 = U_2 I_2$): $I_1 = I_2 \cdot \frac{U_2}{U_1} = \frac{I_2}{k}$. Также можно воспользоваться соотношением токов и коэффициента трансформации напрямую.

#### Решение в общем виде:
1. Напряжение вторичной обмотки:
   $$U_2 = \frac{U_1}{k}$$
2. Ток во вторичной обмотке:
   $$I_2 = \frac{U_2}{R} = \frac{U_1}{k R}$$
3. Ток в первичной обмотке:
   $$I_1 = \frac{I_2}{k} = \frac{U_1}{k^2 R}$$

#### Подстановка числовых значений:
1. Вычисляем напряжение на вторичной обмотке:
   $$U_2 = \frac{2200 \text{ В}}{20} = 110 \text{ В}$$
2. Вычисляем ток во вторичной обмотке:
   $$I_2 = \frac{110 \text{ В}}{11 \text{ Ом}} = 10 \text{ А}$$
3. Вычисляем ток в первичной обмотке:
   $$I_1 = \frac{10 \text{ А}}{20} = 0{,}5 \text{ А}$$
   *(Проверка через мощности: $P_2 = U_2 I_2 = 110 \text{ В} \cdot 10 \text{ А} = 1100$ Вт. Мощность в первичной обмотке $P_1 = U_1 I_1 = 2200 \text{ В} \cdot 0{,}5 \text{ А} = 1100$ Вт. Мощности равны, закон сохранения энергии соблюден).*

#### Проверка размерностей и правдоподобия:
- $[U_2] = [\text{В}]$. $[I_2] = [\text{А}]$. $[I_1] = [\text{А}]$. Все размерности корректны.
- Напряжение понизилось в 20 раз (с 2200 В до 110 В), ток увеличился на нагрузке до 10 А, при этом ток в первичной обмотке составил всего 0,5 А. Расчеты полностью правдоподобны и согласуются с законами электродинамики.

> **Ответ:** Напряжение на вторичной обмотке $U_2 = 110$ В; ток во вторичной обмотке $I_2 = 10$ А; ток в первичной обмотке $I_1 = 0{,}5$ А.

## Типичные ошибки

1. **Сложение действующих и амплитудных значений как обычных чисел.**
   * *Ошибка:* Студент подставляет в формулу импеданса или закона Ома амплитудное напряжение $U_m$, а ток рассчитывает как действующий, либо складывает напряжения $U_R + U_L$ арифметически.
   * *Почему возникает:* Непонимание физического смысла действующих и мгновенных значений переменного тока, а также игнорирование векторного характера гармонических колебаний.
   * *Как избежать:* Всегда строго разделяйте параметры: если задача задана в действующих значениях ($U, I$), работайте с ними; если в амплитудных ($U_m, I_m$), вычисляйте через амплитуды. Для сложения напряжений всегда используйте правило векторных диаграмм или теорему Пифагора.

2. **Путаница в фазовых сдвигах между током и напряжением на элементах R, L, C.**
   * *Ошибка:* Утверждение, что в катушке ток опережает напряжение, а в конденсаторе — отстает.
   * *Почему возникает:* Механическое заучивание формул без анализа физической природы процессов (ЭДС самоиндукции в катушке и накопление заряда на обкладках конденсатора).
   * *Как избежать:* Помните мнемоническое правило «ОЛЕНЬ» (В индуктивности L напряжение U опережает ток I) или выводите соотношение через производные: напряжение на катушке пропорционально производной тока ($\sim dI/dt$), поэтому косинус дает опережение на $\pi/2$.

3. **Игнорирование единиц измерения емкости и индуктивности (микро-, милли-).**
   * *Ошибка:* Подстановка в формулу Томсона или формулу сопротивлений значений емкости в микрофарадах ($50$ мкФ) или индуктивности в миллигенри ($10$ мГн) без перевода в систему СИ.
   * *Почему возникает:* Невнимательность к префиксам единиц измерения.
   * *Как избежать:* Всегда перед началом расчета переводите все величины в основные единицы системы СИ: фарады [Ф], генри [Гн], герцы [Гц], омы [Ом].

4. **Отождествление резонанса напряжений с короткого замыканием цепи.**
   * *Ошибка:* Студент считает, что при резонансе полное сопротивление цепи $Z = 0$, поэтому ток обращается в бесконечность.
   * *Почему возникает:* Путаница между полным сопротивлением $Z$ и реактивной разностью $X_L - X_C$.
   * *Как избежать:* Помните, что при резонансе обращается в нуль именно реактивная составляющая ($X_L - X_C = 0$), но остается активное сопротивление резистора $R$. Полное сопротивление в резонансе минимально, но не равно нулю: $Z_{\min} = R$.

5. **Ошибки в расчете коэффициента мощности ($\cos\varphi$).**
   * *Ошибка:* Вычисление активной мощности по формуле $P = UI$ без учета сдвига фаз для цепи с реактивными элементами.
   * *Почему возникает:* Перенос формул постоянного тока на цепи переменного тока с реактивными сопротивлениями.
   * *Как избежать:* Всегда проверяйте состав цепи: если в цепи присутствуют катушки или конденсаторы, активная мощность обязательно умножается на коэффициент мощности: $P = UI\cos\varphi$.

6. **Неправильное применение формул трансформатора для постоянного тока.**
   * *Ошибка:* Попытка подать постоянное напряжение от аккумулятора на первичную обмотку трансформатора в надежде получить преобразованное напряжение на вторичной обмотке.
   * *Почему возникает:* Непонимание того, что электромагнитная индукция возникает только при изменении магнитного потока во времени.
   * *Как избежать:* Помните ключевое определение: трансформатор работает **только** на переменном токе. Постоянный ток не создает переменного магнитного потока, ЭДС индукции во вторичной обмотке равна нулю.

7. **Неверный выбор знака в формуле полного сопротивления (импеданса).**
   * *Ошибка:* Запись импеданса в виде $Z = R + X_L - X_C$ или возведение разности в нечетную степень.
   * *Почему возникает:* Забывание геометрического смысла теоремы Пифагора для ортогональных векторов на векторной диаграмме.
   * *Как избежать:* Импеданс выводится по теореме Пифагора из катетов $R$ и $(X_L - X_C)$, поэтому формула содержит квадрат корня из суммы квадратов: $Z = \sqrt{R^2 + (X_L - X_C)^2}$.
