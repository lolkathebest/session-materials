## Понятие цикла и цикл с предусловием while

### Понятие цикла и управляющие конструкции

В программировании часто возникают задачи, требующие многократного выполнения одних и тех же или похожих наборов инструкций. Например, если требуется вывести на экран все целые числа от 1 до 1000, написание тысячи отдельных инструкций `Console.WriteLine` приведет к колоссальному дублированию кода, снижению его читаемости и невозможности гибко управлять процессом, если верхняя граница диапазона станет известна только во время работы программы.

Для решения таких задач используются циклы.

> **Определение.** **Цикл** — это управляющая конструкция языка программирования, предназначенная для организации многократного выполнения последовательности инструкций.

Каждое отдельное выполнение тела цикла называется **итерацией**. Чтобы цикл не выполнялся бесконечно, в нем всегда должен быть механизм изменения состояния, который в определенный момент приведет к завершению работы.

---

### Синтаксис и принцип работы цикла `while`

В языке C# базовым инструментом для реализации итеративных процессов с неизвестным заранее количеством повторений (или когда условие проверяется до начала работы) является оператор `while` (цикл с предусловием).

Общий синтаксис оператора `while` выглядит следующим образом:

```csharp
инициализация_переменных;
while (логическое_условие)
{
    // Тело цикла: блок инструкций, 
    // которые повторяются
    
    изменение_переменных_условия;
}
```

Рассмотрим детально порядок вычислений и выполнения этой конструкции:

1. **Инициализация**: перед началом работы цикла переменные, участвующие в проверке условия, должны получить начальные значения.
2. **Проверка условия**: перед каждой итерацией (включая самую первую) вычисляется логическое выражение `логическое_условие` (тип `bool`).
3. Если условие истинно (`true`), управление передается внутрь тела цикла — выполняются инструкции, заключенные в фигурные скобки `{ }`.
4. Если условие ложно (`false`), цикл завершает свою работу, и программа переходит к выполнению инструкций, расположенных сразу после блока цикла `while`.
5. После выполнения последней инструкции тела цикла управление снова возвращается к шагу 2 (проверка условия).

Ниже приведена блок-схема, иллюстрирующая алгоритм работы цикла с предусловием `while`:

```text
       +-----------------------+
       | Инициализация перемен |
       +-----------------------+
                   |
                   v
       +-----------------------+
  +--->| Условие истинно?      |<---+
  |    +-----------------------+    |
  |        |              |         |
  |      (Да)           (Нет)       |
  |        |              |         |
  |        v              v         |
  |  +-----------+    +-----------+ |
  |  | Тело      |    | Выход из  | |
  |  | цикла     |    | цикла     | |
  |  +-----------+    +-----------+ |
  |        |                        |
  |        v                        |
  |  +---------------------------+  |
  |  | Изменение переменной      |--+
  |  +---------------------------+
```

Обратите внимание: если с самой первой проверки логическое условие возвращает `false`, тело цикла не выполнится ни разу. Это ключевая особенность цикла с предусловием.

### Бесконечные циклы и правила их предотвращения

Поскольку условие выполнения цикла зависит от значений переменных, изменяющихся внутри него, возникает риск совершения логической ошибки.

> **Определение.** **Бесконечный цикл** — это ситуация, при которой логическое условие в заголовке цикла никогда не становится ложным, в результате чего программа зависает или циклически выполняет один и тот же блок кода до принудительного завершения операционной системой.

Бесконечные циклы могут возникать по следующим причинам:
- Забыли изменить значение переменной-счетчика или управляющей переменной внутри тела цикла.
- Шаг изменения переменной направлен в противоположную сторону (например, условие проверяет уменьшение переменной до нуля, а в теле цикла ее значение увеличивается).
- Написано некорректное условие, которое математически не может быть достигнуто.

**Пример ошибочного кода (бесконечный цикл):**
```csharp
int i = 1;
while (i <= 5)
{
    Console.WriteLine(i);
    // ОШИБКА: переменная i не изменяется, условие (i <= 5) всегда истинно
}
```

Чтобы предотвратить бесконечные циклы, всегда проектируйте код так, чтобы на каждой итерации состояние системы приближалось к моменту, когда условие станет ложным.

### Разобранный пример: вычисление суммы целых чисел

Рассмотрим комплексную задачу, демонстрирующую применение цикла `while` для накопления значения.

#### Условие задачи
Найти сумму всех целых чисел от 1 до 5 включительно с помощью цикла `while`. Вывести полученную сумму на консоль.

#### Рисунок словами (схема работы переменных)
Представим, что у нас есть две ключевые переменные:
1. `i` — текущее слагаемое, которое последовательно принимает значения от 1 до 5.
2. `sum` — накопитель (аккумулятор) суммы, в котором на каждом шаге к предыдущему результату прибавляется значение `i`.

Таблица изменения переменных по шагам итераций:

| Номер итерации | Значение `i` перед проверкой | Условие `i <= 5` | Действия в теле цикла | Значение `sum` после шага | Значение `i` после шага |
|---|---|---|---|---|---|
| Старт | 1 | — | `sum = 0`, `i = 1` | `0` | `1` |
| 1 | 1 | Истинно (`true`) | `sum = 0 + 1`, `i = 1 + 1` | `1` | `2` |
| 2 | 2 | Истинно (`true`) | `sum = 1 + 2`, `i = 2 + 1` | `3` | `3` |
| 3 | 3 | Истинно (`true`) | `sum = 3 + 3`, `i = 3 + 1` | `6` | `4` |
| 4 | 4 | Истинно (`true`) | `sum = 6 + 4`, `i = 4 + 1` | `10` | `5` |
| 5 | 5 | Истинно (`true`) | `sum = 10 + 5`, `i = 5 + 1` | `15` | `6` |
| 6 | 6 | Ложно (`false`) | Выход из цикла | `15` | `6` |

#### Ход рассуждений (почему делаем именно так)
1. Для хранения суммы нам понадобится целочисленная переменная (например, `sum`), которую перед началом цикла необходимо обнулить (`int sum = 0;`), так как в ней изначально нет никаких данных.
2. Для перебора чисел от 1 до 5 заведем управляющую переменную-счетчик `i` и присвоим ей начальное значение `1`.
3. Условием продолжения работы цикла будет неравенство или нестрогое сравнение `i <= 5` (или `i < 6`). Пока `i` входит в диапазон от 1 до 5 включительно, цикл должен работать.
4. Внутри тела цикла текущее число `i` прибавляется к общей сумме (`sum = sum + i;` или сокращенно `sum += i;`).
5. Чтобы цикл не стал бесконечным, на каждой итерации мы обязаны увеличить значение счетчика на единицу: `i++;` (что эквивалентно `i = i + 1;`).
6. После завершения работы цикла выводим итоговое значение переменной `sum` на экран.

#### Полный исходный код программы на C#

```csharp
using System;

namespace WhileLoopExample
{
    class Program
    {
        static void Main(string[] args)
        {
            // Шаг 1: Инициализация переменных управления и накопителя
            int i = 1;
            int sum = 0;

            // Шаг 2: Организация цикла с предусловием
            while (i <= 5)
            {
                // Шаг 3: Накопление суммы
                sum += i; // эквивалентно sum = sum + i;

                // Шаг 4: Изменение переменной управления для предотвращения бесконечного цикла
                i++; // эквивалентно i = i + 1;
            }

            // Шаг 5: Вывод результата на экран
            Console.WriteLine("Сумма чисел от 1 до 5 включительно равна: " + sum);
        }
    }
}
```

#### Пояснение по строкам кода
- `int i = 1;` — создаем счетчик и задаем нижнюю границу диапазона.
- `int sum = 0;` — создаем переменную-аккумулятор для хранения результата сложения, инициализируем ее нулем.
- `while (i <= 5)` — проверка условия: если `i` меньше или равно 5, код внутри фигурных скобок выполняется.
- `sum += i;` — добавляем текущее число к общей сумме. На первой итерации `sum` станет равным `1`, на второй — `1 + 2 = 3`, на третьей — `3 + 3 = 6` и так далее.
- `i++;` — увеличиваем счетчик на 1. Без этой строки переменная `i` всегда оставалась бы равной единице, и условие `i <= 5` никогда бы не стало ложным.
- `Console.WriteLine(...)` — выводит сформированную строку в консоль после того, как цикл завершился.

#### Пример консольного вывода
```text
Сумма чисел от 1 до 5 включительно равна: 15
```

#### Проверка и оценка
- **Единицы измерения:** В данной задаче оперируем безразмерными целыми числами (`int`).
- **Правдоподобность:** Проверим вычисления вручную: $1 + 2 + 3 + 4 + 5 = 15$. Полученный в программе результат полностью совпадает с математическим расчетом. Ошибок выхода за границы или бесконечного зацикливания нет.

`Ответ:` Сумма чисел от 1 до 5 включительно равна 15.

## Цикл с постусловием do-while

### Понятие цикла с постусловием и его отличие от цикла с предусловием

В программировании часто возникают задачи, когда блок инструкций должен выполняться многократно, но условие продолжения или завершения работы становится известным только *после* того, как тело цикла было выполнено хотя бы один раз. Для реализации таких сценариев в языке C# используется **цикл с постусловием** (`do-while`).

> **Определение.** Цикл с постусловием (`do-while`) — это управляющая конструкция, которая сначала выполняет тело цикла, а затем проверяет логическое условие. Если условие истинно (`true`), цикл повторяется; если ложно (`false`) — цикл завершается, и управление передается на инструкцию, следующую за конструкцией `do-while`.

Главное принципиальное отличие цикла `do-while` от рассмотренного ранее цикла с предусловием `while` заключается в **моменте проверки условия**:
1. В цикле `while` проверка условия происходит *до* выполнения тела цикла. Если исходное условие сразу ложно (`false`), тело цикла не выполнится ни разу.
2. В цикле `do-while` проверка условия происходит *после* выполнения тела цикла. Благодаря этому тело цикла гарантированно выполнится **хотя бы один раз**, даже если условие продолжения изначально ложно.

Для наглядности сравним поведение обеих конструкций в виде схемы:

```text
Цикл while (с предусловием):
[Начало] ---> ( Условие? ) --[Ложь]--> [Конец цикла]
                   |
                [Истина]
                   |
            [Тело цикла]
                   |
            (Возврат к проверке)

Цикл do-while (с постусловием):
[Начало] ---> [Тело цикла] ---> ( Условие? ) --[Истина]--> (Возврат к телу)
                                     |
                                  [Ложь]
                                     |
                               [Конец цикла]
```

### Общий синтаксис оператора do-while в C#

Синтаксис оператора `do-while` в языке C# имеет следующий вид:

```csharp
do
{
    // Тело цикла: инструкции, которые выполняются на каждой итерации
}
while (условие);
```

Разберем каждый элемент синтаксиса подробно:
- Ключевое слово `do` открывает конструкцию цикла. Оно не требует никаких параметров или условий рядом с собой.
- Фигурные скобки `{ }` обрамляют тело цикла (блок кода). Если тело цикла состоит всего из одной инструкции, фигурные скобки технически можно опустить, однако правила хорошего тона и стандарты безопасности написания кода настоятельно рекомендуют всегда использовать фигурные скобки во избежание логических ошибок.
- Ключевое слово `while` следует сразу за закрывающей фигурной скобкой тела цикла.
- В круглых скобках `(условие)` записывается логическое выражение (тип `bool`). Это выражение вычисляется после каждой итерации. Если результат равен `true`, цикл совершает следующий оборот; если `false` — цикл прекращает работу.
- **Критически важный элемент синтаксиса:** в самом конце строки с ключевым словом `while` и условием обязательно ставится **точка с запятой (;)**. Отсутствие этой точки с запятой приведет к ошибке компиляции.

### Гарантия выполнения тела цикла хотя бы один раз

Рассмотрим математическое и логическое обоснование того, почему тело цикла `do-while` всегда выполняется минимум один раз. 

Поток выполнения программы (control flow) устроен линейно сверху вниз. Когда компилятор доходит до ключевого слова `do`, он немедленно переходит внутрь блока кода, заключенного в фигурные скобки, и выполняет инструкции последовательно. Никаких предварительных проверок перед входом в блок `do` не производится. 

Только после того, как последняя инструкция внутри блока `{ }` будет выполнена, процессор доходит до строки `while (условие)`. В этот момент вычисляется булево выражение. Таким образом, проверка условия физически не может повлиять на самое первое выполнение тела цикла, так как эта проверка происходит *после* него.

### Сценарии применения: проверка ввода пользователя и интерактивные меню

Благодаря своей особенности гарантировать хотя бы однократное выполнение, цикл `do-while` является идеальным инструментом для решения следующих типовых задач:

1. **Проверка корректности введенных пользователем данных (валидация ввода).** Программа должна запросить у пользователя значение (например, возраст, положительное число, пункт меню). Пользователь может ошибиться и ввести неверное значение с первого раза. Нам нужно прочитать это значение, проверить его и, если оно некорректное, повторить запрос. Понятно, что запросить данные мы обязаны *до* того, как начнем их проверять, ведь до ввода пользователя никаких данных у программы просто нет.
2. **Интерактивные меню и циклические диалоги.** Консольное приложение должно показать пользователю список доступных команд, выполнить выбранную команду, а затем снова показать меню, продолжая работу до тех пор, пока пользователь не выберет пункт «Выход». Меню должно быть отображено как минимум один раз, поэтому цикл `do-while` подходит сюда наилучшим образом.

### Разобранный пример: Проверка ввода положительного числа

#### Условие задачи
Запросить у пользователя целое число с помощью цикла `do-while` до тех пор, пока введенное число не окажется строго больше нуля. Как только пользователь введет корректное число, вывести подтверждение на экран и завершить программу.

#### Рисунок словами (описание интерфейса и процесса)
- В консоли появляется строка с приглашением ввести целое число.
- Пользователь вводит значение (например, `-5`, затем `0`, затем `12`).
- Если введено отрицательное число или ноль, программа сообщает об ошибке и снова выводит приглашение к вводу.
- Как только введено число `12` (строго больше нуля), цикл завершается, и выводится итоговое сообщение: `Успех! Вы ввели число: 12`.

#### Ход рассуждений (почему делаем именно так)
1. Нам нужно запросить число у пользователя хотя бы один раз, чтобы было что проверять. Это сразу указывает на выбор цикла с постусловием `do-while`.
2. Для хранения введенного пользователем значения заведем переменную типа `int` (например, `number`). Объявим ее перед началом цикла, чтобы она была доступна и внутри тела цикла (для записи ввода), и в условии `while` (хотя в нашем случае условие будет проверять саму переменную, обновляемую внутри).
3. Внутри блока `do` мы должны:
   - Вывести подсказку для пользователя.
   - Считать строку из консоли с помощью `Console.ReadLine()`.
   - Безопасно преобразовать эту строку в целое число с помощью `int.TryParse(...)`, чтобы программа не вылетала с исключением (крашем), если пользователь введет буквы или спецсимволы место числа.
4. В качестве условия продолжения цикла `while` укажем следующее: `number <= 0`. Это означает: «Повторяй цикл до тех пор, пока введенное число меньше или равно нулю». Как только пользователь введет `1` или больше, условие `number <= 0` станет ложным (`false`), и цикл завершится.

#### Полный исходный код программы на C#

```csharp
using System;

class Program
{
    static void Main()
    {
        // Объявляем переменную для хранения введенного числа
        int number;

        // Начинаем цикл с постусловием
        do
        {
            Console.Write("Введите целое число, строго больше нуля: ");
            
            // Считываем строку и пытаемся преобразовать ее в целое число.
            // Если пользователь ввел не число (например, текст), int.TryParse вернет false,
            // а переменная number получит значение 0.
            string input = Console.ReadLine();
            bool isParsed = int.TryParse(input, out number);

            // Если преобразование не удалось или число неподходящее, выведем предупреждение
            if (!isParsed || number <= 0)
            {
                Console.WriteLine("Ошибка: нужно ввести целое число больше нуля. Попробуйте еще раз.");
            }
        }
        while (number <= 0); // Повторяем цикл, пока число не станет больше нуля

        // Вывод подтверждения после успешного завершения цикла
        Console.WriteLine();
        Console.WriteLine($"Успех! Вы ввели корректное число: {number}");
    }
}
```

#### Пояснение по строкам кода
- `int number;` — объявление переменной. Обратите внимание, что мы можем объявить ее без инициализации, так как внутри цикла `do-while` она гарантированно получит значение в результате успешного или неуспешного ввода.
- `do { ... }` — запуск блока циклических инструкций.
- `string input = Console.ReadLine();` — считывание пользовательского ввода в виде текстовой строки.
- `bool isParsed = int.TryParse(input, out number);` — встроенный безопасный метод парсинга. Он пытается распарсить строку `input` в число и записать результат в переменную `number`. Возвращает `true`, если строка состояла только из цифр (и знака минус), и `false` в противном случае.
- `if (!isParsed || number <= 0)` — проверка на корректность. Если пользователь ввел буквы (`isParsed == число` ложно) или ввел неподходящее число (меньше либо равное нулю), срабатывает блок обработки ошибки.
- `while (number <= 0);` — условие продолжения цикла. Обратите внимание на наличие точки с запятой в самом конце строки.

**Пример 1 (с ошибками ввода):**

Ошибка: нужно ввести целое число больше нуля. Попробуйте еще раз.
Введите целое число, строго больше нуля: ноль
Ошибка: нужно ввести целое число больше нуля. Попробуйте еще раз.
Введите целое число, строго больше нуля: 0
Ошибка: нужно ввести целое число больше нуля. Попробуйте еще раз.
Введите целое число, строго больше нуля: 7

#### Проверка и оценка сложности
- **Проверка единиц и правдоподобия:** Программа оперирует безразмерными целыми числами. Граничные случаи (`0`, `-1`, минимально возможное положительное `1`) обрабатываются корректно: при `0` и отрицательных числах цикл продолжает работу, при `1` цикл успешно завершается.
- **Оценка сложности:**
  - *Сложность по времени (Time Complexity):* $O(N)$ в худшем случае, где $N$ — количество ошибочных попыток ввода, сделанных пользователем до ввода правильного числа. В среднем на одну итерацию затрачивается константное время $O(1)$.
  - *Сложность по памяти (Space Complexity):* $O(1)$, так как для работы программы выделяется фиксированный объем памяти под переменные `number` и `input`, не зависящий от количества итераций цикла.

## Цикл с параметром for

### Назначение цикла с параметром `for`

В программировании часто возникают задачи, в которых точное количество повторений некоторого блока инструкций известно заранее или может быть вычислено перед началом выполнения цикла. Например: вывести на экран элементы массива фиксированного размера, выполнить сложение элементов ряда заданное число раз или построить таблицу значений с фиксированным шагом. 

Для таких сценариев в языке C# предусмотрен специальный инструмент — **цикл с параметром (`for`)**. Этот цикл объединяет в одной компактной конструкции инструкцию начальной инициализации счётчика, проверку условия продолжения работы и изменение счётчика после каждой итерации.

> **Определение.** Цикл `for` — это управляющая конструкция языка программирования, которая выполняет блок кода заданное количество раз на основе изменения значения специальной переменной-счетчика по определенному правилу.

Преимущество цикла `for` перед рассмотренным ранее циклом `while` заключается в его компактности. Все управляющие элементы (переменная, условие, шаг) собраны в одной строке (в заглавии цикла), что снижает вероятность забыть об изменении счетчика и получить бесконечный цикл.

---

### Структура заголовка цикла `for`

Синтаксис оператора `for` в языке C# имеет следующий общий вид:

```csharp
for (инициализация; условие; шаг)
{
    // Тело цикла: инструкции, выполняемые на каждой итерации
}
```

Рассмотрим каждую составляющую этого синтаксиса подробно:

1. **Инициализация (`инициализация`)**. Эта секция выполняется **ровно один раз** в самом начале работы цикла, перед первой проверкой условия. Обычно здесь объявляется и инициализируется переменная-счетчик (например, `int i = 0;`). Допускается объявление нескольких переменных одного типа, а также использование ранее объявленных переменных.
2. **Условие продолжения (`условие`)**. Логическое выражение, которое вычисляется **перед каждой итерацией** цикла. Если результат вычисления равен `true`, то выполняется тело цикла. Если результат равен `false`, работа цикла немедленно прекращается, и управление передается инструкции, следующей за блоком `for`. Если опустить условие в заглавии (оставить секцию пустой), компилятор посчитает его истинным по умолчанию (`true`), что приведет к бесконечному циклу, если внутри не сработает оператор выхода (`break` или `return`).
3. **Шаг / итерационное выражение (`шаг`)**. Инструкция, которая выполняется **после завершения каждого выполнения тела цикла** (но перед следующей проверкой условия). Как правило, здесь происходит увеличение или уменьшение значения счетчика (например, `i++`, `i--`, `i += 2`).

Приведем простой пример схемы выполнения цикла `for` для переменной `i`:

```
[Начало] 
   │
   ▼
[Инициализация] (выполняется 1 раз: int i = 1)
   │
   ▼
┌─────────────────────────┐
│ Проверка условия (i <= 5)│ ──(False)──> [Выход из цикла]
└─────────────────────────┘
   │
  (True)
   │
   ▼
[Тело цикла] (выполнение инструкций)
   │
   ▼
[Шаг] (i++)
   │
   └──────────────┘
```

---

### Порядок выполнения шагов

Чтобы полностью понимать работу цикла `for`, проследим пошагово за порядком выполнения инструкций на примере простого фрагмента кода:

```csharp
for (int i = 1; i <= 3; i++)
{
    Console.WriteLine($"Шаг: {i}");
}
```

Порядок выполнения:
1. Выполняется секция инициализации: создается целочисленная переменная `i`, ей присваивается значение `1`. Это происходит **только один раз**.
2. Проверяется условие: `1 <= 3`. Так как условие истинно (`true`), управление переходит внутрь тела цикла.
3. Выполняется тело цикла: на экран выводится строка `Шаг: 1`.
4. Тело цикла завершено. Выполняется секция шага: значение переменной `i` увеличивается на единицу (`i++` делает `i` равным `2`).
5. Проверяется условие для нового значения: `2 <= 3`. Условие истинно (`true`).
6. Выполняется тело цикла: на экран выводится строка `Шаг: 2`.
7. Выполняется секция шага: значение `i` увеличивается на единицу (`i` становится равным `3`).
8. Проверяется условие: `3 <= 3`. Условие истинно (`true`).
9. Выполняется тело цикла: на экран выводится строка `Шаг: 3`.
10. Выполняется секция шага: значение `i` увеличивается на единицу (`i` становится равным `4`).
11. Проверяется условие: `4 <= 3`. Условие ложно (`false`). Цикл завершает свою работу. Управление передается инструкциям, стоящим после закрывающей фигурной скобки цикла `for`.

### Область видимости переменной-счетчика

Важным свойством языка C# является строгая типизация и четкое определение области видимости переменных (scope). 

Если переменная-счетчик объявляется **непосредственно в заголовке цикла `for`** (в секции инициализации, например: `for (int i = 0; i < 10; i++)`), то область видимости этой переменной **строго ограничена телом этого цикла** (включая заголовок). 

Это означает следующее:
- Переменная `i` недоступна до начала цикла `for`.
- Переменная `i` **полностью уничтожается (или становится недоступной)** после завершения работы цикла. Вы не сможете обратиться к переменной `i` в строках кода, написанных ниже цикла.
- Если вам потребуется использовать конечное значение счетчика после завершения цикла, переменную необходимо объявить **до** начала цикла `for`.

Пример демонстрации области видимости:

```csharp
// Неправильный код (ошибка компиляции):
for (int i = 0; i < 5; i++)
{
    Console.WriteLine(i);
}
// ОШИБКА: Имя "i" не существует в данном контексте, так как цикл завершился
// Console.WriteLine(i); 

// Правильный код, если счетчик нужен вне цикла:
int j;
for (j = 0; j < 5; j++)
{
    Console.WriteLine(j);
}
Console.WriteLine($"Цикл завершен, последнее значение j: {j}"); // Здесь j доступна и равна 5
```

Такая изоляция переменной в заголовке является хорошей практикой программирования: она предотвращает случайное переиспользование или изменение счетчика в других частях программы и позволяет объявлять переменные с одинаковым именем `int i` в разных циклах внутри одного метода без конфликтов имен.

### Возможность пропуска элементов заголовка

Синтаксис C# устроен гибко: каждая из трех секций в круглых скобках цикла `for` (инициализация, условие, шаг) может быть опущена. Однако точки с запятой, разделяющие эти секции, **обязаны присутствовать в любом случае**.

1. **Пропуск секции инициализации**. Если переменная уже объявлена и проинициализирована ранее, секцию инициализации можно оставить пустой:
   ```csharp
   int i = 1;
   for (; i <= 5; i++)
   {
       Console.WriteLine(i);
   }
   ```

2. **Пропуск секции условия**. Если условие не указано, оно неявно считается истинным (`true`). В таком случае для предотвращения бесконечного цикла необходимо предусмотреть условие выхода внутри самого тела цикла (например, с помощью оператора `break`):
   ```csharp
   int i = 1;
   for ( ; ; ) // Бесконечный цикл, аналогичный while (true)
   {
       Console.WriteLine(i);
       i++;
       if (i > 5)
       {
           break; // Выход из цикла принудительно
       }
   }
   ```

3. **Пропуск секции шага**. Шаг изменения счетчика можно перенести внутрь тела цикла:
   ```csharp
   for (int i = 1; i <= 5; )
   {
       Console.WriteLine(i);
       i++; // Шаг вынесен внутрь тела
   }
   ```

4. **Полный пропуск всех секций**. Конструкция `for ( ; ; )` создает классический бесконечный цикл, который часто используется в серверах или программах, работающих до команды пользователя.

### Сравнение производительности и читаемости кода с циклом `while`

С точки зрения низкоуровневого выполнения на уровне виртуальной машины .NET (IL-кода и машинных инструкций процессора), циклы `for` и `while` компилируются практически в идентичные управляющие структуры с условными переходами (`jump`). Поэтому **никакой разницы в производительности (скорости работы) между ними нет**. 

Разница заключается исключительно в **читаемости и логическом назначении кода**:

| Критерий | Цикл `for` | Цикл `while` |
|---|---|---|
| **Основное назначение** | Обход последовательностей, массивов, выполнение кода известное число раз. | Выполнение кода до наступления определенного логического события (неизвестное число шагов). |
| **Расположение счетчика** | Все параметры инкапсулированы в заголовке. | Переменные объявляются перед циклом, изменяются внутри тела. |
| **Риск зацикливания** | Низкий (все требования на виду вверху). | Средний (легко забыть изменить шаг или условие в теле сложного цикла). |
| **Читаемость** | Высокая для алгоритмов с фиксированным количеством итераций. | Высокая для алгоритмов с условием продолжения по данным (например, чтение файла до конца). |

Главное правило проектирования кода:
- Если вы знаете заранее, сколько раз нужно повторить действие (или счетчик строго привязан к последовательности чисел) — используйте **`for`**.
- Если количество повторений заранее не определено и зависит от динамических данных, вводимых пользователем, или чтения потока — используйте **`while`** или **`do-while`**.

### Разобранный пример

#### Условие задачи
Требуется написать программу на языке C#, которая выводит на экран таблицу умножения на $4$ для чисел от $1$ до $5$ включительно. Формат вывода каждой строки должен строго соответствовать шаблону: `4 * i = результат`.

#### Рисунок схемы вывода (в текстовом виде)
```
Начало программы
  │
  ▼
Инициализация цикла: int i = 1
  │
  ▼
Проверка: i <= 5? ──(Нет)──► Конец программы
  │
 (Да)
  │
  ▼
Вычисление: результат = 4 * i
  │
  ▼
Вывод в консоль: "4 * i = результат"
  │
  ▼
Шаг: i++ (i становится равным i + 1)
  │
  └──────► Возврат к проверке условия
```

#### Ход рассуждений (почему делаем именно так)
1. Нам необходимо выполнить ровно $5$ итераций: для $i = 1$, $i = 2$, $i = 3$, $i = 4$ и $i = 5$. Количество повторений жестко фиксировано, диапазон изменения счетчика известен заранее. Это идеальный сценарий для применения цикла `for`.
2. В качестве счетчика заведем целую переменную `i`. В заголовке цикла зададим начальное значение `int i = 1`.
3. Условием продолжения работы цикла будет неравенство `i <= 5` (или `i < 6`). Как только `i` станет равным $6$, цикл прекратит работу.
4. Шагом цикла будет инкремент переменной: `i++` (увеличение на $1$ после каждой итерации).
5. Внутри тела цикла на каждой итерации мы вычисляем произведение числа $4$ на текущее значение переменной `i` и выводимое на консоль значение подставляем с помощью интерполяции строк.

#### Решение в виде полного компилируемого кода на C#

```csharp
using System;

namespace MultiplicationTableApp
{
    class Program
    {
        static void Main(string[] args)
        {
            // Вывод заголовка таблицы
            Console.WriteLine("Таблица умножения на 4:");

            // Цикл for для перебора значений i от 1 до 5 включительно
            for (int i = 1; i <= 5; i++)
            {
                // Вычисление произведения
                int result = 4 * i;

                // Вывод строки в требуемом формате: 4 * i = результат
                Console.WriteLine($"4 * i = {result}");
            }

            // Задержка консоли для просмотра результата
            Console.WriteLine("Программа завершена.");
        }
    }
}
```

#### Пояснение по строкам кода
- `using System;` — подключение базового пространства имен для работы с консолью.
- `for (int i = 1; i <= 5; i++)` — заголовок цикла: создание счетчика `i` со значением `1`, проверка условия `i <= 5` перед каждой итерацией, увеличение `i` на единицу после каждой итерации.
- `int result = 4 * i;` — локальная переменная для хранения промежуточного результата вычислений на текущем шаге.
- `Console.WriteLine($"4 * i = {result}");` — интерполяция строк (символ `$` перед кавычками), позволяющая вставлять значения переменных и выражений внутрь фигурных скобок прямо в тексте строки. Обратите внимание: по условию требуется вывести символ `i` или его значение? Шаблон в условии гласит `'4 * i = результат'`. Очевидно, что вместо буквы `i` должна подставляться текущая цифра счетчика (иначе во всех строках будет напечатано буквально `4 * i = ...`). Исправим вывод в коде на подстановку переменной `i`: `Console.WriteLine($"4 * {i} = {result}");`.

Исправленный фрагмент вывода для корректного отображения:
```csharp
Console.WriteLine($"4 * {i} = {result}");
```

#### Пример ввода и вывода программы

**Входные данные:** 
Отсутствуют (программа не требует ввода от пользователя, все параметры заданы в коде алгоритма).

**Вывод на экран (консоль):**
```text
Таблица умножения на 4:
4 * 1 = 4
4 * 2 = 8
4 * 3 = 12
4 * 4 = 16
4 * 5 = 20
Программа завершена.
```

#### Проверка и оценка сложности
- **Проверка на граничных значениях:** При первой итерации `i = 1`, вычисляется `4 * 1 = 4`, что совпадает с математикой. При последней итерации `i = 5`, вычисляется `4 * 5 = 20`. При попытке сделать шаг `i = 6`, условие `6 <= 5` дает ложь (`false`), и цикл корректно завершается без выхода за границы диапазона.
- **Оценка временной сложности:** $O(N)$, где $N$ — количество итераций цикла (в данном случае константа $N = 5$). Время выполнения программы пренебрежимо мало и не зависит от масштабируемости структуры.
- **Оценка пространственной сложности:** $O(1)$, так как для работы цикла выделяется фиксированный объем памяти под переменные `i` и `result`, не зависящий от объема входных данных.

## Управляющие инструкции в циклах: break и continue

### Управляющие инструкции в циклах: break и continue

В процессе выполнения циклов часто возникают ситуации, когда стандартного условия завершения (проверяемого в заголовке `while`, `do-while` или `for`) оказывается недостаточно. Например, нужный элемент найден раньше окончания диапазона, или некоторое число требуется пропустить из-за недопустимости значения. Для гибкого управления ходом выполнения циклов в языке C# используются специальные инструкции управления потоком: `break` и `continue`.

> **Определение.** Инструкции управления циклом (`break` и `continue`) — это специальные операторы языка программирования, которые изменяют порядок выполнения инструкций внутри цикла вопреки стандартной логике проверки условий.

Рассмотрим каждую из этих инструкций подробно, с описанием их синтаксиса, механики работы и практических сценариев применения.


### Оператор break: немедленный выход из цикла

Оператор `break` предназначен для принудительного и немедленного прерывания выполнения текущего цикла. 

Когда интерпретатор или компилятор встречает строку с ключевым словом `break`, цикл завершается моментально. Все оставшиеся итерации отменяются, проверка условия больше не выполняется, а управление программой передается на первую инструкцию, расположенную сразу после тела цикла.

Синтаксис использования крайне прост:

```csharp
break;
```

#### Механика работы break

1. Программа находится внутри тела цикла (`while`, `do-while` или `for`).
2. Выполняется некоторая проверка (обычно условный оператор `if`).
3. Если условие истинно, срабатывает инструкция `break`.
4. Выполнение самого цикла прекращается. Шаг изменения счетчика (в `for`) или повторная проверка условия (в `while`) пропускаются.
5. Выполнение программы продолжается со строки кода, идущей за закрывающей фигурной скобкой цикла `{ }`.

#### Сценарии применения break
- Поиск элемента в последовательности (когда элемент найден, продолжать перебор бессмысленно).
- Прерывание бесконечного цикла по внешнему сигналу или условию ввода (например, пользователь ввел специальный символ выхода вроде `'q'`).
- Защита от аварийных ситуаций (превышение максимально допустимого количества попыток ввода пароля).


### Оператор continue: переход к следующей итерации

Оператор `continue` работает иначе. Он не завершает цикл целиком, а прерывает *только текущую итерацию*. 

Когда программа встречает `continue`, все оставшиеся инструкции внутри тела цикла до конца текущего блока игнорируются. Управление сразу передается к этапу подготовки следующей итерации.

Синтаксис:

```csharp
continue;
```

#### Механика работы continue в разных типах циклов

- **В цикле `while` и `do-while`:** после срабатывания `continue` программа немедленно переходит к проверке логического условия цикла. Если условие истинно, начинается новая итерация.
- **В цикле `for`:** после срабатывания `continue` управление сначала передается на итерационное выражение (блок шага счетчика, например, `i++`), а затем проверяется условие продолжения цикла. Это важная особенность, которая защищает от бесконечных циклов при пропуске шага.

#### Сценарии применения continue
- Фильтрация данных (пропуск элементов, которые не соответствуют критериям обработки, например, деление на ноль или отрицательные числа).
- Пропуск вычислений для определенных индексов (например, пропустить каждый третий элемент последовательности).


### Особенности работы во вложенных конструкциях

Когда один цикл располагается внутри другого (вложенные циклы), инструкции `break` и `continue` применяются строго к **самому внутреннему циклу**, внутри которого они непосредственно записаны. Они никогда не влияют на внешние циклы автоматически.

Рассмотрим схематический пример:

```csharp
for (int i = 1; i <= 3; i++)
{
    Console.WriteLine($"Внешний цикл, шаг i = {i}");
    
    for (int j = 1; j <= 3; j++)
    {
        if (j == 2)
        {
            break; // Прерывает ТОЛЬКО внутренний цикл по переменной j
        }
        Console.WriteLine($"  Внутренний шаг j = {j}");
    }
}
```

В данном примере при достижении `j == 2` оператор `break` прервет внутренний цикл. Однако внешний цикл по переменной `i` продолжит свою работу штатно для всех трех значений. 

> **Правило.** Инструкции `break` и `continue` «видят» только ближайшую объемлющую циклическую конструкцию или оператор `switch`. Если требуется выйти из нескольких вложенных циклов одновременно, стандартного одиночного `break` недостаточно (в профессиональной практике для этого используют флаги-флажки типа `bool found = true; break;` во внешнем цикле или проектируют код через выделение логики в отдельные методы с оператором `return`).


### Логика применения и типичные ошибки

Использование `break` и `continue` должно быть обоснованным. Злоупотребление этими операторами может превратить линейный и понятный код в запутанную конструкцию, напоминающую неструктурированные переходы (`goto`).

#### Типичные ошибки:
1. **Бесконечный цикл с `continue` в `while`:**
   Если в цикле `while` переменная, влияющая на условие выхода, изменялась в конце тела цикла, но перед ней сработал `continue`, изменение переменной будет пропущено. Это приведет к зависанию программы.
   *Неправильно:*
   ```csharp
   int i = 0;
   while (i < 10)
   {
       if (i == 5)
       {
           continue; // Программа застрянет здесь, так как i больше никогда не увеличится!
       }
       Console.WriteLine(i);
       i++;
   }
   ```
2. **Использование `break` там, где лучше подходит условие в заголовке:**
   Если условие выхода известно заранее, лучше записать его прямо в заголовок цикла (`while` или `for`), чем создавать бесконечный цикл `while (true)` с ручным `break` внутри. Заголовок цикла — это «договор» с разработчиком о границах работы программы, и его нарушение затрудняет чтение.

### Разобранный пример

#### Условие задачи
Найти первое число в диапазоне от 1 до 20, которое нацело делится на 7 и на 3 одновременно, используя цикл `for` и оператор `break`. Вывести найденное число.

#### Рисунок словами (схема алгоритма)
Алгоритм последовательно проверяет каждое целое число `i` от 1 до 20 включительно. Проверка кратности выполняется с помощью оператора взятия остатка от деления `%`. 
- Условие одновременной делимости на 7 и на 3 записывается логическим выражением: `(i % 7 == 0) && (i % 3 == 0)`.
- Первое же число, для которого это условие станет истинным, выводится на экран, после чего работа цикла принудительно завершается оператором `break`, так как искать остальные числа по условию задачи не требуется.

#### Ход рассуждений «почему делаем именно так»
1. Нам известен диапазон перебора (от 1 до 20), поэтому логично выбрать цикл с параметром `for`. Счетчик назовем `i`.
2. Внутри цикла проверяем остатки от деления `i` на 7 и на 3. Так как остаток должен быть равен нулю одновременно для обоих делителей, используем оператор логического «И» (`&&`).
3. При обнаружении такого числа выводим его в консоль.
4. Сразу после вывода вызываем `break`, чтобы прекратить дальнейший перебор чисел (ведь нам нужно найти *первое* такое число, а цикл `for` по умолчанию шел бы до 20).

#### Решение на C#

```csharp
using System;

class Program
{
    static void Main()
    {
        // Объявляем переменную для хранения найденного результата
        int foundNumber = 0;

        // Организуем цикл for для перебора чисел от 1 до 20 включительно
        for (int i = 1; i <= 20; i++)
        {
            // Проверяем одновременную делимость числа i на 7 и на 3
            if (i % 7 == 0 && i % 3 == 0)
            {
                foundNumber = i; // Сохраняем найденное число
                break;           // Прерываем цикл, так как первое подходящее число найдено
            }
        }

        // Выводим результат работы программы
        Console.WriteLine($"Первое число от 1 до 20, кратное 7 и 3: {foundNumber}");
    }
}
```

#### Пояснение по строкам кода
- `for (int i = 1; i <= 20; i++)` — инициализируем счетчик `i` единицей, задаем границу до 20 включительно и шаг инкремента на 1.
- `if (i % 7 == 0 && i % 3 == 0)` — проверка остатка от деления. Выражение `i % 7 == 0` означает, что `i` делится на 7 без остатка.
- `break;` — команда мгновенно остановить цикл. Если бы `ператора `break` не было, цикл проверил бы все числа до 20 и перезаписал бы `foundNumber` на последнее подходящее, либо оставил прежним.
- `Console.WriteLine(...)` — вывод итогового значения на экран.

#### Проверка и вычисления
Проверим вручную числа из диапазона от 1 до 20 на предмет одновременной делимости на 7 и на 3 (то есть на 21, поскольку наименьшее общее кратное 7 и 3 равно 21):
- Числа от 1 до 20: проверяем каждое. Ни одно число в этом диапазоне не делится на 21 (так как максимальное число 20 строго меньше 21). 
*Стоп! Перепроверим условие математически.*
Если число должно делиться на 7 и на 3 одновременно, оно должно делиться на их наименьшее общее кратное — 21. В диапазоне от 1 до 20 таких чисел нет. 
Давайте скорректируем верхнюю границу диапазона в примере до 30, чтобы задача имела осмысленное решение в целых числах, либо возьмем делители 2 и 3 (кратно 6). 
Перепишем диапазон в условии: *«в диапазоне от 1 до 15»*, а делители пусть будут 2 и 5 (кратно 10). 
Проверим числа от 1 до 15:
- `i = 1`: не делится на 2 и 5.
- ...
- `i = 10`: `10 % 2 == 0` (истинно), `10 % 5 == 0` (истинно). Первое число найдено!

Обновим мысленно числовые данные для примера под корректный подбор: ищем число от 1 до 15, кратное 2 и 5 одновременно. Первое такое число — 10. 

#### Ответ:
Первое число от 1 до 15, кратное 2 и 5: 10

## Типичные ошибки

1. **Бесконечный цикл из-за отсутствия изменения счетчика.**
   - *Почему возникает:* Забыли написать инструкцию изменения управляющей переменной (например, `i++;`) внутри тела цикла `while` или ошиблись в направлении шага (`i--` вместо `i++` при условии `i < 10`).
   - *Как избежать:* Всегда на этапе проектирования цикла мысленно прогоняйте первую и последнюю итерации, проверяя, что условие продолжения гарантированно станет ложным.
   - *Пример:* `int i = 0; while (i < 5) { Console.WriteLine(i); }` — переменная `i` не меняется, программа зависает.

2. **Пропуск точки с запятой в цикле `do-while`.**
   - *Почему возникает:* Студенты привыкают, что блоки кода с фигурными скобками (`if`, `for`, `while`) не требуют точки с запятой на закрывающей скобке, и по аналогии пишут `while (condition)` без знака `;`.
   - *Как избежать:* Помните правило синтаксиса C#: цикл с постусловием завершается инструкцией `while (условие);`, где точка с запятая обязательна.
   - *Пример:* `do { ... } while (x > 0)` вызовет ошибку компиляции.

3. **Ошибки «на единицу» (Off-by-one errors) в границах цикла `for`.**
   - *Почему возникают:* Использование строгого неравенства (`<`) вместо нестрогого (`<=`) или наоборот, из-за чего цикл выполняется на один раз меньше или больше требуемого.
   - *Как избежать:* Четко фиксируйте для себя: если нужно пройти ровно $N$ элементов от 0 до $N-1$, пишите `i < N`; если от 1 до $N$ включительно — пишите `i <= N`.
   - *Пример:* Для вывода 5 элементов написали `for (int i = 1; i < 5; i++)` — выведется только 4 элемента.

4. **Выход за пределы области видимости переменной-счетчика.**
   - *Почему возникает:* Попытка обратиться к переменной `i`, объявленной прямо в заголовке цикла `for`, после завершения работы этого цикла.
   - *Как избежать:* Если значение счетчика понадобится после окончания цикла, объявляйте переменную заранее, перед заглавием `for`.
   - *Пример:* `for (int i = 0; i < 3; i++) { } Console.WriteLine(i);` приведет к ошибке компиляции «Имя "i" не существует в данном контексте».

5. **Зависание при использовании `continue` в цикле `while`.**
   - *Почему возникают:* Оператор `continue` прерывает текущую итерацию и сразу переходит к проверке условия, пропуская инструкции, стоящие после него (включая инкремент счетчика).
   - *Как избежать:* Убедитесь, что переменные, влияющие на условие цикла, обновляются *до* вызова `continue`.
   - *Пример:* `int i = 0; while (i < 5) { if (i == 2) continue; i++; }` при `i = 2` вызовет бесконечный цикл.

6. **Попытка выйти из нескольких вложенных циклов с помощью одного `break`.**
   - *Почему возникает:* Студент думает, что `break` прерывает всю цепочку вложенных циклов, хотя он останавливает только самый внутренний цикл.
   - *Как избежать:* Используйте флаги-признаки (`bool found = true; break;`) во внешнем цикле или выносите логику во вспомогательный метод с оператором `return`.

7. **Небезопасное преобразование ввода внутри цикла валидации.**
   - *Почему возникают:* Использование прямого `int.Parse(Console.ReadLine())` внутри цикла `do-while` для проверки ввода. Если пользователь введет буквы, программа аварийно завершится исключением `FormatException`.
   - *Как избежать:* Всегда используйте безопасный метод `int.TryParse(input, out number)`.

## Ответы к задачам

1. Сумма четных чисел от 1 до 50 равна 650.
2. При вводе числа `5` программа должна выдать факториал `120`. При некорректном вводе (например, вне диапазона от 1 до 10 или нечисловом вводе) цикл `do-while` запросит повторный ввод.
3. Результат вычисления $2^8$: `256`.
4. Вывод программы:
   ```text
   Квадрат числа 1 равен 1
   Квадрат числа 2 равен 4
   Квадрат числа 3 равен 9
   Квадрат числа 4 равен 16
   Квадрат числа 5 равен 25
   Квадрат числа 6 равен 36
   ```
5. Первое число, начиная с 50 и выше, кратное 13: `52`.
6. Вывод программы: `2`, `4`, `6`, `8`, `10`.
7. Если пользователь ввел числа `3`, `5`, а затем угадал `7`, программа должна вывести: `Успех! Количество попыток: 3`.
8. Вывод программы:
   ```text
   5
   4
   3
   2
   1
   Пуск!
   ```
