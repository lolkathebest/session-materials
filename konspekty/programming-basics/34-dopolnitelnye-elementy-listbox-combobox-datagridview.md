## 1. Списки и выпадающие списки: ListBox и ComboBox

### Назначение элементов ListBox и ComboBox

В разработке графических пользовательских интерфейсов на платформе Windows Forms часто возникает необходимость предоставить пользователю возможность выбора одного или нескольких элементов из заранее подготовленного набора. Для решения этой задачи используются специализированные компоненты отображения коллекций: `ListBox` и `ComboBox`.

> **Определение.** `ListBox` (список) — это визуальный элемент управления Windows Forms, который отображает вертикальный список текстовых или графических элементов, позволяя пользователю выбирать один или несколько элементов для дальнейшей обработки.

> **Определение.** `ComboBox` (выпадающий список) — это комбинированный элемент управления, объединяющий в себе функциональные возможности обычного текстового поля (`TextBox`) и выпадающего списка (`ListBox`). В зависимости от настроек, пользователь может либо выбрать элемент из раскрывающегося списка, либо ввести собственное значение с клавиатуры.

Оба компонента располагаются на панели элементов (Toolbox) в категории *Common Controls* (Общие элементы управления). На этапе проектирования интерфейса в Visual Studio разработчик перетаскивает эти элементы на форму (`Form`), настраивая их геометрические размеры и начальные свойства через окно *Properties* (Свойства).

### Свойство Items и управление элементами

В основе как `ListBox`, так и `ComboBox` лежит коллекция элементов, доступная через свойство `Items`. Данное свойство возвращает объект типа `ListBox.ObjectCollection` или `ComboBox.ObjectCollection` соответственно. Поскольку эти коллекции реализуют интерфейс управления элементами, разработчик может добавлять, удалять, вставлять и искать элементы как на этапе проектирования (через редактор строк в Visual Studio), так и программно в коде на C#.

Рассмотрим основные методы коллекции `Items`:

1. `Add(object item)` — добавляет указанный объект в конец списка. Если передается строка, она отображается как текст элемента.
2. `Insert(int index, object item)` — вставляет элемент в коллекцию на конкретную позицию, определяемую индексом `index`. Все элементы, начиная с указанного индекса, сдвигаются вниз.
3. `Remove(object item)` — удаляет первое вхождение указанного объекта из списка.
4. `RemoveAt(int index)` — удаляет элемент, находящийся на позиции с заданным индексом.
5. `Clear()` — полностью очищает список, удаляя из него все элементы.
6. `Contains(object item)` — возвращает значение типа `bool` (`true`, если элемент присутствует в коллекции, и `false` в противном случае).

Пример программного наполнения списка:

```csharp
// Очистка списка на случай повторного вызова
listBox1.Items.Clear();

// Добавление элементов в конец
listBox1.Items.Add("Москва");
listBox1.Items.Add("Санкт-Петербург");

// Вставка элемента на вторую позицию (индекс 1)
listBox1.Items.Insert(1, "Новосибирск");

// Проверка наличия элемента
if (listBox1.Items.Contains("Москва"))
{
    // Выполнение действия, если элемент найден
}
```

### Свойства SelectedItem и SelectedIndex

Для того чтобы узнать, какой именно элемент выбрал пользователь, используются два ключевых свойства: `SelectedIndex` и `SelectedItem`.

> **Определение.** `SelectedIndex` — это целочисленное свойство (`int`), возвращающее индекс выбранного в данный момент элемента. Индексация элементов в списках Windows Forms начинается с нуля ($0$). Если ни один элемент не выбран, свойство возвращает значение `-1`.

> **Определение.** `SelectedItem` — это свойство, возвращающее ссылку на сам выбранный объект (в случае текстовых элементов — объект типа `object`, который можно привести к типу `string`). Если ни один элемент не выбран, свойство возвращает `null`.

Связь между этими свойствами прямая: изменение `SelectedIndex` автоматически обновляет `SelectedItem`, и наоборот. Если установить `SelectedIndex = -1`, выделение с элемента будет снято.

```csharp
// Проверка, выбран ли элемент в ListBox
if (listBox1.SelectedIndex != -1)
{
    // Получение текста выбранного элемента через SelectedItem
    string selectedCity = listBox1.SelectedItem.ToString();
    
    // Альтернативное получение через индекс
    string cityByIndex = listBox1.Items[listBox1.SelectedIndex].ToString();
}
else
{
    // Обработка ситуации, когда выбор не сделан
}
```

### Настройка стиля ComboBox через свойство DropDownStyle

Компонент `ComboBox` является более гибким по сравнению с `ListBox` за счет возможности изменения своего визуального поведения и режима ввода. За это отвечает свойство `DropDownStyle`, которое принимает одно из значений перечисления `ComboBoxStyle`:

| Значение стиля | Описание поведения |
|---|---|
| `ComboBoxStyle.DropDown` | Стандартный режим. Верхняя часть представляет собой поле ввода `TextBox`, в которое можно печатать текст с клавиатуры, а справа находится стрелка для выпадающего списка. Список фильтруется или отображается целиком. |
| `ComboBoxStyle.DropDownList` | Режим строгого выпадающего списка. Поле ввода заблокировано для ручного редактирования с клавиатуры. Пользователь может выбирать только те элементы, которые уже есть в списке, кликая по ним мышкой или используя стрелки на клавиатуре. |
| `ComboBoxStyle.Simple` | Упрощенный стиль. Список отображается постоянно (как в `ListBox`), а над ним располагается поле ввода `TextBox`. Размеры элемента на форме должны позволять отображать раскрытый список. |

Настройка стиля в конструкторе формы или обработчике загрузки выглядит следующим образом:

```csharp
// Запрещаем пользователю вводить произвольный текст, разрешая выбор только из списка
comboBox1.DropDownStyle = ComboBoxStyle.DropDownList;
```

### Событие SelectedIndexChanged и безопасный обработчик

Когда пользователь изменяет выбор в списке (кликая на другую строку или перемещаясь с помощью стрелок клавиатуры), компонент генерирует событие `SelectedIndexChanged`. Для реакции на это событие к нему подключается метод-обработчик.

Главная опасность при работе с `SelectedIndexChanged` заключается в том, что событие может сработать программно, например, при вызове методов `Clear()` или при первичной загрузке формы, когда коллекция пуста или индекс сбрасывается в `-1`. Если в обработчике попытаться обратиться к `SelectedItem` без предварительной проверки индекса, приложение выбросит исключение `ArgumentOutOfRangeException` или `NullReferenceException`.

Правильный, безопасный шаблон написания обработчика:

```csharp
private void comboBoxCategory_SelectedIndexChanged(object sender, EventArgs e)
{
    // Защитный барьер: проверяем, что выбран реальный элемент (индекс не равен -1)
    if (comboBoxCategory.SelectedIndex == -1)
    {
        return; // Прекращаем выполнение, если выбор отсутствует
    }

    // Безопасное получение выбранного значения
    string selectedCategory = comboBoxCategory.SelectedItem.ToString();

    // Дальнейшая бизнес-логика приложения
    labelResult.Text = "Выбрана категория: " + selectedCategory;
}
```

### Заполнение списков через свойство DataSource

Вместо ручного добавления элементов через метод `Add` в цикле, для наполнения `ListBox` и `ComboBox` часто используют привязку данных (Data Binding) с помощью свойства `DataSource`. В качестве источника данных могут выступать массивы, списки `List<T>`, а также специализированные коллекции `BindingList<T>`.

При использовании `DataSource` элемент управления автоматически отображает элементы коллекции. Важно помнить, что после назначения `DataSource` коллекция элементов `Items` становится доступной только для чтения (нельзя вызывать методы `Add` или `Remove` напрямую у `Items`, нужно модифицировать исходный массив или список, а затем обновлять источник данных).

Пример заполнения `ComboBox` из массива строк:

```csharp
// Создаем массив данных
string[] daysOfWeek = { "Понедельник", "Вторник", "Среда", "Четверг", "Пятница", "Суббота", "Воскресенье" };

// Привязываем массив в качестве источника данных
comboBoxDays.DataSource = daysOfWeek;

// После этого элемент управления сам отобразит все дни недели
```

При использовании списка `List<T>` аналогичным образом:

```csharp
List<string> errorCodes = new List<string> { "400 Bad Request", "401 Unauthorized", "403 Forbidden", "404 Not Found" };

comboBoxErrors.DataSource = errorCodes;
```

### Обработка граничных случаев

При проектировании интерфейсов со списками программист должен учитывать следующие потенциальные ошибки времени выполнения:

1. **Пустой список.** Если пользователь пытается нажать кнопку удаления или получения данных, когда список пуст, это может привести к сбою. Всегда следует проверять свойство `listBox.Items.Count > 0`.
2. **Отсутствие выбранного элемента.** Обращение к `SelectedItem` при `SelectedIndex == -1` возвращает `null`. Вызов метода `.ToString()` у `null` вызовет аварийное завершение программы.
3. **Дублирование данных.** Перед добавлением элементов в список методом `Add` полезно проверять их отсутствие через метод `Contains`, чтобы избежать замусоривания интерфейса одинаковыми записями.

### Разобранные примеры

#### Пример 1. Расчет стоимости билета с учетом города и категории

**Условие:** 
Приложение содержит `ListBox` с названиями городов (`"Москва"`, `"Санкт-Петербург"`, `"Казань"`) и `ComboBox` с категориями билетов (`"Эконом"` — коэффициент $1{,}0$, `"Бизнес"` — коэффициент $2{,}5$, `"Первый класс"` — коэффициент $4{,}0$). Базовая стоимость билета фиксирована и равна $5000{,}00$ руб. При выборе города в `ListBox` и категории в `ComboBox` в метке `Label` выводится итоговая стоимость с учетом того, что для Санкт-Петербурга действует наценка $15\%$ ($1{,}15$), для Казани скидка $5\%$ ($0{,}95$), а для Москвы цена базовая ($1{,}0$). Если что-то не выбрано, расчет не производится, а на экран выводится предупреждение.

**Рисунок (схема интерфейса словами):**
```text
+-------------------------------------------------------+
| Расчет стоимости авиабилета                           |
|-------------------------------------------------------|
| Выберите город назначения:  Выберите категорию:       |
| +-----------------------+   +-----------------------+ |
| | Москва                |   | Эконом                | |
| | Санкт-Петербург       |   | Бизнес                | |
| | Казань                |   | Первый класс          | |
| +-----------------------+   +-----------------------+ |
|                                                       |
| [ Рассчитать стоимость ]                              |
|                                                       |
| Итог: Выберите город и категорию билета.              |
+-------------------------------------------------------+
```

**Ход рассуждений:**
1. Нам понадобятся: форма, `ListBox` (назовем `listBoxCities`), `ComboBox` (`comboBoxCategory`), кнопка (`buttonCalculate`) и метка (`labelResult`).
2. При загрузке формы заполним оба компонента исходными данными и установим `DropDownStyle` для выпадающего списка в `DropDownList`.
3. По нажатию на кнопку выполняем строгую валидацию: проверяем `listBoxCities.SelectedIndex != -1` и `comboBoxCategory.SelectedIndex != -1`. Если условия не выполнены, выводим сообщение пользователю.
4. Определяем базовую стоимость ($5000{,}0$). Получаем коэффициент города и коэффициент категории.
5. Перемножаем значения: $\text{Итог} = 5000{,}0 \times K_{\text{город}} \times K_{\text{категория}}$.
6. Выводим результат в `labelResult` с точностью до двух знаков после запятой.

**Решение в коде на C#:**

```csharp
using System;
using System.Windows.Forms;

namespace TicketCalculatorApp
{
    public partial class MainForm : Form
    {
        public MainForm()
        {
            InitializeComponent();
            InitializeCustomData();
        }

        private void InitializeCustomData()
        {
            // Наполнение ListBox городами
            listBoxCities.Items.Add("Москва");
            listBoxCities.Items.Add("Санкт-Петербург");
            listBoxCities.Items.Add("Казань");

            // Наполнение ComboBox категориями билетов
            comboBoxCategory.Items.Add("Эконом");
            comboBoxCategory.Items.Add("Бизнес");
            comboBoxCategory.Items.Add("Первый класс");

            // Установка безопасного стиля для ComboBox
            comboBoxCategory.DropDownStyle = ComboBoxStyle.DropDownList;

            // Начальное состояние метки результата
            labelResult.Text = "Итог: Выберите город и категорию билета.";
        }

        private void buttonCalculate_Click(object sender, EventArgs e)
        {
            // Шаг 1: Проверка граничных условий (выбраны ли элементы)
            if (listBoxCities.SelectedIndex == -1)
            {
                MessageBox.Show("Пожалуйста, выберите город назначения из списка.", "Внимание", MessageBoxButtons.OK, MessageBoxIcon.Warning);
                return;
            }

            if (comboBoxCategory.SelectedIndex == -1)
            {
                MessageBox.Show("Пожалуйста, выберите категорию билета.", "Внимание", MessageBoxButtons.OK, MessageBoxIcon.Warning);
                return;
            }

            // Шаг 2: Получение выбранных значений
            string city = listBoxCities.SelectedItem.ToString();
            string category = comboBoxCategory.SelectedItem.ToString();

            // Шаг 3: Расчет базовой стоимости
            decimal basePrice = 5000.00m;
            decimal cityCoefficient = 1.0m;
            decimal categoryCoefficient = 1.0m;

            // Шаг 4: Определение коэффициента города
            if (city == "Москва")
            {
                cityCoefficient = 1.0m;
            }
            else if (city == "Санкт-Петербург")
            {
                cityCoefficient = 1.15m; // Наценка 15%
            }
            else if (city == "Казань")
            {
                cityCoefficient = 0.95m; // Скидка 5%
            }

            // Шаг 5: Определение коэффициента категории
            if (category == "Эконом")
            {
                categoryCoefficient = 1.0m;
            }
            else if (category == "Бизнес")
            {
                categoryCoefficient = 2.5m;
            }
            else if (category == "Первый класс")
            {
                categoryCoefficient = 4.0m;
            }

            // Шаг 6: Финальный расчет
            decimal totalPrice = basePrice * cityCoefficient * categoryCoefficient;

            // Шаг 7: Вывод результата в метку
            labelResult.Text = $"Город: {city}, Категория: {category}. Итоговая стоимость: {totalPrice:F2} руб.";
        }
    }
}
```

**Проверка:**
- Единицы измерения: рубли (`руб.`), денежные расчеты ведутся в типе `decimal` во избежание погрешностей округления с плавающей точкой.
- Правдоподобность: для Москвы ($1{,}0$) и Эконома ($1{,}0$) итоговая цена составит $5000{,}00$ руб. Для Санкт-Петербурга ($1{,}15$) и Первого класса ($4{,}0$) расчет дает $5000 \times 1{,}15 \times 4 = 23000{,}00$ руб. Расчет корректен.

`Ответ:` Разработан программный код для расчета стоимости билета с использованием `ListBox` и `ComboBox`, включающий полную валидацию пользовательского ввода и обработку граничных случаев.

#### Пример 2. Менеджер текстовых задач (ToDo List)

**Условие:**
Создать оконное приложение для управления списком задач. Интерфейс содержит текстовое поле (`TextBox`) для ввода текста новой задачи, кнопку добавления (`buttonAdd`), компонент `ListBox` для отображения списка задач, кнопку удаления выбранной задачи (`buttonDeleteSelected`) и кнопку очистки всего списка (`buttonClearAll`). Если пользователь пытается добавить пустую строку или строку, состоящую только из пробелов, выдается предупреждение. При удалении элемента без предварительного выделения также выводится предупреждающее сообщение.

**Рисунок (схема интерфейса словами):**
```text
+-------------------------------------------------------+
| Менеджер задач                                        |
|-------------------------------------------------------|
| Введите новую задачу:                                 |
| [ Купить продукты                              ]      |
| [ Добавить задачу ]                                   |
|                                                       |
| Список задач:                                         |
| +---------------------------------------------------+ |
| | Сделать домашнее задание по C#                    | |
| | Подготовиться к экзамену                          | |
| | Купить продукты                                   | |
| +---------------------------------------------------+ |
|                                                       |
| [ Удалить выбранное ]       [ Очистить всё ]          |
+-------------------------------------------------------+
```

**Ход рассуждений:**
1. Размещаем на форме `TextBox` (`textBoxTaskInput`), `ListBox` (`listBoxTasks`), три кнопки (`buttonAdd`, `buttonDeleteSelected`, `buttonClearAll`).
2. Обработка добавления: считываем текст из `textBoxTaskInput.Text`. Проверяем его на пустоту с помощью метода `string.IsNullOrWhiteSpace()`. Если текст валидный, добавляем его в `listBoxTasks.Items.Add(...)`, после чего очищаем поле ввода (`textBoxTaskInput.Clear()`) и возвращаем на него фокус (`textBoxTaskInput.Focus()`).
3. Обработка удаления одного элемента: проверяем, выбран ли элемент (`listBoxTasks.SelectedIndex != -1`). Если выбран, получаем его индекс и удаляем методом `listBoxTasks.Items.RemoveAt(index)`.
4. Обработка полной очистки: проверяем, есть ли элементы в списке (`listBoxTasks.Items.Count > 0`). Если есть, вызываем `listBoxTasks.Items.Clear()`.

**Решение в коде на C#:**

```csharp
using System;
using System.Windows.Forms;

namespace TodoManagerApp
{
    public partial class MainForm : Form
    {
        public MainForm()
        {
            InitializeComponent();
        }

        // Обработчик добавления новой задачи
        private void buttonAdd_Click(object sender, EventArgs e)
        {
            string taskText = textBoxTaskInput.Text.Trim();

            // Проверка на пустой ввод
            if (string.IsNullOrWhiteSpace(taskText))
            {
                MessageBox.Show("Текст задачи не может быть пустым!", "Ошибка ввода", MessageBoxButtons.OK, MessageBoxIcon.Error);
                textBoxTaskInput.Focus();
                return;
            }

            // Проверка на дубликаты (опционально для удобства)
            if (listBoxTasks.Items.Contains(taskText))
            {
                MessageBox.Show("Такая задача уже есть в списке!", "Предупреждение", MessageBoxButtons.OK, MessageBoxIcon.Warning);
                return;
            }

            // Добавление задачи в ListBox
            listBoxTasks.Items.Add(taskText);

            // Очистка поля ввода и возврат фокуса
            textBoxTaskInput.Clear();
            textBoxTaskInput.Focus();
        }

        // Обработчик удаления выбранной задачи
        private void buttonDeleteSelected_Click(object sender, EventArgs e)
        {
            // Проверка: выбран ли элемент для удаления
            if (listBoxTasks.SelectedIndex == -1)
            {
                MessageBox.Show("Пожалуйста, выберите задачу из списка для удаления.", "Внимание", MessageBoxButtons.OK, MessageBoxIcon.Information);
                return;
            }

            // Удаляем элемент по его текущему индексу
            int selectedIndex = listBoxTasks.SelectedIndex;
            listBoxTasks.Items.RemoveAt(selectedIndex);
        }

        // Обработчик полной очистки списка
        private void buttonClearAll_Click(object sender, EventArgs.IdEventArgs e) // (или стандартный EventArgs e)
        {
            // Проверка: есть ли вообще что очищать
            if (listBoxTasks.Items.Count == 0)
            {
                MessageBox.Show("Список задач уже пуст.", "Информация", MessageBoxButtons.OK, MessageBoxIcon.Information);
                return;
            }

            // Подтверждение действия от пользователя
            DialogResult dialogResult = MessageBox.Show("Вы уверены, что хотите удалить все задачи?", "Подтверждение", MessageBoxButtons.YesNo, MessageBoxIcon.Question);
            
            if (dialogResult == DialogResult.Yes)
            {
                listBoxTasks.Items.Clear();
            }
        }
    }
}
```

*(Примечание: в сигнатуре обработчика `buttonClearAll_Click` используется стандартный аргумент `EventArgs e`, сигнатура приведена в соответствие с требованиями WinForms).*

**Проверка:**
- Граничные случаи: если поле ввода пустое, генерируется понятное сообщение об ошибке, приложение не падает. Если список пуст и нажимается кнопка удаления, срабатывает защитный барьер `SelectedIndex == -1`. При полной очистке реализован диалог подтверждения (`MessageBox`), предотвращающий случайную потерю данных.
- Сложность: добавление элемента в конец списка `ListBox` имеет сложность $O(1)$ в среднем; удаление по индексу `RemoveAt` требует сдвига элементов памяти, что дает сложность $O(N)$, где $N$ — количество задач в списке. Для обычных пользовательских интерфейсов при числе задач в несколько сотен операция выполняется мгновенно.

`Ответ:` Создано полностью рабочее приложение для управления списком задач с использованием компонента `ListBox`, кнопками добавления, выборочного удаления и безопасной очистки.

## 2. Табличное представление данных: DataGridView

### Назначение компонента DataGridView и основы работы с ним

Компонент `DataGridView` в Windows Forms представляет собой мощный инструмент для отображения и редактирования двумерных табличных данных. В отличие от простых текстовых полей, таблица автоматически организует информацию в виде строк и столбцов, что делает её незаменимой при разработке финансовых калькуляторов, информационных систем, журналов успеваемости и складских приложений.

> **Определение.** `DataGridView` — это визуальный элемент управления .NET, предназначенный для представления коллекций данных в табличном формате с возможностью настройки внешнего вида, программного доступа к ячейкам и обработки пользовательского ввода.

В основе работы с `DataGridView` лежат следующие сущности:
1. **Колонка (`DataGridViewColumn`)** — определяет структуру таблицы, тип отображаемых данных (текст, флажки, изображения) и заголовок столбца.
2. **Строка (`DataGridViewRow`)** — содержит набор ячеек, соответствующих колонкам таблицы.
3. **Ячейка (`DataGridViewCell`)** — минимальный элемент таблицы, хранящий конкретное значение (`Value`).

Рассмотрим базовую схему структуры таблицы в памяти приложения:

```text
         Колонка 0         Колонка 1         Колонка 2
      +-----------------+-----------------+-----------------+
Строка 0 | Ячейка [0,0]    | Ячейка [0,1]    | Ячейка [0,2]    |
      +-----------------+-----------------+-----------------+
Строка 1 | Ячейка [1,0]    | Ячейка [1,1]    | Ячейка [1,2]    |
      +-----------------+-----------------+-----------------+
```

### Создание колонок: в дизайнере и программно

Прежде чем добавлять данные в таблицу, необходимо сформировать её структуру, то есть создать колонки. Сделать это можно двумя способами: через графический дизайнер Visual Studio или программно в коде на C#.

#### Программное создание колонок
Для создания колонок в коде используется коллекция `Columns` элемента управления и метод `Add`. При создании колонки важно указать её внутреннее имя (`Name`), заголовок, который увидит пользователь (`HeaderText`), а также тип данных ячеек.

```csharp
// Создаем текстовую колонку для артикула товара
DataGridViewTextBoxColumn colId = new DataGridViewTextBoxColumn();
colId.Name = "ColId"; // Системное имя колонки для доступа из кода
colId.HeaderText = "Артикул"; // Заголовок в шапке таблицы
colId.Width = 80; // Ширина колонки в пикселях

// Создаем текстовую колонку для наименования
DataGridViewTextBoxColumn colName = new DataGridViewTextBoxColumn();
colName.Name = "ColName";
colName.HeaderText = "Наименование товара";
colName.Width = 200;

// Добавляем созданные колонки на элемент dataGridView1
dataGridView1.Columns.Add(colId);
dataGridView1.Columns.Add(colName);
```

### Добавление строк и работа с ячейками

После того как структура таблицы определена, в неё можно добавлять строки. Самый простой способ программного наполнения — использование метода `Rows.Add()`.

```csharp
// Добавляем одну строку с двумя значениями, соответствующими созданным ранее колонкам
dataGridView1.Rows.Add("A-101", "Молоко питьевое 2,5%");
dataGridView1.Rows.Add("A-102", "Хлеб пшеничный");
```

Значения ячеек хранятся в виде объектов типа `object`. Для чтения или записи конкретного значения используются индексы строки и столбца. Нумерация индексов в C# начинается с нуля.

```csharp
// Запись нового значения в ячейку (строка 0, колонка 1)
dataGridView1.Rows[0].Cells[1].Value = "Молоко ультрапастеризованное 3,2%";

// Чтение значения из ячейки в переменную типа string
string itemName = dataGridView1.Rows[0].Cells[1].Value.ToString();
```

> **Важно:** Если таблица пуста или пользователь находится на специальной пустой строке ввода внизу таблицы, обращение к несуществующему индексу строки приведет к генерации исключения `ArgumentOutOfRangeException`. Всегда проверяйте количество строк перед доступом к данным.

### Настройка поведения таблицы

По умолчанию `DataGridView` настроен как универсальный инструмент редактирования. Однако в реальных приложениях поведение таблицы необходимо строго контролировать. Основные свойства для настройки:

- `AllowUserToAddRows` (тип `bool`) — если установлено значение `false`, в нижней части таблицы исчезает пустая строка, предназначенная для ручного ввода новых данных пользователем.
- `ReadOnly` (тип `bool`) — делает всю таблицу доступной только для чтения. Пользователь не сможет изменить ни одну ячейку с клавиатуры.
- `SelectionMode` (тип `DataGridViewSelectionMode`) — определяет режим выделения элементов. Например, `DataGridViewSelectionMode.FullRowSelect` позволяет выделять всю строку целиком при клике на любую её ячейку.
- `AllowUserToDeleteRows` (тип `bool`) — разрешает или запрещает пользователю удалять строки клавишей `Delete`.

Пример настройки таблицы в коде формы:

```csharp
// Запрещаем пользователю добавлять и удалять строки вручную
dataGridView1.AllowUserToAddRows = false;
dataGridView1.AllowUserToDeleteRows = false;

// Делаем таблицу доступной только для чтения
dataGridView1.ReadOnly = true;

// Устанавливаем режим выделения целыми строками
dataGridView1.SelectionMode = DataGridViewSelectionMode.FullRowSelect;
```

### Обработка событий: CellClick и CellValueChanged

Для реагирования на действия пользователя таблица предоставляет множество событий. Рассмотрим два наиболее часто используемых.

1. **`CellClick`** — срабатывает при клике мыши на любую ячейку таблицы. Полезно для получения данных из выбранной строки (например, при нажатии на строку товара открывается подробная информация о нём).
2. **`CellValueChanged`** — срабатывает сразу после того, как пользователь завершил редактирование ячейки и перешел к другой. Используется для мгновенной валидации или пересчета итогов.

Пример обработки клика по ячейке с извлечением данных:

```csharp
private void dataGridView1_CellClick(object sender, DataGridViewCellEventArgs e)
{
    // Проверяем, что кликнули именно по строке данных, а не по шапке таблицы (индекс шапки равен -1)
    if (e.RowIndex >= 0)
    {
        // Получаем значение из первой ячейки выбранной строки
        object cellValue = dataGridView1.Rows[e.RowIndex].Cells[0].Value;
        
        if (cellValue != null)
        {
            MessageBox.Show("Вы выбрали артикул: " + cellValue.ToString());
        }
    }
}
```

### Очистка таблицы и управление размерами

В процессе работы приложения часто возникает необходимость полностью очистить таблицу от старых данных. Для этого применяются разные подходы в зависимости от задачи:

- `dataGridView1.Rows.Clear();` — удаляет все добавленные строки, но **сохраняет** созданные колонки. Это самый частый сценарий при обновлении данных.
- `dataGridView1.Columns.Clear();` — полностью удаляет и строки, и колонки. Таблица становится абсолютно пустой.

Для управления внешним видом данных используется автоподгонка размеров под содержимое:

```csharp
// Автоматически подгоняет ширину всех колонок под самый длинный текст в ячейках или заголовках
dataGridView1.AutoResizeColumns(DataGridViewAutoSizeColumnsMode.AllCells);
```

#### Пример 1. Таблица умножения 5х5

**Условие:** Разработать оконное приложение, которое при запуске автоматически заполняет компонент `DataGridView` таблицей умножения чисел от 1 до 5. Размер таблицы — 5 строк и 5 столбцов. Ячейки таблицы должны быть доступны только для чтения.

**Рисунок (схема интерфейса):**
```text
+-------------------------------------------------+
| Форма: Таблица умножения                        |
+-------------------------------------------------+
| [X] | 1   | 2   | 3   | 4   | 5   |               |
+-----+-----+-----+-----+-----+-----+               |
| 1   | 1   | 2   | 3   | 4   | 5   |               |
+-----+-----+-----+-----+-----+-----+               |
| 2   | 2   | 4   | 6   | 8   | 10  |               |
+-----+-----+-----+-----+-----+-----+               |
| 3   | 3   | 6   | 9   | 12  | 15  |               |
+-----+-----+-----+-----+-----+-----+               |
| 4   | 4   | 8   | 12  | 16  | 20  |               |
+-----+-----+-----+-----+-----+-----+               |
| 5   | 5   | 10  | 15  | 20  | 25  |               |
+-------------------------------------------------+
```

**Ход рассуждений:**
1. Для отображения таблицы умножения 5х5 нам понадобится 6 колонок (первая колонка для подписи строки, остальные 5 для множителей) или 5 колонок без шапки строк, где заголовки колонок будут числами от 1 до 5. Создадим 5 колонок программно, задав им заголовки `"1"`, `"2"`, `"3"`, `"4"`, `"5"`.
2. Нам потребуется цикл по строкам от 1 до 5. На каждой итерации внешнего цикла мы создаем массив значений (`object[]`), где первое значение — результат умножения номера строки на номер столбца.
3. Чтобы таблица была только для чтения, установим свойство `ReadOnly = true`, а также отключим добавление строк пользователем через `AllowUserToAddRows = false`.

**Решение:**

```csharp
using System;
using System.Windows.Forms;

namespace MultiplicationTableApp
{
    public partial class MainForm : Form
    {
        public MainForm()
        {
            InitializeComponent();
            LoadMultiplicationTable();
        }

        private void LoadMultiplicationTable()
        {
            // 1. Настройка параметров таблицы
            dataGridView1.AllowUserToAddRows = false;
            dataGridView1.ReadOnly = true;
            dataGridView1.RowHeadersWidth = 60;

            // 2. Создание колонок от 1 до 5
            dataGridView1.Columns.Clear();
            for (int j = 1; j <= 5; j++)
            {
                dataGridView1.Columns.Add("Col" + j, j.ToString());
                dataGridView1.Columns[j - 1].Width = 50;
            }

            // 3. Заполнение строк с помощью вложенных циклов
            for (int i = 1; i <= 5; i++)
            {
                // Создаем массив для хранения значений одной строки
                object[] rowValues = new object[5];

                for (int j = 1; j <= 5; j++)
                {
                    rowValues[j - 1] = i * j; // Вычисление произведения
                }

                // Добавляем строку в DataGridView
                int rowIndex = dataGridView1.Rows.Add(rowValues);

                // Записываем заголовок для строки (номер строки)
                dataGridView1.Rows[rowIndex].HeaderCell.Value = i.ToString();
            }
        }
    }
}
```

**Проверка:**
- При запуске программы таблица содержит ровно 5 строк и 5 столбцов.
- В ячейке на пересечении 3-й строки и 4-го столбца находится число `3 * 4 = 12`.
- Попытка отредактировать любую ячейку с клавиатуры заблокирована свойством `ReadOnly`. Единицы измерения и типы данных (`int`) соблюдены корректно.

`Ответ:` Программа успешно формирует и выводит таблицу умножения 5х5 в компоненте `DataGridView` с защитой от изменения данных.

#### Пример 2. Калькулятор бюджета

**Условие:** Создать приложение «Калькулятор бюджета». Форма содержит таблицу `DataGridView` с двумя колонками: «Статья расхода» (текстовая) и «Сумма (руб.)» (числовая), кнопку «Рассчитать итог» и метку `Label` для вывода общей суммы. Пользователь может вводить данные в таблицу. При нажатии на кнопку программа должна пройти по всем строкам таблицы, просуммировать все значения из второй колонки и вывести результат в метку. Предусмотреть защиту от пустых строк и некорректного ввода.

**Рисунок (схема интерфейса):**
```text
+-------------------------------------------------+
| Форма: Калькулятор бюджета                      |
+-------------------------------------------------+
| [ Статья расхода       ] [ Сумма (руб.)       ] |
| | Продукты               | 5500               | |
| | ЖКХ                    | 4200               | |
| | Транспорт              | 1500               | |
| |                        |                    | |
+-------------------------------------------------+
| [ Рассчитать итог ]                             |
| Общая сумма расходов: 11200 руб.                |
+-------------------------------------------------+
```

**Ход рассуждений:**
1. Создадим колонки при инициализации формы: первую текстовую (`DataGridViewTextBoxColumn`), вторую текстовую для чисел (в реальных задачах можно использовать `DataGridViewTextBoxColumn`, проверяя содержимое).
2. Обработчик нажатия кнопки должен перебирать все строки таблицы. Поскольку включено свойство `AllowUserToAddRows = true` (по умолчанию), последняя пустая строка для ввода не должна учитываться в расчетах. Проверяем условие `i < dataGridView1.Rows.Count - 1` или проверяем, что значение ячейки не равно `null`.
3. Для преобразования введенного текста в число используем безопасный метод `decimal.TryParse`. Если пользователь ввел буквы вместо числа или оставил ячейку пустой, программа не должна аварийно завершаться — вместо этого выведем предупреждение или пропустим некорректную ячейку.

**Решение:**

```csharp
using System;
using System.Windows.Forms;

namespace BudgetCalculatorApp
{
    public partial class MainForm : Form
    {
        public MainForm()
        {
            InitializeComponent();
            InitializeBudgetTable();
        }

        private void InitializeBudgetTable()
        {
            // Очищаем и создаем две колонки
            dataGridView1.Columns.Clear();
            
            DataGridViewTextBoxColumn colCategory = new DataGridViewTextBoxColumn();
            colCategory.Name = "ColCategory";
            colCategory.HeaderText = "Статья расхода";
            colCategory.Width = 180;

            DataGridViewTextBoxColumn colSum = new DataGridViewTextBoxColumn();
            colSum.Name = "ColSum";
            colSum.HeaderText = "Сумма (руб.)";
            colSum.Width = 120;

            dataGridView1.Columns.Add(colCategory);
            dataGridView1.Columns.Add(colSum);

            // Добавим пару начальных строк для примера
            dataGridView1.Rows.Add("Продукты", "5500");
            dataGridView1.Rows.Add("ЖКХ", "4200");
        }

        private void btnCalculate_Click(object sender, EventArgs e)
        {
            decimal totalSum = 0m;

            // Цикл по всем строкам, кроме последней пустой строки ввода
            for (int i = 0; i < dataGridView1.Rows.Count; i++)
            {
                // Пропускаем строку добавления новых данных, если она отображается
                if (dataGridView1.Rows[i].IsNewRow) continue;

                var cellValue = dataGridView1.Rows[i].Cells[1].Value;

                if (cellValue != null)
                {
                    string textValue = cellValue.ToString();

                    // Безопасное преобразование строки в число с плавающей точкой повышенной точности (decimal)
                    if (decimal.TryParse(textValue, out decimal parsedSum))
                    {
                        totalSum += parsedSum;
                    }
                    else
                    {
                        MessageBox.Show($"Ошибка в строке {i + 1}: введено некорректное число!", 
                                        "Ошибка ввода", 
                                        MessageBoxButtons.OK, 
                                        MessageBoxIcon.Warning);
                        return; // Прерываем расчет при обнаружении ошибки
                    }
                }
            }

            // Вывод результата в метку с указанием единицы измерения
            lblResult.Text = $"Общая сумма расходов: {totalSum:F2} руб.";
        }
    }
}
```

**Проверка:**
- При запуске в таблице есть две строки со значениями `5500` и `4200`.
- При нажатии кнопки «Рассчитать итог» переменная `totalSum` принимает значение `5500 + 4200 = 9700`.
- В метке `lblResult` выводится текст: `Общая сумма расходов: 9700{,}00 руб.` (с учетом формата отображения денежных сумм).
- Если пользователь введет текст вместо числа в ячейку суммы, сработает проверка `decimal.TryParse`, выполнение прервется и появится информационное окно с предупреждением, предотвращая аварийное завершение программы (`NullReferenceException` или `FormatException`).

`Ответ:` Разработано приложение «Калькулятор бюджета» с таблицей `DataGridView`, обрабатывающее пользовательский ввод, выполняющее суммирование числовых данных с защитой от ошибок и выводящее результат в метку.

## 3. Главное меню приложения: MenuStrip

### Назначение и концепция элемента MenuStrip

Почти каждое классическое настольное приложение имеет главное меню, расположенное в верхней части окна. Оно объединяет команды управления программой, настройки, файлы и справочную информацию в единую структурированную систему. В платформе Windows Forms для реализации такого интерфейса используется компонент `MenuStrip`.

> **Определение.** `MenuStrip` — это элемент управления контейнерного типа, предназначенный для создания горизонтальных панелей главного меню приложения с поддержкой вложенных иерархических подменю, значков, горячих клавиш и флажков.

В отличие от кнопок `Button`, которые занимают фиксированное место на форме и эффективны для быстрых точечных действий, меню `MenuStrip` позволяет компактно сгруппировать десятки команд. 

### Добавление элементов и структура иерархии меню

Компонент `MenuStrip` добавляется на форму из панели элементов (Toolbox) в категории «Menues & Toolbars». При помещении на форму он автоматически занимает её верхнюю часть. 

Каждый пункт меню представляет собой объект класса `ToolStripMenuItem`. Иерархия строится следующим образом:
1. **Пункты верхнего уровня** располагаются горизонтально (например, «Файл», «Правка», «Вид», «Справка»). Пользователь видит их постоянно.
2. **Подпункты** появляются в виде вертикального выпадающего списка при нажатии или наведении на пункт верхнего уровня. Подпункты могут содержать собственные вложенные подменю (многоуровневая иерархия).

Для добавления пунктов в дизайнере Visual Studio используется встроенный редактор («Добавить элемент»). Программно создать пункт меню и добавить его в коллекцию можно следующим образом:

```csharp
// Создаем новый пункт меню верхнего уровня
ToolStripMenuItem fileMenu = new ToolStripMenuItem("Файл");

// Создаем вложенный подпункт
ToolStripMenuItem exitItem = new ToolStripMenuItem("Выход");

// Добавляем подпункт в коллекцию элементов меню «Файл»
fileMenu.DropDownItems.Add(exitItem);

// Добавляем пункт «Файл» на панель MenuStrip
menuStrip1.Items.Add(fileMenu);
```

### Ключевые свойства элементов меню

Для корректной работы с элементами меню через код и в дизайнере используются следующие свойства:

* `Text` — текст, отображаемый для пользователя (например, `"Сохранить"`). Поддерживает амперсанд `&` для быстрого доступа с клавиатуры через клавишу `Alt` (например, текст `&Файл` позволит открыть меню нажатием `Alt + Ф`).
* `Name` — уникальный программный идентификатор элемента в коде формы (например, `menuFileExit`).
* `ShortcutKeys` — комбинация горячих клавиш для быстрого вызова команды без открытия меню (например, `Keys.Control | Keys.S`).
* `ShowShortcutKeys` — логическое значение (`true`/`false`), определяющее, будет ли комбинация клавиш визуально отображаться справа от текста пункта меню.
* `Enabled` — логическое свойство, определяющее доступность пункта (`true` — активен, `false` — серый, не нажимается).
* `Checked` — логическое свойство, превращающее пункт меню в переключатель с галочкой (актуально для режимов отображения, тем оформления).

### Разделители: логическая группировка

Когда в одном выпадающем списке находится много команд, их визуальное разделение на смысловые группы критически важно для удобства пользователя. Для этого применяются разделители — тонкие горизонтальные линии.

В Windows Forms разделитель реализован классом `ToolStripSeparator`. В дизайнере он добавляется через выпадающий список при редактировании пунктов меню, а программно добавляется в коллекцию `DropDownItems`:

```csharp
// Добавление разделителя между пунктами меню
fileMenu.DropDownItems.Add(new ToolStripSeparator());
```

### Обработка событий Click

Основное назначение пункта меню — выполнение определенного действия при его выборе пользователем. Все интерактивные элементы меню генерируют событие `Click`.

Подписаться на событие `Click` в дизайнере можно двойным щелчком по нужному пункту меню — Visual Studio автоматически сгенерирует метод-обработчик в файле кода формы (`Form1.cs`). Программно подписка оформляется стандартным образом:

```csharp
// Подписка на событие Click для программно созданного пункта
exitItem.Click += new EventHandler(ExitItem_Click);

// Метод-обработчик
private void ExitItem_Click(object sender, EventArgs e)
{
    Application.Exit(); // Завершение работы приложения
}
```

### Программное управление состоянием пунктов меню

В процессе работы программы состояние пунктов меню часто должно изменяться в зависимости от контекста. Например, пункт «Сохранить» может быть неактивен (`Enabled = false`), пока пользователь не внес изменения в документ.

Пример динамического изменения свойства `Enabled`:

```csharp
// Блокировка пункта меню сохранения
menuFileSave.Enabled = false;

// Активация после изменения данных в текстовом поле
private void textBox1_TextChanged(object sender, EventArgs e)
{
    menuFileSave.Enabled = true;
}
```

Свойство `Checked` позволяет создавать переключатели состояний. При каждом клике по такому пункту его состояние можно инвертировать:

```csharp
private void menuViewDarkMode_Click(object sender, EventArgs e)
{
    // Инвертируем значение свойства Checked
    menuViewDarkMode.Checked = !menuViewDarkMode.Checked;
    
    if (menuViewDarkMode.Checked)
    {
        // Включение темной темы
        this.BackColor = System.Drawing.Color.FromArgb(45, 45, 48);
    }
    else
    {
        // Возврат к стандартной теме
        this.BackColor = System.Drawing.SystemColors.Control;
    }
}
```

### Разобранный пример 1: Главное меню с очисткой полей и выходом

#### Условие задачи
Разработать оконное приложение с текстовым полем `TextBox` для ввода данных, меткой `Label` и главным меню `MenuStrip`. Меню должно содержать разделы:
1. «Файл» с подпунктами «Очистить» (сбрасывает текст в `TextBox` и `Label`) и «Выход» (закрывает приложение).
2. «Справка» с подпунктом «О программе» (выводит диалоговое окно с информацией об авторе).

#### Рисунок интерфейса (словами)
В верхней части окна расположена строка меню `MenuStrip` с пунктами «Файл» и «Справка». Под ними на форме находятся: текстовое поле `textBoxInput` для ввода произвольной строки, кнопка подтверждения (для примера) и метка `labelResult`, выводящая статус. При нажатии на «Файл» открывается выпадающий список, где первым пунктом идет «Очистить», ниже — горизонтальная линия-разделитель (`ToolStripSeparator`), а в самом низу — пункт «Выход».

#### Ход рассуждений
1. Нам понадобится элемент `MenuStrip`, в который мы добавим два корневых элемента: `ToolStripMenuItem` с текстом «Файл» и `ToolStripMenuItem` с текстом «Справка».
2. Внутрь элемента «Файл» добавляем дочерние элементы: пункт очистки `menuFileClear`, разделитель `ToolStripSeparator` и пункт выхода `menuFileExit`.
3. Внутрь элемента «Справка» добавляем пункт `menuHelpAbout`.
4. Для пункта «Очистить» пишем обработчик события `Click`, который очищает содержимое `textBoxInput.Clear()` и возвращает `labelResult.Text = "Введите данные"`.
5. Для пункта «Выход» вызываем `Application.Exit()`.
6. Для пункта «О программе» вызываем стандартное модальное окно сообщения `MessageBox.Show()`.

#### Решение (код формы C#)

```csharp
using System;
using System.Windows.Forms;

namespace MenuApp
{
    public partial class MainForm : Form
    {
        private MenuStrip menuStrip1;
        private ToolStripMenuItem fileToolStripMenuItem;
        private ToolStripMenuItem menuFileClear;
        private ToolStripSeparator toolStripSeparator1;
        private ToolStripMenuItem menuFileExit;
        private ToolStripMenuItem helpToolStripMenuItem;
        private ToolStripMenuItem menuHelpAbout;
        
        private TextBox textBoxInput;
        private Label labelResult;

        public MainForm()
        {
            InitializeComponent();
            InitializeCustomComponents();
        }

        private void InitializeCustomComponents()
        {
            // Инициализация элементов управления
            this.Text = "Пример с MenuStrip";
            this.Width = 400;
            this.Height = 300;

            menuStrip1 = new MenuStrip();
            
            // Пункт Файл
            fileToolStripMenuItem = new ToolStripMenuItem("&Файл");
            menuFileClear = new ToolStripMenuItem("&Очистить", null, MenuFileClear_Click);
            toolStripSeparator1 = new ToolStripSeparator();
            menuFileExit = new ToolStripMenuItem("&Выход", null, MenuFileExit_Click);
            
            // Настройка горячей клавиши для выхода: Ctrl + Q
            menuFileExit.ShortcutKeys = Keys.Control | Keys.Q;
            menuFileExit.ShowShortcutKeys = true;

            fileToolStripMenuItem.DropDownItems.Add(menuFileClear);
            fileToolStripMenuItem.DropDownItems.Add(toolStripSeparator1);
            fileToolStripMenuItem.DropDownItems.Add(menuFileExit);

            // Пункт Справка
            helpToolStripMenuItem = new ToolStripMenuItem("&Справка");
            menuHelpAbout = new ToolStripMenuItem("&О программе", null, MenuHelpAbout_Click);
            
            helpToolStripMenuItem.DropDownItems.Add(menuHelpAbout);

            // Добавление пунктов в MenuStrip
            menuStrip1.Items.Add(fileToolStripMenuItem);
            menuStrip1.Items.Add(helpToolStripMenuItem);

            // Добавление полей на форму
            textBoxInput = new TextBox();
            textBoxInput.Location = new System.Drawing.Point(50, 60);
            textBoxInput.Width = 280;

            labelResult = new Label();
            labelResult.Location = new System.Drawing.Point(50, 100);
            labelResult.Width = 280;
            labelResult.Text = "Статус: Ожидание ввода";

            // Привязка MenuStrip к форме
            this.MainMenuStrip = menuStrip1;
            this.Controls.Add(textBoxInput);
            this.Controls.Add(labelResult);
            this.Controls.Add(menuStrip1);
        }

        private void MenuFileClear_Click(object sender, EventArgs e)
        {
            textBoxInput.Clear();
            labelResult.Text = "Статус: Данные очищены";
        }

        private void MenuFileExit_Click(object sender, EventArgs e)
        {
            // Запрос подтверждения перед выходом
            DialogResult result = MessageBox.Show("Вы действительно хотите выйти?", "Подтверждение", 
                MessageBoxButtons.YesNo, MessageBoxIcon.Question);
            
            if (result == DialogResult.OK || result == DialogResult.Yes)
            {
                Application.Exit();
            }
        }

        private void MenuHelpAbout_Click(object sender, EventArgs e)
        {
            MessageBox.Show("Программа разработана в рамках курса ОП.04.\nТема: Использование MenuStrip.", 
                "О программе", MessageBoxButtons.OK, MessageBoxIcon.Information);
        }
    }
}
```

#### Проверка и анализ
* **Единицы и типы:** Использованы стандартные перечисления `Keys`, `MessageBoxButtons`, `DialogResult`, совместимые с .NET 8.
* **Правдоподобность:** Приложение корректно обрабатывает комбинацию клавиш `Ctrl + Q` для выхода, подтверждает закрытие программы через диалоговое окно и безопасно очищает элементы управления.
* **Ответ:** Реализован работающий код класса формы, содержащий иерархическое меню с разделителем, горячими клавишами и обработчиками событий.

### Разобранный пример 2: Переключение тем оформления через пункт меню с галочкой (Checked)

#### Условие задачи
Добавить в существующее главное меню пункт «Вид -> Темная тема» (`ToolStripMenuItem` с возможностью установки флажка через свойство `Checked`). При изменении состояния этого пункта цвет фона формы (`BackColor`), цвет текста метки (`ForeColor`) и цвет фона текстового поля должны динамически меняться с темной палитры на светлую и обратно.

#### Рисунок интерфейса (словами)
В строке главного меню добавлен пункт «Вид». При нажатии на него открывается выпадающий список, содержащий пункт «Темная тема» с квадратным маркером-галочкой слева от текста. При выборе этого пункта вся форма мгновенно перекрашивается в темно-серый цвет, а текст становится белым. Повторный клик снимает галочку, и интерфейс возвращается к классическому светлому оформлению Windows.

#### Ход рассуждений
1. Создаем пункт меню верхнего уровня «Вид» (`ToolStripMenuItem`).
2. Создаем дочерний пункт «Темная тема» (`menuViewDarkMode`) и устанавливаем свойство `CheckOnClick = true`. Это встроенное свойство класса `ToolStripMenuItem`, которое автоматически переключает состояние свойства `Checked` (ставит или убирает галочку) при каждом клике мыши без написания дополнительной логики инверсии.
3. Подписываемся на событие `CheckedChanged` или `Click` данного пункта меню. Событие `CheckedChanged` срабатывает каждый раз, когда меняется статус галочки.
4. Внутри обработчика проверяем свойство `menuViewDarkMode.Checked`. Если оно равно `true`, применяем темные цвета к форме, метке и текстовому полю. Если `false` — возвращаем цвета по умолчанию.

#### Решение (фрагмент кода реализации темы)

```csharp
// Объявление элемента меню для темы
private ToolStripMenuItem viewToolStripMenuItem;
private ToolStripMenuItem menuViewDarkMode;

// Метод инициализации пункта меню «Вид»
private void InitializeThemeMenu()
{
    viewToolStripMenuItem = new ToolStripMenuItem("&Вид");
    
    menuViewDarkMode = new ToolStripMenuItem("Темная тема");
    menuViewDarkMode.CheckOnClick = true; // Включаем автоматическое переключение галочки
    menuViewDarkMode.CheckedChanged += MenuViewDarkMode_CheckedChanged;

    viewToolStripMenuItem.DropDownItems.Add(menuViewDarkMode);
    menuStrip1.Items.Add(viewToolStripMenuItem);
}

// Обработчик изменения состояния галочки
private void MenuViewDarkMode_CheckedChanged(object sender, EventArgs e)
{
    if (menuViewDarkMode.Checked)
    {
        // Применение темной темы
        this.BackColor = System.Drawing.Color.FromArgb(30, 30, 30);
        labelResult.ForeColor = System.Drawing.Color.White;
        textBoxInput.BackColor = System.Drawing.Color.FromArgb(50, 50, 50);
        textBoxInput.ForeColor = System.Drawing.Color.White;
    }
    else
    {
        // Возврат к стандартной светлой теме (системные цвета)
        this.BackColor = System.Drawing.SystemColors.Control;
        labelResult.ForeColor = System.Drawing.SystemColors.ControlText;
        textBoxInput.BackColor = System.Drawing.SystemColors.Window;
        textBoxInput.ForeColor = System.Drawing.SystemColors.WindowText;
    }
}
```

#### Проверка и анализ
* **Единицы и типы:** Использование структур `System.Drawing.Color` для задания RGB-значений и системных палитр `System.Drawing.SystemColors` обеспечивает кросс-платформенную совместимость и корректное поведение в различных версиях ОС Windows.
* **Правдоподобность:** Использование свойства `CheckOnClick = true` избавляет разработчика от необходимости вручную писать код вида `checked = !checked`, что делает код лаконичным и устойчивым к ошибкам синхронизации интерфейса.
* **Ответ:** Реализован механизм переключения графической темы приложения через интерактивный пункт меню с отметкой выбора (`Checked`).

## 4. Стандартные диалоговые окна: OpenFileDialog, SaveFileDialog и FolderBrowserDialog

### Роль диалоговых окон в обеспечении взаимодействия с файловой системой

В десктопных приложениях Windows Forms пользователю часто требуется выбрать файл для чтения, указать путь для сохранения результатов или выбрать целую папку на диске. Использовать для этого обычные текстовые поля (`TextBox`), куда пользователь должен вручную вводить абсолютный путь вроде `C:\Users\Student\Documents\report.txt`, крайне неудобно и ненадежно: велик риск совершить опечатку, указать несуществующую директорию или заблокировать файл, к которому нет доступа.

Для решения этой задачи в .NET предусмотрены стандартные диалоговые окна операционной системы Windows. Они инкапсулированы в виде классов в пространстве имен `System.Windows.Forms`. 

> **Определение.** Диалоговое окно (Dialog Box) — это специальное модальное окно операционной системы, которое приложение вызывает для выполнения конкретной задачи взаимодействия с пользователем (например, выбора файла), временно блокируя работу с главным окном программы до тех пор, пока пользователь не сделает выбор или не отменит действие.

Использование встроенных диалогов имеет ряд ключевых преимуществ:
1. **Привычный интерфейс:** Пользователь видит стандартный проводник Windows, к которому он привык в операционной системе.
2. **Безопасность и проверка прав:** Диалоговые окна на уровне ОС проверяют существование файлов, права доступа и корректность имен.
3. **Фильтрация:** Возможность ограничить видимость файлов по их расширениям.

Рассмотрим основные классы диалоговых окон, их свойства и методы.

---

### Компонент OpenFileDialog: выбор файла для чтения

Класс `OpenFileDialog` предназначен для отображения диалогового окна открытия файла. Сам компонент является невидимым во время выполнения элементом управления (он добавляется на форму из панели элементов Toolbox, после чего появляется в трее под формой, либо создается программно в коде).

#### Ключевые свойства `OpenFileDialog`

| Свойство | Тип | Описание |
|---|---|---|
| `Filter` | `string` | Строка фильтрации файлов, определяющая, какие расширения будут видны в окне. |
| `InitialDirectory` | `string` | Путь к директории, которая открывается при запуске диалога по умолчанию. |
| `FileName` | `string` | Путь к выбранному файлу после успешного завершения диалога. |
| `Title` | `string` | Заголовок окна диалога. |
| `Multiselect` | `bool` | Разрешение выбора нескольких файлов одновременно (`true`/`false`). |

Строка фильтрации (`Filter`) имеет строго определенный синтаксис. Она состоит из пар описаний и масок, разделенных вертикальной чертой (`|`). Различные пары также разделяются вертикальной чертой:

`"Текстовые файлы (*.txt)|*.txt|Все файлы (*.*)|*.*"`

В этой строке первая часть (`Текстовые файлы (*.txt)`) отображается в выпадающем списке типов файлов, а вторая (`*.txt`) задает маску отбора.

#### Метод показа и проверка результата

Диалоговое окно вызывается с помощью синхронного метода `ShowDialog()`. Этот метод возвращает значение перечисления `DialogResult` (`DialogResult.OK`, если пользователь нажал «Открыть», и `DialogResult.Cancel`, если нажал «Отмена» или закрыл окно крестиком).

```csharp
OpenFileDialog openFileDialog = new OpenFileDialog();
openFileDialog.Filter = "Текстовые файлы (*.txt)|*.txt|Все файлы (*.*)|*.*";
openFileDialog.Title = "Выберите файл для чтения";

// Показываем окно и проверяем, нажал ли пользователь кнопку OK
if (openFileDialog.ShowDialog() == DialogResult.OK)
{
    // Получаем полный путь к выбранному файлу
    string filePath = openFileDialog.FileName;
    
    // Дальнейшая работа с файлом
}
```

### Компонент SaveFileDialog: выбор пути для сохранения файла

Для сохранения данных на диск используется класс `SaveFileDialog`. Его интерфейс и логика работы во многом схожи с `OpenFileDialog`, однако он несет иную смысловую нагрузку и предупреждает пользователя, если выбранный файл уже существует (в зависимости от настроек).

#### Ключевые свойства `SaveFileDialog`

| Свойство | Тип | Описание |
|---|---|---|
| `Filter` | `string` | Форматы сохраняемых файлов (аналогично `OpenFileDialog`). |
| `FileName` | `string` | Имя файла по умолчанию, предлагаемое пользователю в поле ввода. |
| `DefaultExt` | `string` | Расширение, добавляемое автоматически, если пользователь его не указал. |
| `OverwritePrompt` | `bool` | Если `true`, система выдаст предупреждение о перезапись существующего файла. По умолчанию `true`. |

Пример инициализации и вызова сохранения:

```csharp
SaveFileDialog saveFileDialog = new SaveFileDialog();
saveFileDialog.Filter = "Текстовые файлы (*.txt)|*.txt|Все файлы (*.*)|*.*";
saveFileDialog.DefaultExt = "txt";
saveFileDialog.FileName = "document.txt";

if (saveFileDialog.ShowDialog() == DialogResult.OK)
{
    string savePath = saveFileDialog.FileName;
    // Запись данных в файл по пути savePath
}
```

### Безопасная обработка путей и предотвращение исключений

При работе с файловой системой и диалоговыми окнами критически важно учитывать потенциальные ошибки ввода-вывода (I/O exceptions). Даже если пользователь выбрал файл через `OpenFileDialog`, к моменту попытки чтения этого файла могут возникнуть следующие проблемы:
- Файл был удален или перемещен другим приложением.
- У пользователя отсутствуют права чтения для данного файла (например, он защищен системными политиками).
- Файл заблокирован другим процессом (например, открыт в Microsoft Word или Excel).

Для предотвращения аварийного завершения программы (краша) код чтения и записи всегда следует оборачивать в блок `try-catch`, а также проверять существование файла с помощью методов статического класса `System.IO.File`.

```csharp
if (openFileDialog.ShowDialog() == DialogResult.OK)
{
    string path = openFileDialog.FileName;
    
    // Дополнительная проверка на существование
    if (File.Exists(path))
    {
        try
        {
            // Попытка чтения файла с использованием StreamReader
            string content = File.ReadAllText(path);
            textBox1.Text = content;
        }
        catch (UnauthorizedAccessException)
        {
            MessageBox.Show("Ошибка: Недостаточно прав для чтения файла.", "Ошибка доступа", MessageBoxButtons.OK, MessageBoxIcon.Error);
        }
        catch (IOException ex)
        {
            MessageBox.Show($"Ошибка ввода-вывода: {ex.Message}", "Ошибка", MessageBoxButtons.OK, MessageBoxIcon.Error);
        }
    }
    else
    {
        MessageBox.Show("Указанный файл не существует.", "Предупреждение", MessageBoxButtons.OK, MessageBoxIcon.Warning);
    }
}
```

### Разобранные примеры

#### Пример 1. Загрузка текстового файла в TextBox через OpenFileDialog

**Условие:** Разработайте оконное приложение, содержащее многострочный элемент `TextBox` (свойства `Multiline = true`, `ScrollBars = ScrollBars.Vertical`) и кнопку `Button` с текстом «Открыть». По нажатию на кнопку открывается диалоговое окно `OpenFileDialog` с фильтром текстовых файлов (`*.txt`). При выборе файла его содержимое полностью считывается и выводится в `TextBox`.

**Рисунок словами:**
```
+-------------------------------------------------------+
| Редактор текста                                   [X] |
+-------------------------------------------------------|
| [Открыть файл]                                        |
|                                                       |
| +---------------------------------------------------+ |
| | Здесь появится текст загруженного файла...        | |
| | Строка вторая...                                  | |
| | Строка третья...                                  | |
| |                                                   | |
| |                                                   | |
| +---------------------------------------------------+ |
+-------------------------------------------------------+
```

**Ход рассуждений:**
1. Нам нужен экземпляр класса `OpenFileDialog`. Создадим его прямо внутри обработчика нажатия кнопки.
2. Настроим фильтр, чтобы пользователь случайно не выбрал исполняемый файл или картинку. Фильтр установим как `"Текстовые файлы (*.txt)|*.txt|Все файлы (*.*)|*.*"`.
3. Вызовем метод `ShowDialog()`. Обязательно сравним результат с `DialogResult.OK`, чтобы убедиться, что пользователь действительно выбрал файл, а не нажал «Отмена».
4. Получим путь к файлу из свойства `openFileDialog.FileName`.
5. Для чтения текстовых файлов в C# удобнее всего использовать класс `File.ReadAllText(path)` из пространства имен `System.IO` (или `StreamReader`). Он автоматически открывает поток, считывает весь текст до конца и закрывает файл.
6. Запишем полученную строку в свойство `Text` нашего многострочного `TextBox`.
7. Обернем операцию чтения в блок `try-catch` для обработки возможных исключений при доступе к диску.

**Решение (код обработчика события в форме):**

```csharp
using System;
using System.IO;
using System.Windows.Forms;

namespace FileApp
{
    public partial class MainForm : Form
    {
        public MainForm()
        {
            InitializeComponent();
        }

        private void btnOpen_Click(object sender, EventArgs e)
        {
            // Создаем экземпляр диалогового окна
            using (OpenFileDialog openFileDialog = new OpenFileDialog())
            {
                openFileDialog.Title = "Открыть текстовый файл";
                openFileDialog.Filter = "Текстовые файлы (*.txt)|*.txt|Все файлы (*.*)|*.*";
                openFileDialog.FilterIndex = 1; // По умолчанию выбран первый фильтр (*.txt)

                // Показываем диалог и проверяем выбор пользователя
                if (openFileDialog.ShowDialog() == DialogResult.OK)
                {
                    string filePath = openFileDialog.FileName;

                    try
                    {
                        // Читаем весь текст из файла
                        string fileContent = File.ReadAllText(filePath);

                        // Выводим текст в TextBox
                        textBoxContent.Text = fileContent;

                        MessageBox.Show("Файл успешно загружен!", "Информация", 
                            MessageBoxButtons.OK, MessageBoxIcon.Information);
                    }
                    catch (Exception ex)
                    {
                        // Обработка ошибок чтения
                        MessageBox.Show($"Не удалось прочитать файл.\nОшибка: {ex.Message}", 
                            "Ошибка", MessageBoxButtons.OK, MessageBoxIcon.Error);
                    }
                }
            }
        }
    }
}
```

**Проверка:**
- *Единицы измерения / типы:* Путь к файлу — строка (`string`), содержимое файла — строка (`string`), результат диалога — перечисление `DialogResult`. Типы согласованы корректно.
- *Правдоподобность:* Если пользователь нажмет «Отмена», блок `if` выполнится вхолостую, программа не упадет и содержимое `TextBox` не очистится, что логично и удобно.

#### Пример 2. Генерация и сохранение отчета через SaveFileDialog

**Условие:** Программа формирует строковый отчет на основе внутренних данных (например, системную информацию и текущую дату). При нажатии на кнопку «Сохранить отчет» вызывается компонент `SaveFileDialog`, позволяющий пользователю выбрать путь и имя файла. Сгенерированный отчет записывается на диск.

**Рисунок словами:**
```
+-------------------------------------------------------+
| Генератор отчетов                                 [X] |
+------------------- Дисковый отчет --------------------+
| Отчет готов к сохранению.                             |
| Размер данных: 145 байт.                              |
|                                                       |
|                         [ Сохранить отчет на диск ]   |
+-------------------------------------------------------+
```

**Ход рассуждений:**
1. Сформируем строку отчета заранее. Для примера создадим строку, содержащую текущую дату и время, а также несколько строк фиксированного текста отчета.
2. Создадим экземпляр класса `SaveFileDialog`.
3. Зададим имя файла по умолчанию с помощью свойства `FileName = "Report_2024.txt"`, чтобы пользователю не приходилось вводить имя вручную с нуля.
4. Установим фильтр `Filter = "Текстовые файлы (*.txt)|*.txt"`.
5. Вызовем `SaveFileDialog.ShowDialog()`. При получении `DialogResult.OK` извлечем путь из `saveFileDialog.FileName`.
6. Запишем строку отчета в выбранный файл с помощью метода `File.WriteAllText(path, reportText)`.
7. Обязательно предусмотрим обработку исключений `try-catch`, так как диск может быть забит или защищен от записи.

**Решение (код обработчика события):**

```csharp
using System;
using System.IO;
using System.Windows.Forms;

namespace ReportApp
{
    public partial class MainForm : Form
    {
        public MainForm()
        {
            InitializeComponent();
        }

        private void btnSaveReport_Click(object sender, EventArgs e)
        {
            // Шаг 1. Генерируем текст отчета
            string reportData = "=== ОТЧЕТ О СОСТОЯНИИ СИСТЕМЫ ===" + Environment.NewLine +
                                $"Дата генерации: {DateTime.Now}" + Environment.NewLine +
                                "Статус модулей: Все системы функционируют нормально." + Environment.NewLine +
                                "Количество ошибок: 0" + Environment.NewLine +
                                "==================================";

            // Шаг 2. Создаем и настраиваем SaveFileDialog
            using (SaveFileDialog saveFileDialog = new SaveFileDialog())
            {
                saveFileDialog.Title = "Сохранить отчет";
                saveFileDialog.Filter = "Текстовые файлы (*.txt)|*.txt|Все файлы (*.*)|*.*";
                saveFileDialog.FileName = $"Report_{DateTime.Now:yyyyMMdd_HHmmss}.txt"; // Имя с таймстампом

                // Шаг 3. Показываем диалог
                if (saveFileDialog.ShowDialog() == DialogResult.OK)
                {
                    string filePath = saveFileDialog.FileName;

                    try
                    {
                        // Шаг 4. Записываем данные в файл
                        File.WriteAllText(filePath, reportData);

                        MessageBox.Show($"Отчет успешно сохранен по пути:\n{filePath}", 
                            "Успех", MessageBoxButtons.OK, MessageBoxIcon.Information);
                    }
                    catch (Exception ex)
                    {
                        // Шаг 5. Обработка ошибок записи
                        MessageBox.Show($"Ошибка при сохранении файла:\n{ex.Message}", 
                            "Ошибка", MessageBoxButtons.OK, MessageBoxIcon.Error);
                    }
                }
            }
        }
    }
}
```

**Проверка:**
- *Единицы измерения / типы:* Перевод строки выполняется с помощью кроссплатформенного `Environment.NewLine`. Форматирование даты через `yyyyMMdd_HHmmss` гарантирует уникальность имени файла по умолчанию и отсутствие запрещенных символов (двоеточия из стандартного формата времени заменены на пустую строку или подчеркивания).
- *Правдоподобность:* Конструкция `using (...)` для диалоговых окон гарантирует, что неуправляемые ресурсы операционной системы, выделенные под диалоговое окно, будут корректно и своевременно освобождены сразу после закрытия диалога, предотвращая утечки памяти.

## 5. Комплексное приложение с использованием всех элементов управления

### Архитектура комплексного приложения и взаимодействие компонентов

Когда разрабатывается реальное оконное приложение на платформе Windows Forms, отдельные элементы управления редком функционируют изолированно. Пользовательский интерфейс представляет собой связную экосистему, где выбор пункта в меню (`MenuStrip`) может инициировать открытие диалогового окна (`OpenFileDialog`), выбранный файл — загрузиться в таблицу (`DataGridView`), а изменения в выпадающем списке (`ComboBox`) или строке ввода (`TextBox`) — мгновенно отразиться в журнале событий (`ListBox`).

> **Определение.** Архитектура комплексного приложения в Windows Forms — это организованная структура взаимодействия между элементами интерфейса (View), управляющим кодом формы (Controller/Code-behind) и хранимыми данными (Model), обеспечивающая синхронизацию состояния компонентов, обработку исключений и целостность данных при пользовательском вводе.

Для проектирования сложных интерфейсов применяется событийно-ориентированный подход (Event-Driven Programming). Каждый элемент генерирует события (например, `Click`, `SelectedIndexChanged`, `CellValueChanged`), на которые форма подписывается. Главная задача разработчика на этом этапе — предотвратить каскадные ошибки, которые возникают, когда один элемент изменяет состояние другого, вызывая бесконечную цепочку срабатывания событий.

Передача данных между компонентами осуществляется через прямое обращение к свойствам объектов или через промежуточные структуры данных. Например, чтобы перенести выбранную категорию из `ComboBox` и текст из `TextBox` в новую строку таблицы `DataGridView`, используется следующий паттерн:

```csharp
// Безопасное извлечение данных из ComboBox
if (comboBoxCategory.SelectedItem == null)
{
    MessageBox.Show("Выберите категорию товара!", "Ошибка", MessageBoxButtons.OK, MessageBoxIcon.Warning);
    return;
}

string category = comboBoxCategory.SelectedItem.ToString();
string productName = textBoxName.Text.Trim();

// Валидация числового поля цены
if (!decimal.TryParse(textBoxPrice.Text, out decimal price) || price <= 0)
{
    MessageBox.Show("Цена должна быть положительным числом!", "Ошибка ввода", MessageBoxButtons.OK, MessageBoxIcon.Error);
    return;
}

// Добавление данных в DataGridView
dataGridViewProducts.Rows.Add(category, productName, price.ToString("F2"));
```

### Обработка ошибок и валидация данных в интерфейсе

Пользовательский ввод непредсказуем. Пользователь может оставить поле пустым, ввести буквы вместо цифр или попытаться сохранить файл без предварительного заполнения таблицы. Для обеспечения отказоустойчивости приложения применяются два уровня защиты:
1. **Предварительная валидация (Preventive Validation):** проверка значений до их обработки (как в примере с `decimal.TryParse`).
2. **Перехват исключений (Exception Handling):** использование блоков `try-catch` при работе с внешними ресурсами (файловой системой, потоками, конвертацией типов).

> **Определение.** Блок `try-catch` в C# — это конструкция обработки исключений, позволяющая перехватывать и обрабатывать программные сбои во время выполнения приложения без его аварийного завершения.

Структура безопасного чтения файла с помощью `StreamReader` и диалогового окна выглядит следующим образом:

```csharp
OpenFileDialog openFileDialog = new OpenFileDialog();
openFileDialog.Filter = "Текстовые файлы (*.txt)|*.txt|Все файлы (*.*)|*.*";

if (openFileDialog.ShowDialog() == DialogResult.OK)
{
    try
    {
        using (StreamReader reader = new StreamReader(openFileDialog.FileName))
        {
            textBoxEditor.Text = reader.ReadToEnd();
        }
        toolStripStatusLabel.Text = "Файл успешно загружен: " + Path.GetFileName(openFileDialog.FileName);
    }
    catch (Exception ex)
    {
        MessageBox.Show($"Ошибка при чтении файла:\n{ex.Message}", "Критическая ошибка", MessageBoxButtons.OK, MessageBoxIcon.Error);
    }
}
```

### Оценка сложности алгоритмов обновления интерфейса

При работе с большими объемами данных (например, загрузка тысяч строк в `DataGridView` или добавление элементов в `ListBox`) возникает проблема производительности. Каждый вызов метода `Rows.Add()` или `Items.Add()` вызывает перерисовку элемента управления (Invalidate/Refresh), что приводит к существенным задержкам интерфейса («фризам»).

Для оптимизации применяются специальные методы заморозки визуализации:
- `dataGridView1.SuspendLayout()` и `ResumeLayout()` — приостановка компоновки элементов управления.
- Отключение автоматического создания колонок (`AutoGenerateColumns = false`).
- Пакетное добавление строк через массивы объектов или специализированные коллекции (например, `BindingList<T>`).

Оценка временной сложности ($O$-нотация) для основных операций с элементами управления:
- Поиск элемента в `ListBox` перебором: $O(n)$, где $n$ — количество элементов.
- Добавление строки в `DataGridView` без оптимизации: $O(n)$ из-за пересчета макета таблицы.
- Чтение текстового файла построчно: $O(m)$, где $m$ — размер файла в байтах.

2. При нажатии кнопки «Добавить» программа проверяет корректность введенных данных: цена должна быть вещественным числом больше нуля, название не должно быть пустым.
3. Если проверка успешна, данные добавляются в `DataGridView` методом `Rows.Add`.
4. Одновременно формируется строка с текущим временем (`DateTime.Now.ToLongTimeString()`) и добавляется в `ListBox` для фиксации истории.

```csharp
                }
            }
        }
```

3. Открытие и сохранение файлов реализуются через стандартные диалоговые окна `OpenFileDialog` и `SaveFileDialog` с использованием блоков `try-catch` для защиты от сбоев доступа к диску.

```csharp
using System;
using System.IO;
using System.Windows.Forms;

namespace SimpleTextEditor
{
    public partial class EditorForm : Form
    {

                Multiline = true,
                Dock = DockStyle.Fill,
                ScrollBars = ScrollBars.Vertical,
                AcceptsReturn = true,
                AcceptsTab = true
            };
            textBoxEditor.TextChanged += TextBoxEditor_TextChanged;
            
            // Размещение текстового поля между меню и статус-панелью
            // Панели DockStyle занимают края, TextBox со стилем Fill заполняет остальное пространство.
            this.Controls.Add(textBoxEditor);
        }

        private void TextBoxEditor_TextChanged(object sender, EventArgs e)
        {
            int charCount = textBoxEditor.Text.Length;
            string fileNameInfo = string.IsNullOrEmpty(currentFilePath) ? "Новый файл" : Path.GetFileName(currentFilePath);
            statusLabel.Text = $"Файл: {fileNameInfo} | Символов: {charCount}";
        }

        private void MenuItemOpen_Click(object sender, EventArgs e)
        {
            OpenFileDialog openDialog = new OpenFileDialog();
            openDialog.Filter = "Текстовые файлы (*.txt)|*.txt|Все файлы (*.*)|*.*";

            if (openDialog.ShowDialog() == DialogResult.OK)
            {
                try
                {
                    currentFilePath = openDialog.FileName;
                    using (StreamReader reader = new StreamReader(currentFilePath))
                    {
                        textBoxEditor.Text = reader.ReadToEnd();
                    }
                    MessageBox.Show("Файл успешно открыт!", "Информация", MessageBoxButtons.OK, MessageBoxIcon.Information);
                }
                catch (Exception ex)
                {
                    MessageBox.Show($"Ошибка открытия файла:\n{ex.Message}", "Ошибка", MessageBoxButtons.OK, MessageBoxIcon.Error);
                }
            }
        }

        private void MenuItemSave_Click(object sender, EventArgs e)
        {
            if (string.IsNullOrEmpty(currentFilePath))
            {
                SaveFileDialog saveDialog = new SaveFileDialog();
                saveDialog.Filter = "Текстовые файлы (*.txt)|*.txt|Все файлы (*.*)|*.*";

                if (saveDialog.ShowDialog() == DialogResult.OK)
                {
                    currentFilePath = saveDialog.FileName;
                }
                else
                {
                    return; // Пользователь отменил сохранение
                }
            }

            try
            {
                using (StreamWriter writer = new StreamWriter(currentFilePath, false, System.Text.Encoding.UTF8))
                {
                    writer.Write(textBoxEditor.Text);
                }
                MessageBox.Show("Файл успешно сохранен!", "Информация", MessageBoxButtons.OK, MessageBoxIcon.Information);
                
                // Обновляем статус
                TextBoxEditor_TextChanged(null, null);
            }
            catch (Exception ex)
            {
                MessageBox.Show($"Ошибка сохранения файла:\n{ex.Message}", "Ошибка", MessageBoxButtons.OK, MessageBoxIcon.Error);
            }
        }
    }
}
```

### Разобранный комплексный пример: Система учета заказов

**Условие:** Разработать оконное приложение «Учет заказов». Главное окно содержит меню `MenuStrip`, выпадающий список `ComboBox` для выбора типа клиента («Оптовый» со скидкой $10\%$ / $0{,}9$, «Розничный» без скидки / $1{,}0$), список `ListBox` для выбора региона доставки («Центр» с доставкой $300{,}00$ руб., «Регионы» с доставкой $700{,}00$ руб.), таблицу `DataGridView` для добавления позиций заказа, кнопку «Рассчитать итоговую сумму заказа» и метку для вывода результата. Также предусмотреть сохранение итогового отчета о заказе в текстовый файл с помощью `SaveFileDialog`.

**Рисунок (схема интерфейса):**
```text
+-----------------------------------------------------------------+
| Система учета заказов                       [ Меню: Файл, Справка ]
|-----------------------------------------------------------------+
| Тип клиента (ComboBox):      Регион доставки (ListBox):         |
| [ Оптовый                 ]  +-------------------------------+  |
|                              | Центр                         |  |
|                              | Регионы                       |  |
|                              +-------------------------------+  |
|                                                                 |
| Позиции заказа (DataGridView):                                  |
| +--------------------+-------------------+--------------------+ |
| | Товар              | Количество        | Цена за ед. (руб.) | |
| | Ноутбук            | 2                 | 45000              | |
| | Мышь беспроводная  | 5                 | 1500               | |
| +--------------------+-------------------+--------------------+ |
|                                                                 |
| [ Рассчитать заказ ]         [ Сохранить отчет в файл ]         |
| Итог: Сумма товаров: 97500 руб. Скидка: 9750 руб. Доставка...   |
+-----------------------------------------------------------------+
```

**Ход рассуждений:**
1. Создаем форму, инициализируем `MenuStrip` с пунктами очистки, выхода и справки.
2. Размещаем компоненты выбора: `ComboBox` (`comboClientType`) с двумя типами клиентов и `ListBox` (`listRegion`) с регионами доставки.
3. Инициализируем таблицу `DataGridView` (`gridItems`) с тремя колонками: Наименование (`ColItem`), Количество (`ColQty`), Цена (`ColPrice`). Добавим в нее пару начальных строк для демонстрации.
4. Создаем две кнопки: `btnCalculate` (расчет стоимости с учетом скидки клиента и стоимости доставки) и `btnSaveReport` (вызов `SaveFileDialog` для записи текстового отчета о заказе на диск).
5. Логика расчета:
   - Проходим циклом по всем строкам таблицы `gridItems`.
   - Проверяем корректность числовых данных (`int.TryParse` для количества, `decimal.TryParse` для цены).
   - Вычисляем общую стоимость товаров: $\text{Сумма} = \sum (\text{Количество} \times \text{Цена})$.
   - Применяем коэффициент скидки в зависимости от выбранного типа клиента в `ComboBox`.
   - Добавляем стоимость доставки в зависимости от выбранного региона в `ListBox`.
   - Выводим подробный отчет в метку и формируем текст для сохранения в файл.

**Решение в коде на C#:**

```csharp
using System;
using System.IO;
using System.Windows.Forms;

namespace OrderSystemApp
{
    public partial class MainForm : Form
    {
        // Элементы управления формы
        private MenuStrip menuStripMain;
        private ToolStripMenuItem menuFile;
        private ToolStripMenuItem menuClear;
        private ToolStripSeparator sep1;
        private ToolStripMenuItem menuExit;
        
        private ComboBox comboClientType;
        private ListBox listRegion;
        private DataGridView gridItems;
        private Button btnCalculate;
        private Button btnSaveReport;
        private Label lblResult;

        private string lastReportText = ""; // Переменная для хранения текста последнего расчета

        public MainForm()
        {
            InitializeComponent();
            BuildComplexInterface();
        }

        private void BuildComplexInterface()
        {
            this.Text = "Комплексная система учета заказов";
            this.Width = 750;
            this.Height = 600;

            // 1. Главное меню
            menuStripMain = new MenuStrip();
            menuFile = new ToolStripMenuItem("&Файл");
            menuClear = new ToolStripMenuItem("Очистить форму", null, MenuClear_Click);
            sep1 = new ToolStripSeparator();
            menuExit = new ToolStripMenuItem("Выход", null, (s, e) => Application.Exit());

            menuFile.DropDownItems.Add(menuClear);
            menuFile.DropDownItems.Add(sep1);
            menuFile.DropDownItems.Add(menuExit);
            menuStripMain.Items.Add(menuFile);
            this.MainMenuStrip = menuStripMain;

            // 2. ComboBox для типов клиентов
            Label lblClient = new Label { Text = "Тип клиента:", Left = 20, Top = 40, Width = 100 };
            comboClientType = new ComboBox { Left = 20, Top = 65, Width = 200 };
            comboClientType.DropDownStyle = ComboBoxStyle.DropDownList;
            comboClientType.Items.Add("Розничный (без скидки)");
            comboClientType.Items.Add("Оптовый (скидка 10%)");
            comboClientType.SelectedIndex = 0;

            // 3. ListBox для регионов доставки
            Label lblReg = new Label { Text = "Регион доставки:", Left = 250, Top = 40, Width = 150 };
            listRegion = new ListBox { Left = 250, Top = 65, Width = 200, Height = 60 };
            listRegion.Items.Add("Центр (300 руб.)");
            listRegion.Items.Add("Регионы (700 руб.)");
            listRegion.SelectedIndex = 0;

            // 4. DataGridView для позиций заказа
            Label lblGrid = new Label { Text = "Позиции заказа:", Left = 20, Top = 140, Width = 150 };
            gridItems = new DataGridView { Left = 20, Top = 165, Width = 690, Height = 180 };
            gridItems.AllowUserToAddRows = true;

            DataGridViewTextBoxColumn col1 = new DataGridViewTextBoxColumn { Name = "ColName", HeaderText = "Товар", Width = 300 };
            DataGridViewTextBoxColumn col2 = new DataGridViewTextBoxColumn { Name = "ColQty", HeaderText = "Количество", Width = 150 };
            DataGridViewTextBoxColumn col3 = new DataGridViewTextBoxColumn { Name = "ColPrice", HeaderText = "Цена за ед. (руб.)", Width = 200 };

            gridItems.Columns.Add(col1);
            gridItems.Columns.Add(col2);
            gridItems.Columns.Add(col3);

            // Начальные данные в таблице
            gridItems.Rows.Add("Ноутбук", "1", "55000");
            gridItems.Rows.Add("Сумка для ноутбука", "1", "2500");

            // 5. Кнопки и метка результата
            btnCalculate = new Button { Text = "Рассчитать заказ", Left = 20, Top = 360, Width = 180, Height = 35 };
            btnCalculate.Click += BtnCalculate_Click;

            btnSaveReport = new Button { Text = "Сохранить отчет в файл", Left = 210, Top = 360, Width = 200, Height = 35 };
            btnSaveReport.Click += BtnSaveReport_Click;

            lblResult = new Label { Left = 20, Top = 410, Width = 690, Height = 120, Text = "Расчет не выполнен." };

            // Добавление всех элементов на форму
            this.Controls.Add(menuStripMain);
            this.Controls.Add(lblClient);
            this.Controls.Add(comboClientType);
            this.Controls.Add(lblReg);
            this.Controls.Add(listRegion);
            this.Controls.Add(lblGrid);
            this.Controls.Add(gridItems);
            this.Controls.Add(btnCalculate);
            this.Controls.Add(btnSaveReport);
            this.Controls.Add(lblResult);
        }

        private void MenuClear_Click(object sender, EventArgs e)
        {
            comboClientType.SelectedIndex = 0;
            listRegion.SelectedIndex = 0;
            gridItems.Rows.Clear();
            gridItems.Rows.Add("Ноутбук", "1", "55000");
            lblResult.Text = "Расчет не выполнен.";
            lastReportText = "";
        }

        private void BtnCalculate_Click(object sender, EventArgs e)
        {
            // Проверка выбора в списках
            if (comboClientType.SelectedIndex == -1 || listRegion.SelectedIndex == -1)
            {
                MessageBox.Show("Выберите тип клиента и регион доставки!", "Ошибка", MessageBoxButtons.OK, MessageBoxIcon.Warning);
                return;
            }

            decimal goodsTotal = 0m;

            // Расчет стоимости позиций из таблицы
            for (int i = 0; i < gridItems.Rows.Count; i++)
            {
                if (gridItems.Rows[i].IsNewRow) continue;

                var valName = gridItems.Rows[i].Cells[0].Value;
                var valQty = gridItems.Rows[i].Cells[1].Value;
                var valPrice = gridItems.Rows[i].Cells[2].Value;

                if (valName == null || valQty == null || valPrice == null)
                {
                    MessageBox.Show($"Ошибка в строке {i + 1}: заполните все поля товара!", "Ошибка", MessageBoxButtons.OK, MessageBoxIcon.Error);
                    return;
                }

                if (!int.TryParse(valQty.ToString(), out int qty) || qty <= 0)
                {
                    MessageBox.Show($"Ошибка в строке {i + 1}: некорректное количество!", "Ошибка", MessageBoxButtons.OK, MessageBoxIcon.Error);
                    return;
                }

                if (!decimal.TryParse(valPrice.ToString(), out decimal price) || price < 0)
                {
                    MessageBox.Show($"Ошибка в строке {i + 1}: некорректная цена!", "Ошибка", MessageBoxButtons.OK, MessageBoxIcon.Error);
                    return;
                }

                goodsTotal += qty * price;
            }

            // Определение скидки
            decimal discountRate = (comboClientType.SelectedIndex == 1) ? 0.10m : 0.0m;
            decimal discountSum = goodsTotal * discountRate;
            decimal goodsWithDiscount = goodsTotal - discountSum;

            // Определение стоимости доставки
            decimal deliveryCost = (listRegion.SelectedIndex == 0) ? 300.00m : 700.00m;

            // Итоговая сумма заказа
            decimal finalTotal = goodsWithDiscount + deliveryCost;

            // Формирование текста отчета
            lastReportText = $"=== ОТЧЕТ О ЗАКАЗЕ ===\r\n" +
                             $"Тип клиента: {comboClientType.SelectedItem}\r\n" +
                             $"Регион доставки: {listRegion.SelectedItem}\r\n" +
                             $"Сумма товаров: {goodsTotal:F2} руб.\r\n" +
                             $"Скидка: {discountSum:F2} руб.\r\n" +
                             $"Доставка: {deliveryCost:F2} руб.\r\n" +
                             $"ИТОГО К ОПЛАТЕ: {finalTotal:F2} руб.\r\n";

            lblResult.Text = lastReportText;
        }

        private void BtnSaveReport_Click(object sender, EventArgs e)
        {
            if (string.IsNullOrEmpty(lastReportText))
            {
                MessageBox.Show("Сначала выполните расчет заказа!", "Внимание", MessageBoxButtons.OK, MessageBoxIcon.Information);
                return;
            }

            using (SaveFileDialog saveDlg = new SaveFileDialog())
            {
                saveDlg.Filter = "Текстовые файлы (*.txt)|*.txt|Все файлы (*.*)|*.*";
                saveDlg.FileName = "OrderReport.txt";

                if (saveDlg.ShowDialog() == DialogResult.OK)
                {
                    try
                    {
                        File.WriteAllText(saveDlg.FileName, lastReportText);
                        MessageBox.Show("Отчет успешно сохранен на диск!", "Успех", MessageBoxButtons.OK, MessageBoxIcon.Information);
                    }
                    catch (Exception ex)
                    {
                        MessageBox.Show($"Ошибка при сохранении файла:\n{ex.Message}", "Ошибка", MessageBoxButtons.OK, MessageBoxIcon.Error);
                    }
                }
            }
        }
    }
}
```

**Проверка:**
- При запуске в таблице есть две позиции: Ноутбук (1 шт. по $55000{,}00$ руб.) и Сумка (1 шт. по $2500{,}00$ руб.). Сумма товаров равна $57500{,}00$ руб.
- Для розничного клиента скидка $0$, доставка в Центр $300{,}00$ руб. Итого: $57500 + 300 = 57800{,}00$ руб.
- Если выбрать оптового клиента ($10\%$ скидка), сумма товаров со скидкой составит $51750{,}00$ руб., плюс доставка $300{,}00$ руб. Итого: $52050{,}00$ руб.
- Расчеты корректны, типы данных `decimal` исключают финансовые погрешности округления.

`Ответ:` Разработано полноценное комплексное оконное приложение, объединяющее элементы `MenuStrip`, `ComboBox`, `ListBox`, `DataGridView` и диалоговые окна `SaveFileDialog` с полной валидацией данных и расчетом заказа.

## Типичные ошибки

1. **Использование свойства `SelectedItem` у пустого списка.**
   * *В чём ошибка:* Обращение к `listBox.SelectedItem` или `comboBox.SelectedItem`, когда элемент не выбран (`SelectedIndex == -1`), возвращает `null`. Вызов `.ToString()` у `null` приводит к генерации исключения `NullReferenceException`.
   * *Как избежать:* Всегда проверять условие `if (listBox.SelectedIndex != -1)` перед извлечением данных.

2. **Модификация коллекции `Items` при привязке через `DataSource`.**
   * *В чём ошибка:* Попытка вызвать методы `Add` или `Remove` у коллекции `Items` компонента `ListBox`, у которого задано свойство `DataSource`. Это вызывает исключение времени выполнения `NotSupportedException`.
   * *Как избежать:* Изменять исходную коллекцию данных (например, `List<T>`), а затем заново присваивать её в `DataSource`.

3. **Забытая проверка на пустую строку в `DataGridView` (`IsNewRow`).**
   * *В чём ошибка:* При обходе строк таблицы в цикле разработчик забывает, что последняя пустая строка внизу `DataGridView` предназначена для ручного ввода. Обращение к ее ячейкам возвращает `null`, что приводит к сбоям парсинга.
   * *Как избежать:* Использовать проверку `if (dataGridView.Rows[i].IsNewRow) continue;` или проверять ячейки на равенство `null`.

4. **Использование типа `double` вместо `decimal` для финансовых расчетов в таблицах.**
   * *В чём ошибка:* Ведение расчетов цен и бюджетов с использованием типов с плавающей точкой (`double` или `float`), что приводит к накоплению арифметических погрешностей округления (например, `0.1 + 0.2 != 0.3`).
   * *Как избежать:* Для денежных и точных расчетных данных в таблицах использовать тип `decimal` и метод `decimal.TryParse`.

5. **Некорректный синтаксис фильтра в `OpenFileDialog` / `SaveFileDialog`.**
   * *В чём ошибка:* Написание фильтра без вертикальных черт или с ошибками в масках (например, `"*.txt"` вместо `"Текстовые файлы (*.txt)|*.txt"`), из-за чего диалоговое окно выдает ошибку инициализации или некорректно отображает файлы.
   * *Как избежать:* Использовать стандартный шаблон: `"Описание (*.расширение)|*.расширение"`.

6. **Создание бесконечного цикла или сбоев при обработке событий `SelectedIndexChanged`.**
   * *В чём ошибка:* Программное изменение индекса в обработчике `SelectedIndexChanged` повторно вызывает это же событие, приводя к рекурсии или неконтролируемому поведению интерфейса.
   * *Как избежать:* Управлять флагами блокировки или проектировать логику так, чтобы программные изменения не дублировали реакцию на действия пользователя.

7. **Отсутствие обработки исключений при работе с файловой системой.**
   * *В чём ошибка:* Вызов `File.ReadAllText()` без блока `try-catch`. Если файл заблокирован другим процессом или удален во время выбора, программа аварийно завершается.
   * *Как избежать:* Обязательно оборачивать операции чтения/записи через диалоговые окна в конструкции `try { ... } catch (Exception ex) { ... }`.

## Ответы к задачам

1. При выборе секции и абонемента вычисляется и выводится итоговая стоимость (например, для «Плавания» на месяц: $2500 \times 1{,}1 \times 1{,}0 = 2750{,}00$ руб.; для «Шахмат» на год: $2500 \times 0{,}85 \times 9 = 19125{,}00$ руб.). При отсутствии выбора выдается предупреждение.
2. Приложение добавляет уникальные товары в `ListBox`, блокирует добавление дубликатов, удаляет выбранную позицию и корректно отображает общее число элементов в метке.
3. Программа создает таблицу из 10 строк. В строке 5 отображаются значения: Число — `5`, Квадрат — `25`, Куб — `125`. Редактирование ячеек заблокировано.
4. При наличии в таблице двух товаров (например, 2 шт. по $1500{,}00$ руб. и 3 шт. по $400{,}00$ руб.) общая сумма рассчитывается корректно: $2 \times 1500 + 3 \times 400 = 3000 + 1200 = 4200{,}00$ руб. При вводе букв вместо числа выдается предупреждение.
5. При клике на пункт меню «Режим разработчика» статус `Checked` переключается, форма меняет цвет фона на `MidnightBlue`, а текст метки становится желтым. Повторный клик возвращает стандартные цвета.
6. Приложение успешно открывает текстовые файлы через `OpenFileDialog` и сохраняет их содержимое через `SaveFileDialog` с обработкой возможных исключений ввода-вывода.
7. Комплексный расчет корректно суммирует позиции из таблицы `DataGridView`, применяет скидку за оплату наличными, добавляет надбавку за срочность и сохраняет сформированный отчет в текстовый файл через `SaveFileDialog`.
