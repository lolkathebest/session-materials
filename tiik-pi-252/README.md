# Теория информации и кодирования — ПИ-252, зачёт

[← Все предметы и группы](../README.md) · **[📘 Конспекты по всем темам предмета](../konspekty/info-theory/README.md)** — теория, разобранные примеры, задачи с ответами.

- **Аттестация:** зачёт на последней неделе семестра (30.12).
- **Допуск:** выполнены практические и лабораторные работы семестра.
- **Билет:** один теоретический вопрос и одна расчётная задача (решается вручную, с промежуточными шагами).
- **Можно пользоваться:** непрограммируемым калькулятором.
- **Критерии:** «зачтено» — обе части билета выполнены не ниже уровня «3» по
  [общим критериям](../README.md#общие-критерии-оценивания); иначе — «не зачтено».
  В задаче проверяются промежуточные шаги (суммы, логарифмы до 3–4 знаков, деревья и таблицы кодов);
  при равных вероятностях принимается любой корректный вариант кода.

## Теоретические вопросы

**1. Основы теории информации**
1. Информация и данные. Предмет теории информации.
2. Мера информации Хартли. Мера Шеннона. Энтропия дискретного источника и её свойства.
3. Избыточность источника.
4. Совместная и условная энтропия. Взаимная информация.
5. Дискретный канал связи. Двоичный симметричный канал, пропускная способность.
6. Теоремы Шеннона о кодировании для канала без помех и с помехами.

**2. Кодирование источника (сжатие)**
7. Префиксные коды. Неравенство Крафта.
8. Код Шеннона–Фано: построение, средняя длина, эффективность.
9. Код Хаффмана: построение, оптимальность.
10. Арифметическое кодирование.
11. Словарные методы LZ77 и LZ78.
12. Алгоритм LZW: кодирование и декодирование.
13. Сжатие с потерями: квантование, дискретное косинусное преобразование, схема JPEG.

**3. Помехоустойчивое кодирование**
14. Обнаружение и исправление ошибок. Расстояние Хэмминга, минимальное кодовое расстояние.
15. Линейные блочные коды. Порождающая и проверочная матрицы.
16. Синдромное декодирование.
17. Код Хэмминга (7,4): построение, исправление одиночной ошибки.
18. Конечные поля Галуа GF(2^m): сложение и умножение элементов.
19. Циклические коды. Порождающий многочлен.
20. CRC: вычисление и применение.
21. Коды БЧХ и Рида–Соломона (обзор).
22. Сверточные коды: кодер, решётчатая диаграмма.
23. Декодирование сверточных кодов: алгоритм Витерби.
24. Современные коды: турбо-коды, LDPC (обзор).

## Образцы задач

1. Источник выдаёт символы A, B, C, D с вероятностями 0,5; 0,25; 0,125; 0,125.
   Найдите энтропию источника и его избыточность.
2. Постройте коды Шеннона–Фано и Хаффмана для символов с вероятностями
   0,4; 0,2; 0,15; 0,15; 0,1. Сравните их среднюю длину и эффективность.
3. Закодируйте строку `ABABABA` алгоритмом LZW (начальный словарь: A = 1, B = 2). Покажите таблицу шагов.
4. Закодируйте сообщение 1011 кодом Хэмминга (7,4) (проверочные биты — на позициях 1, 2, 4).
   Принято слово 0110111 — вычислите синдром, найдите и исправьте ошибку.
5. Вычислите CRC для сообщения 1101 с порождающим многочленом x³ + x + 1.
6. Двоичный симметричный канал с вероятностью ошибки 0,1. Найдите пропускную способность канала.
